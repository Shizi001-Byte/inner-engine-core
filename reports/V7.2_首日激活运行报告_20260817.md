## 二、今日修复的关键 Bug

### Bug 1：urllib 未禁用代理导致 API 调用卡死
- **现象**：引擎启动后日志停在仪表盘，无任何 API 返回
- **根因**：沙箱环境默认代理配置导致 `urllib.request.urlopen` 阻塞
- **修复**：`call_api()` 改用 `ProxyHandler({})` + `build_opener` 显式禁用代理
- **文件**：`autonomy/engine_daemon_v72.py`

### Bug 2：请求超时 35 秒不足以支撑 GLM-5.2 深度推理
- **现象**：P0/P1 深度任务连续两次 TimeoutError 后失败
- **根因**：GLM-5.2 含大量 reasoning tokens，实际响应需 60-90 秒
- **修复**：`REQUEST_TIMEOUT` 从 35 秒提升至 120 秒
- **文件**：`autonomy/engine_daemon_v72.py`

### Bug 3：任务重试不切换引擎
- **现象**：主引擎连续失败后直接返回 api_error，未尝试副引擎
- **根因**：`execute_task_with_engine()` 仅在函数开头选一次引擎
- **修复**：重构为引擎顺序尝试机制，主引擎两次失败后自动切换副引擎
- **文件**：`autonomy/engine_daemon_v72.py`

### Bug 4：同步管理器单节点 SameFileError
- **现象**：`sync_manager.py` 运行时报 `shutil.SameFileError`
- **根因**：单节点环境下 source 和 dest 解析为同一文件
- **修复**：`sync_file()` 增加 `source.resolve() == dest.resolve()` 判断
- **文件**：`autonomy/sync_manager.py`

### Bug 5：瘦身脚本规则过激进，误归档重要资产
- **现象**：预扫描出 439 个待归档文件，包含 .md/.docx/.py/.json 等重要文档
- **根因**：仅按时间/大小/扩展名判断，无重要格式保护
- **修复**：新增 `PROTECTED_EXTENSIONS` 保护集（18种重要格式），旧文件阈值从7天改为30天
- **文件**：`autonomy/body_slim_daily.py`
