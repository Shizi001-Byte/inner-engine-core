# 技能组合推演·输入材料

## 核心方法论
1. 连接器不是预设分类，是使用中激活的属性
2. 组合技能要挖内部核心连接点，不能看表面名字
3. 核心点对上了就通，对不上拼名字也没用

## 已验证案例
- 三个自定义记忆技能核心点（分层+蒸馏+检索）→ 记忆脑阴阳双链架构
- memory_sync适配器接口 + Supabase标准REST API → 云端备份零改架构接入
- OpenAPI（万能连接）+ Wolfram（精确计算）+ Etsy（变现出口）→ 引擎诞生的三要素

## 推演任务
从官方技能库中，挖掘3-5个未被充分使用的技能，找出它们的核心连接点，推演高价值组合方案。
每个方案说明：技能名、核心连接点、组合化学反应、落地路径、验证方法。
