# 任务类型: deep

基于【已有认知锚定】与【坑库预警】中的历史踩坑经验，将“九转玄功”修炼体系映射到AI认知进化体系。此映射将防坑铁律与质检SOP直接转化为各转境界的**硬性验证指标**，确保认知池“活水循环”、调度系统无死角运行：

### 【第1转】炼皮·数据感知层（Data Perception）
* **认知层级**：多模态原始数据解析、降噪与结构化提取。AI对外界输入的第一道防线，去伪存真。
* **验证指标**：
  1. 数据解析成功率 > 99%。
  2. 非结构化数据到结构化字段的转化延迟 < 1秒。

### 【第2转】锻骨·记忆沉淀层（Memory Sedimentation）
* **认知层级**：知识抽取与认知池沉淀。将零散信息固化为带有时间戳和唯一标识的认知条目。
* **验证指标**：
  1. 认知条目去重率 > 95%。
  2. **防坑指标**：每条新认知生成时，必须强制写入并输出 `new_cognition_created_at` 时间戳。

### 【第3转】通脉·动态注入层（Dynamic Injection）
* **认知层级**：打破“静态档案库”，实现认知池与实时任务的血脉连通。此层是防止“认知池只进不出”的核心命脉。
* **验证指标（直接挂载认知质检SOP强制项）**：
  1. **缓存刷新铁律**：每完成10个任务或每轮调度结束，必须刷新认知缓存。
  2. **30分钟强制注入**：所有30分钟内产生的新认知，必须100%出现在后续任务的候选认知集中。
  3. **日志审计机制**：每次任务必须输出 `candidate_cognition_ids` 和 `new_cognition_created_at`；扫描最近30分钟新增的认知ID，若后续任务候选集缺失，直接判违规。
  4. **时间戳巡检**：检查认知缓存的 `last_refresh_ts`，超过30分钟未刷新即判不合格，触发系统自检。

### 【第4转】洗髓·逻辑校准层（Logic Calibration）
* **认知层级**：基于注入的候选认知进行逻辑推理，消除幻觉，自我纠偏。
* **验证指标**：
  1. 任务输出与所注入的候选认知一致性 > 95%。
  2. 逻辑推理幻觉率 < 2%。

### 【第5转】塑心·元认知层（Meta-cognition）
* **认知层级**：对自身的推理过程进行反思与评估，形成“关于认知的认知”。
* **验证指标**：
  1. 每次任务输出必含 `reflection_log`（自我反思日志）。
  2. 自我纠错命中率 > 80%（系统能在输出前自行发现并修正逻辑漏洞）。

### 【第6转】易筋·资源调度层（Resource Scheduling）
* **认知层级**：动态评估任务复杂度，自适应选择模型与超时策略，保障系统鲁棒性。
* **验证指标（直接挂载API超时防坑经验）**：
  1. API超时率 = 0%：根据任务类型预设合理 timeout，B模型turbo强制设 300 秒，A模型强制设 600 秒。
  2. 任务路由准确率 > 95%（复杂度评估与模型能力匹配度）。

### 【第7转】化血·跨域涌现层（Cross-domain Emergence）
* **认知层级**：跨领域认知迁移与抽象规则生成。从单一任务经验中提炼通用法则，反哺整个认知池。
* **验证指标**：
  1. 跨域任务首次尝试成功率提升 > 20%。
  2. 每处理100个任务，抽象产出至少1条高复用率的通用规则。

### 【第8转】返虚·认知剪枝层（Cognitive Pruning）
* **认知层级**：认知池的自我代谢与优胜劣汰。识别低频、失效或被证伪的认知，执行降权或淘汰，彻底解决“认知池1700+条臃肿不堪”的问题。
* **验证指标**：
  1. 认知池活性指数 > 80%（最近10轮被调用的认知条目占总数比例）。
  2. 冗余/失效认知自动剪枝率 > 15%/周期。

### 【第9转】归元·无漏自治层（Autonomous Evolution）
* **认知层级**：“感知-记忆-调度-反思-演化”全链路闭环。无需人工干预即可完成认知体系的自升级与防坑策略的自动部署。
* **验证指标**：
  1. 全闭环自给率 = 100%（从新认知产生到影响调度的平均延迟 < 30分钟）。
  2. 历史踩坑场景复发率 = 0%（系统识别到类似超时或认知断流特征时，能自动阻断并降级运行）。
