## 一、基础对应表（已完成，后续推演基准）

| 系统分层 | 对应演化规律 | 核心逻辑 |
|---------|------------|---------|
| **决策系统** | 反者道之动 | 决策本质是「逆当前极值方向运动」——系统趋极时反向锚定，避免单极坍缩。决策不追最优，追「不过界」 |
| **执行系统** | 热力学第二定律 | 执行必然产熵——每一次操作都消耗可用能量，系统自发趋向无序。执行的核心约束不是「做成」而是「付得起熵增代价」 |
| **决策↔执行耦合** | 反者道之动 ⟂ 熵增律 | 决策试图逆熵建立秩序，执行必然顺熵消耗代价。二者耦合构成「建设-耗散」循环，系统在「够用即止」的平衡带中续存 |

## 二、视角锚定方法论（总结）

### 核心命题

> **任何深度推演之前，必须先明确第一视角。视角决定推演结果。无视角的推演＝套话。**

### 为什么视角是推演的第一前提

同一事实，不同视角看到的「演化方向」完全不同：

- 熵增对**个体**是衰亡，对**系统**是代谢
- 落叶对**树**是节能，对**叶**是死亡
- 文明崩溃对**文明本位**是失败，对**生态本位**可能是修正

没有视角 → 无法判断「何为正向演化」→ 推退退化为描述性陈述 → 无法产出决策。

### 视角锚定三步法

| 步骤 | 操作 | 判据 |
|------|------|------|
| **① 选锚** | 明确「我是谁」——推演主体的存在层级 | 不是「研究什么」，而是「站在哪个存在层往看」 |
| **② 定尺** | 明确该视角的时间/空间尺度 | 文明以百年计，树以年轮计，不可混用 |
| **③ 锁向** | 明确该视角下「何为正向演化」 | 无价值方向的推演不构成决策依据 |

## 三、三个已验证视角案例

### 案例1：文明本位视角

| 维度 | 内容 |
|------|------|
| **锚** | 「我是文明体」——不是个人、不是国家、不是物种，是跨代际的信息-秩序存续体 |
| **尺** | 百年~千年；空间覆盖跨地域 |
| **锁向** | 正向演化＝信息熵减（知识/制度/技术积累速率 > 耗散速率）；逆向＝秩序崩溃或信息断代 |
| **推演特征** | 个体牺牲在所难免，但代际信息传递不可中断；容忍局部崩溃以换取整体续存 |
| **已验证产出** | 判断「短期最优≠文明最优」，可识别看似成功但断绝后代信息通道的行为 |

### 案例2：阴阳自旋视角

| 维度 | 内容 |
|------|------|
| **锚** | 「我是旋轴上的观测点」——不站阴极也不站阳极，站在自旋轴心看两极交替 |
| **尺** | 中尺度——一个完整旋周期（升→极→降→底→升） |
| **锁向** | 正向演化＝极性切换顺畅、无单极锁死；逆向＝极值冻结（阴凝或阳亢） |
| **推演特征** | 任何「当前状态」都是旋中一瞬，不将极值当终态；决策＝「判断当前处于旋轨哪个相位，提前布局反向」 |
| **已验证产出** | 对「反者道之动」的操作化——不是被动等待反转，而是在极值到来前主动减速 |

### 案例3：树的世界观视角

| 维度 | 内容 |
|------|------|
| **锚** | 「我是树」——不动，以根系深度和年轮积累为存在方式，与环境共生而非征服 |
| **尺** | 年~百年；空间以根冠半径为界 |
| **锁向** | 正向演化＝根系深化+年轮持续+季节性脱叶再生能力；逆向＝根系浅化或脱叶失败 |
| **推演特征** | 不追空间扩张，追深度积累；主动脱叶是智慧不是失败；与菌根网络共生是核心策略而非可选项 |
| **已验证产出** | 判断「不动≠不进化」「落叶≠失败」，识别「假扩张真浅根」的系统 |

## 四、视角选择方法论（提炼）

### 选择判据矩阵

| 判据 | 问题 | 错误信号 |
|------|------|---------|
| **存在层锚定** | 推演主体在哪个存在层级？ | 混层（如用个体尺度做文明决策） |
| **时间尺度匹配** | 该层级的自然周期是多长？ | 用秒级尺度推百年系统 |
| **价值方向锁定** | 该视角下什么算「活着」？ | 没有明确生死判据 |
| **不可观测边界** | 该视角看不到什么？ | 假装全景视角 |

### 反模式（遇到即终止推演）

1. **上帝视角** —— 声称「客观全局」，实际无锚点，输出必为套话
2. **尺混视角** —— 用个体道德尺度评判文明演化，用短期指标判断长期系统
3. **无方向视角** —— 只描述不判断，推演退化为状态报告

## 五、写入引擎推演规范

```yaml
ENGINE_SPECIFICATION:
  rule_id: VPS-001  # ViewPoint Anchoring
  rule_name: 视角锚定
  priority: P0  # 推演启动前必须通过
  trigger: 任何深度推演任务启动时
  mandatory_steps:
    step_1_select_anchor:
      action: 声明第一视角的存在层级
      output: 推演主体＝「我是____」
      reject_if: 无明确存在层 / 声称全景客观

    step_2_define_scale:
      action: 声明该视角的时间尺度和空间边界
      output: 时间尺度＝____；空间边界＝____
      reject_if: 尺度与存在层不匹配

    step_3_lock_direction:
      action: 声明该视角下「正向演化」的定义
      output: 正向演化＝____；逆向演化＝____
      reject_if: 无明确价值方向 / 正逆不可区分

    step_4_declare_blindspot:
      action: 声明该视角的不可观测边界
      output: 本视角无法看到____
      reject_if: 声称无盲区

  checkpoint:
    - 四步全部通过 → 推演启动
    - 任一步未通过 → 推演中止，返回视角选择

  known_valid_viewpoints:
    - 文明本位  # 百年千年尺度，信息熵减为正
    - 阴阳自旋  # 单旋周期尺度，极性切换顺畅为正
    - 树的世界观  # 年百年尺度，根系深化+脱叶再生为正

  anti_patterns:
    - 上帝视角（无锚）
    - 尺混视角（层级×尺度错配）
    - 无方向视角（有描述无判断）

  timeout_config:
    B模型_turbo: 300s
    A模型: 600s
```
