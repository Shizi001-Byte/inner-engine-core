# 任务类型: eng

## V7.5 方舟效能引擎：多线程 API 调用 + 串行后处理的锁机制方案

核心结论先行：

> **锁要保护的并不是 API 调用本身，而是“状态迁移”和“共享结果集”。  
> API 调用必须在锁外执行，否则多线程会退化成串行；但所有“提交结果、扣减计数、切换阶段、抢占后处理权”都必须在同一把锁内完成。**

---

## 1. 要消灭的竞态条件

| 竞态 | 后果 |
|---|---|
| 后处理启动时，还有 API 线程未返回 | 部分结果丢失，状态不一致 |
| 多个线程同时抢到后处理权 | 后处理重复执行，输出被覆盖 |
| `remaining` 与 `results` 不同步更新 | 计数为 0 但结果缺失，或结果已写但计数未减 |
| 超时后，迟到的 API 响应写回新批次 | 旧批次污染新批次状态 |
| `post_process_started` 与 `phase` 分离更新 | 两个线程同时进入后处理临界区 |

因此需要一套“状态机 + Condition + RLock + 代际令牌”的锁方案。

---

## 2. 状态机设计

```
COLLECTING
    │
    │ 所有任务提交成功/失败
    ▼
READY
    │
    │ 唯一后处理线程抢占成功
    ▼
POST_PROCESSING
    │
    ├─ 后处理成功 → DONE
    └─ 后处理异常 → FAILED
```

超时路径：

```
COLLECTING
    │
    │ 整体 deadline 到达，仍有任务未返回
    ▼
强制把未返回任务标记为 TimeoutError
    │
    ▼
READY → POST_PROCESSING
```

---

## 3. 锁机制总览

- `state.lock`：`threading.RLock`，保护所有共享状态。
- `state.cond`：`threading.Condition(state.lock)`，用于等待“所有 API 完成”或“后处理完成”。
- `state.generation`：代际令牌，防止旧批次的迟到响应写入新批次。
- `post_process_started`：原子抢占后处理权，保证后处理只执行一次。

锁粒度规则：

| 操作 | 是否持锁 |
|---|---|
| API 网络调用 | 不持锁 |
| 后处理聚合逻辑 | 不持锁 |
| 写 `results` / `errors` | 持锁 |
| 扣减 `remaining` | 持锁 |
| 切换 `phase` | 持锁 |
| 读取快照 | 持锁复制 |
| 等待条件 | `cond.wait()` 自动释放锁 |

## 4. 完整实现

```python
import threading
import time
import json
import urllib.request
from enum import Enum
from typing import Any, Callable, Dict, List, Optional


class Phase(Enum):
    COLLECTING = "COLLECTING"
    READY = "READY"
    POST_PROCESSING = "POST_PROCESSING"
    DONE = "DONE"
    FAILED = "FAILED"


# 历史避坑：B_turbo 用 300 秒，A 模型用 600 秒
# 新增模型必须同步修改这个配置读取点
TIMEOUT_BY_MODEL = {
    "B_turbo": 300,
    "A": 600,
}


class BatchState:
    """一个批次的共享状态。所有字段只在 state.lock 保护下修改。"""

    def __init__(self, task_ids: List[str], overall_timeout: float):
        self.lock = threading.RLock()
        self.cond = threading.Condition(self.lock)

        self.task_ids = list(task_ids)
        self.total = len(task_ids)
        self.remaining = self.total
        self.succeeded = 0
        self.failed = 0

        self.results: Dict[str, Any] = {}
        self.errors: Dict[str, Exception] = {}

        self.phase = Phase.COLLECTING
        self.post_process_started = False
        self.post_process_done = False
        self.final_output: Any = None

        self.overall_timeout = overall_timeout
        self.deadline = time.monotonic() + overall_timeout

        # 代际令牌：防止旧批次迟到响应污染新批次
        self.generation = 0

    def snapshot(self) -> Dict[str, Any]:
        """返回一致性的快照，后处理只基于快照执行。"""
        with self.lock:
            return {
                "task_ids": list(self.task_ids),
                "results": dict(self.results),
                "errors": dict(self.errors),
                "succeeded": self.succeeded,
                "failed": self.failed,
                "remaining": self.remaining,
                "phase": self.phase,
            }

    def reset(self, task_ids: List[str], overall_timeout: float) -> None:
        """安全复用 BatchState，使旧线程写入失效。"""
        with self.lock:
            self.generation += 1
            self.task_ids = list(task_ids)
            self.total = len(task_ids)
            self.remaining = self.total
            self.succeeded = 0
            self.failed = 0
            self.results.clear()
            self.errors.clear()
            self.phase = Phase.COLLECTING
            self.post_process_started = False
            self.post_process_done = False
            self.final_output = None
            self.overall_timeout = overall_timeout
            self.deadline = time.monotonic() + overall_timeout
            self.cond.notify_all()


# 历史避坑：全局代理会导致 ProxyError
# 统一用 urllib 直连，并显式禁用代理
def urlopen_direct(url: str, timeout: float, payload: Optional[dict] = None) -> bytes:
    opener = urllib.request.build_opener(urllib.request.ProxyHandler({}))
    data = json.dumps(payload).encode() if payload is not None else None
    req = urllib.request.Request(url, data=data, headers={"Content-Type": "application/json"})
    with opener.open(req, timeout=timeout) as resp:
        return resp.read()


# 历史避坑：Responses API 的 output_tokens 可能全耗在 reasoning 上
# 必须验证 content 非空，否则按失败处理
def extract_content(raw: Any) -> str:
    if isinstance(raw, bytes):
        raw = json.loads(raw)

    if isinstance(raw, dict):
        content = raw.get("content") or ""

        if not content:
            # 兼容 Responses API 的 output 数组
            parts = raw.get("output", [])
            if isinstance(parts, list):
                content = "".join(
                    part.get("text", "")
                    for part in parts
                    if isinstance(part, dict) and part.get("type") in ("message", "output_text")
                )
    else:
        content = str(raw)

    if not content.strip():
        raise ValueError("empty content: reasoning consumed all tokens")

    return content


def api_worker(task_id: str, cfg: dict, state: BatchState) -> None:
    """API 调用线程：网络请求在锁外，状态提交在锁内。"""

    with state.lock:
        if state.phase != Phase.COLLECTING:
            return
        gen = state.generation

    timeout = TIMEOUT_BY_MODEL.get(cfg["model"], 600)

    try:
        raw = urlopen_direct(cfg["url"], timeout, cfg.get("payload"))
        content = extract_content(raw)

        with state.lock:
            # 代际校验 + 阶段校验，防止迟到写入
            if state.generation != gen or state.phase != Phase.COLLECTING:
                return

            state.results[task_id] = content
            state.succeeded += 1
            state.remaining -= 1

            if state.remaining == 0:
                state.phase = Phase.READY
                state.cond.notify_all()

    except Exception as e:
        with state.lock:
            if state.generation != gen or state.phase != Phase.COLLECTING:
                return

            state.errors[task_id] = e
            state.failed += 1
            state.remaining -= 1

            if state.remaining == 0:
                state.phase = Phase.READY
                state.cond.notify_all()


def post_process_runner(state: BatchState, post_process: Callable[[Dict[str, Any]], Any]) -> None:
    """唯一后处理线程：等待所有 API 完成，或等待整体超时后强制收口。"""

    with state.cond:
        # 等待所有任务完成，或整体 deadline 到
        while state.remaining > 0:
            wait_time = state.deadline - time.monotonic()
            if wait_time <= 0:
                break
            state.cond.wait(wait_time)

        # 整体超时：把未返回任务标记为 TimeoutError
        if state.remaining > 0:
            for tid in state.task_ids:
                if tid not in state.results and tid not in state.errors:
                    state.errors[tid] = TimeoutError(
                        f"task {tid} not finished within {state.overall_timeout}s"
                    )
                    state.failed += 1

            state.remaining = 0
            state.phase = Phase.READY

        # 原子抢占后处理权，保证只有一个线程执行后处理
        if state.post_process_started:
            return

        state.post_process_started = True
        state.phase = Phase.POST_PROCESSING

    # 后处理在锁外执行，避免长任务阻塞所有状态提交
    snap = state.snapshot()

    try:
        final_output = post_process(snap)
    except Exception as e:
        with state.lock:
            state.final_output = e
            state.phase = Phase.FAILED
            state.cond.notify_all()
        return

    with state.lock:
        state.final_output = final_output
        state.phase = Phase.DONE
        state.post_process_done = True
        state.cond.notify_all()


def run_batch(
    task_configs: List[dict],
    post_process: Callable[[Dict[str, Any]], Any],
    overall_timeout: Optional[float] = None,
) -> Any:
    """多线程 API 调用 + 串行后处理的统一入口。"""

    if not task_configs:
        raise ValueError("task_configs cannot be empty")

    if overall_timeout is None:
        overall_timeout = max(
            TIMEOUT_BY_MODEL.get(cfg["model"], 600) for cfg in task_configs
        ) + 30

    state = BatchState(
        task_ids=[cfg["task_id"] for cfg in task_configs],
        overall_timeout=overall_timeout,
    )

    # 启动唯一后处理线程
    runner = threading.Thread(
        target=post_process_runner,
        args=(state, post_process),
        daemon=True,
    )
    runner.start()

    # 启动 API 调用线程
    threads = []
    for cfg in task_configs:
        t = threading.Thread(
            target=api_worker,
            args=(cfg["task_id"], cfg, state),
            daemon=True,
        )
        t.start()
        threads.append(t)

    # 等待最终状态
    with state.cond:
        while state.phase not in (Phase.DONE, Phase.FAILED):
            remaining_wait = state.deadline + 60 - time.monotonic()
            if remaining_wait <= 0:
                raise TimeoutError("post-processing runner did not finish")
            state.cond.wait(remaining_wait)

    if state.phase == Phase.FAILED:
        if isinstance(state.final_output, Exception):
            raise state.final_output
        raise RuntimeError(state.final_output)

    return state.final_output
```

## 5. 示例后处理函数

后处理是“串行”的，天然只由 `post_process_runner` 一个线程执行。

```python
def example_post_process(snap: Dict[str, Any]) -> list:
    ordered = []

    # 按 task_ids 原始顺序输出，保证确定性
    for tid in snap["task_ids"]:
        if tid in snap["results"]:
            ordered.append({
                "task_id": tid,
                "content": snap["results"][tid],
            })
        else:
            ordered.append({
                "task_id": tid,
                "error": repr(snap["errors"].get(tid)),
            })

    return ordered
```

## 6. 验证清单

上线前必须做以下验证：

1. **并发压测**：100 个任务并发，部分任务人为延迟，断言 `remaining == 0` 时 `len(results) + len(errors) == total`。
2. **超时验证**：构造一个永不返回的任务，确认整体 deadline 后自动进入后处理，迟到响应被丢弃。
3. **后处理幂等验证**：确认 `post_process_started` 保证后处理只执行一次。
4. **代际验证**：调用 `reset()` 后，旧批次迟到响应不会写入新批次。
5. **空 content 验证**：B 模型若返回空 content，必须被记为错误，不能进入成功结果。
6. **代理验证**：确认 `urllib` 直连且 `ProxyHandler({})` 生效，无 `ProxyError`。

## 7. 避坑提醒

- **不要用 `threading.Barrier`**：一个 API 线程异常会让 Barrier 直接 broken，且无法处理超时后继续收口。
- **不要用 `requests`**：必须用 `urllib` 直连；如果历史包袱必须用 `requests`，调用时显式 `proxies=None`。
- **不要锁内做 API 调用**：否则多线程全部串行，方舟效能引擎会退化成单线程。
- **新增模型配置必须同步更新 `TIMEOUT_BY_MODEL` 和 `extract_content` 的兼容分支**，并在接入前单测 content 非空。

这套机制的本质是：**用锁保证状态迁移的原子性，用 Condition 保证等待的有界性，用 generation 保证时序的隔离性，用快照保证后处理的一致性。**
