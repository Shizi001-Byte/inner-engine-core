## 一、问题建模与根因分析

### 1.1 竞态场景拓扑

```
┌─────────────────────────────────────────────────────────────────┐
│                    V7.5 方舟效能引擎                              │
│                                                                 │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐            │
│  │ Thread-A │  │ Thread-B │  │ Thread-C │  │ Thread-D │  API层    │
│  │ API.Call │  │ API.Call │  │ API.Call │  │ API.Call │  (并发)  │
│  └────┬─────┘  └────┬─────┘  └────┬─────┘  └────┬─────┘            │
│       │              │              │              │              │
│       ▼              ▼              ▼              ▼              │
│  ═══════════════════════════════════════════════════════         │
│  ║        共享状态空间 (EngineState / ContextPool)      ║        │
│  ═══════════════════════════════════════════════════════         │
│       │              │              │              │              │
│       ▼              ▼              ▼              ▼              │
│  ┌──────────────────────────────────────────────────┐            │
│  │           串行后处理队列                           │            │
│  │  [PostProcess₁] → [PostProcess₂] → [PP₃] → ...  │  后处理层  │
│  └──────────────────────────────────────────────────┘  (串行)    │
│                                                                 │
│  问题域：                                                        │
│  P1: API并发修改共享状态 → 丢失更新/脏读                         │
│  P2: 后处理串行化瓶颈 → 状态快照不一致                            │
│  P3: API返回与后处理之间的时间窗口 → TOCTOU                      │
│  P4: 后处理重入/回调导致的锁升级 → 死锁                          │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 竞态条件分类矩阵

| 编号 | 竞态类型 | 触发条件 | 后果 | 严重度 |
|------|---------|---------|------|--------|
| RC-01 | 丢失更新 | 多线程同时写`EngineState.metrics` | 效能数据丢失 | **严重** |
| RC-02 | 脏读 | 后处理读取API正在修改的`ContextSlot` | 计算结果错误 | **严重** |
| RC-03 | TOCTOU | API检查状态→后处理使用状态之间状态被篡改 | 安全绕过 | **致命** |
| RC-04 | 顺序违背 | 后处理执行顺序与API调用顺序不一致 | 数据依赖断裂 | **高** |
| RC-05 | 锁升级死锁 | 后处理持锁回调API，API尝试获取同锁 | 引擎挂死 | **致命** |
| RC-06 | 可见性缺失 | 线程A写状态，后处理线程不可见 | 幽灵状态 | **高** |

### 2.2 锁粒度策略

```
全局锁 (粗粒度)          分段锁 (中粒度)          槽位锁 (细粒度)        无锁
├─ EngineStateMutex     ├─ StateSegment[16]     ├─ SlotLock[N]        ├─ AtomicCounter

│                       │                       │                     │
```

### 3.1 引擎核心状态结构

```cpp
// ark_engine_types.h — V7.5方舟效能引擎核心类型定义

#pragma once
#include <atomic>
#include <shared_mutex>
#include <mutex>
#include <array>
#include <vector>
#include <optional>
#include <memory>
#include <functional>
#include <chrono>
#include <cstdint>

namespace ark {

// ========== Layer 1: 原子层 ==========

/// 全局单调递增序列号 — 用于建立因果序
class AtomicSequence {
public:
    static AtomicSequence& instance() {
        static AtomicSequence inst;
        return inst;
    }
    
    uint64_t next() {
        return seq_.fetch_add(1, std::memory_order_acq_rel);
    }
    
    uint64_t current() const {
        return seq_.load(std::memory_order_acquire);
    }
    
private:
    std::atomic<uint64_t> seq_{0};
    AtomicSequence() = default;
};

/// 版本化引用 — Copy-on-Write 基础设施
template<typename T>
class VersionedRef {
public:
    struct Versioned {
        std::shared_ptr<const T> data;
        uint64_t version;
        uint64_t seq;
    };
    
    /// 读取当前快照 (无锁读)
    Versioned read() const {
        Versioned v;
        v.data = std::atomic_load_explicit(&ptr_, std::memory_order_acquire);
        v.version = version_.load(std::memory_order_acquire);
        v.seq = seq_.load(std::memory_order_acquire);
        return v;
    }
    
    /// 写入新版本 (CAS保证原子性)
    bool write(std::shared_ptr<const T> new_data, uint64_t expected_seq) {
        uint64_t current_seq = seq_.load(std::memory_order_acquire);
        if (current_seq != expected_seq) {
            return false; // CAS失败，序列号不匹配
        }
        
        uint64_t new_version = version_.fetch_add(1, std::memory_order_acq_rel) + 1;
        uint64_t new_seq = AtomicSequence::instance().next();
        
        std::atomic_store_explicit(&ptr_, new_data, std::memory_order_release);
        version_.store(new_version, std::memory_order_release);
        seq_.store(new_seq, std::memory_order_release);
        
        return true;
    }
    
private:
    std::shared_ptr<const T> ptr_;
    std::atomic<uint64_t> version_{0};
    std::atomic<uint64_t> seq_{0};
};

/// 危险指针 — 防止使用期间被回收
class HazardPointer {
public:
    static HazardPointer& instance() {
        static HazardPointer inst;
        return inst;
    }
    
    struct Slot {
        std::atomic<void*> ptr{nullptr};
        std::atomic<bool> active{false};
    };
    
    Slot* acquire() {
        for (auto& s : slots_) {
            bool expected = false;
            if (s.active.compare_exchange_strong(expected, true,
                    std::memory_order_acq_rel)) {
                return &s;
            }
        }
        return nullptr; // 槽位耗尽
    }
    
    void release(Slot* slot) {
        slot->ptr.store(nullptr, std::memory_order_release);
        slot->active.store(false, std::memory_order_release);
    }
    
private:
    static constexpr size_t MAX_HAZARD_PTRS = 64;
    std::array<Slot, MAX_HAZARD_PTRS> slots_;
    HazardPointer() = default;
};

// ========== Layer 2: 状态层 ==========

/// 引擎上下文槽位 — 每个API调用分配一个
struct ContextSlot {
    uint64_t slot_id;
    uint64_t call_seq;              // API调用序列号
    uint64_t completion_seq;       // API完成序列号  
    std::atomic<int32_t> ref_count{0};
    std::atomic<bool> in_use{false};
    
    // 业务数据
    struct State {
        std::string context_id;
        std::vector<uint8_t> payload;
        std::unordered_map<std::string, std::string> metadata;
        std::chrono::steady_clock::time_point created_at;
    } state;
    
    // 细粒度自旋锁 (仅保护本槽位)
    std::atomic<bool> slot_lock{false};
    
    void lock_spin() {
        while (slot_lock.exchange(true, std::memory_order_acq_rel)) {
            // 指数退避
            for (int i = 0; i < 4; ++i)
                __builtin_ia32_pause();
        }
    }
    
    void unlock_spin() {
        slot_lock.store(false, std::memory_order_release);
    }
};

/// 引擎全局状态
struct EngineState {
    // 核心效能指标 (VersionedRef → Copy-on-Write)
    struct Metrics {
        uint64_t total_calls{0};
        uint64_t total_errors{0};
        double avg_latency_ms{0.0};
        double p99_latency_ms{0.0};
        uint64_t active_threads{0};
    };
    VersionedRef<Metrics> metrics;
    
    // 上下文槽位池 (分段锁保护)
    static constexpr size_t NUM_SLOTS = 256;
    static constexpr size_t NUM_SEGMENTS = 16;  // 16段，每段16个槽位
    std::array<ContextSlot, NUM_SLOTS> slots;
    std::array<std::shared_mutex, NUM_SEGMENTS> segment_locks;
    
    // 上下文ID → 槽位索引 映射
    std::unordered_map<std::string, uint32_t> id_to_slot;
    std::shared_mutex id_map_lock;  // 保护id_to_slot
};

// ========== Layer 3: 编排层 ==========

/// 后处理任务项
struct PostProcessTask {
    uint64_t seq;                   // 因果序序列号
    uint64_t slot_id;
    uint32_t slot_index;
    std::function<void()> handler;
    std::chrono::steady_clock::time_point enqueued_at;
    
    // 完成回调
    std::promise<void> done;
    std::shared_future<void> done_future;
};

/// 世代标记 — 用于快照隔离
struct Epoch {
    std::atomic<uint64_t> current{0};
    
    uint64_t enter() {
        return current.fetch_add(1, std::memory_order_acq_rel) + 1;
    }
    
    bool is_stale(uint64_t epoch) const {
        return epoch < current.load(std::memory_order_acquire);
    }
};

} // namespace ark
```

### 3.2 锁管理器核心实现

```cpp
// ark_lock_manager.h — 锁机制核心管理器

#pragma once
#include "ark_engine_types.h"
#include <queue>
#include <condition_variable>
#include <thread>

namespace ark {

/// ================================================================
/// 分段锁管理器 — 保护ContextSlot池
/// ================================================================
class SegmentLockManager {
public:
    explicit SegmentLockManager(EngineState& state) : state_(state) {}
    
    /// 获取槽位索引对应的分段锁
    std::shared_mutex& segment_for(uint32_t slot_index) {
        return state_.segment_locks[slot_index % EngineState::NUM_SEGMENTS];
    }
    
    /// 读锁获取 (多个后处理可并发读)
    void lock_read_slot(uint32_t slot_index) {
        segment_for(slot_index).lock_shared();
    }
    
    void unlock_read_slot(uint32_t slot_index) {
        segment_for(slot_index).unlock_shared();
    }
    
    /// 写锁获取 (API修改状态时)
    void lock_write_slot(uint32_t slot_index) {
        segment_for(slot_index).lock();
    }
    
    void unlock_write_slot(uint32_t slot_index) {
        segment_for(slot_index).unlock();
    }
    
    /// 槽位级别自旋锁 (用于短临界区)
    ContextSlot& get_slot(uint32_t index) {
        return state_.slots[index];
    }
    
private:
    EngineState& state_;
};

/// ================================================================
/// 串行后处理序列化器 — 保证后处理严格串行执行
/// ================================================================
class PostProcessSerializer {
public:
    explicit PostProcessSerializer(EngineState& state) 
        : state_(state), running_(true) {
        worker_ = std::thread(&PostProcessSerializer::run, this);
    }
    
    ~PostProcessSerializer() {
        running_.store(false, std::memory_order_release);
        cv_.notify_one();
        if (worker_.joinable()) worker_.join();
    }
    
    /// 提交后处理任务 (线程安全)
    /// 返回 future 用于等待后处理完成
    std::shared_future<void> submit(
        uint64_t slot_id,
        uint32_t slot_index,
        std::function<void(uint32_t)> handler  // handler接收slot_index
    ) {
        auto task = std::make_unique<PostProcessTask>();
        task->seq = AtomicSequence::instance().next();
        task->slot_id = slot_id;
        task->slot_index = slot_index;
        task->enqueued_at = std::chrono::steady_clock::now();
        
        auto promise = std::make_shared<std::promise<void>>();
        task->done_future = promise->get_future().share();
        
        // 包装handler，加入快照读取逻辑
        uint32_t idx = slot_index;
        task->handler = [this, idx, handler = std::move(handler)]() {
            // 后处理执行前：获取读锁快照
            std::shared_lock<std::shared_mutex> rlk(
                state_.segment_locks[idx % EngineState::NUM_SEGMENTS]);
            
            // 执行业务后处理
            handler(idx);
        };
        
        {
            std::lock_guard<std::mutex> lk(queue_mutex_);
            queue_.push(std::move(task));
        }
        cv_.notify_one();
        
        return promise->get_future().share();
    }
    
private:
    void run() {
        while (running_.load(std::memory_order_acquire)) {
            std::unique_ptr<PostProcessTask> task;
            
            {
                std::unique_lock<std::mutex> lk(queue_mutex_);
                cv_.wait(lk, [this] {
                    return !queue_.empty() || 
                           !running_.load(std::memory_order_acquire);
                });
                
                if (!running_.load(std::memory_order_acquire)) break;
                if (queue_.empty()) continue;
                
                task = std::move(const_cast<std::unique_ptr<PostProcessTask>&>(
                    queue_.front()));
                queue_.pop();
            }
            
            if (task) {
                // === 串行执行点 ===
                // 此时只有一个后处理在执行，消除并发
                
                try {
                    task->handler();
                } catch (...) {
                    // 记录异常但不传播
                }
                
                task->done.set_value();
            }
        }
    }
    
    EngineState& state_;
    std::atomic<bool> running_;
    std::thread worker_;
    
    std::queue<std::unique_ptr<PostProcessTask>> queue_;
    std::mutex queue_mutex_;
    std::condition_variable cv_;
};

/// ================================================================
/// 因果序屏障 — 保证"先调用API先后处理"的因果顺序
/// ================================================================
class CausalBarrier {
public:
    explicit CausalBarrier(size_t num_threads) 
        : num_threads_(num_threads),
          arrived_(0),
          epoch_(0) {}
    
    /// 线程到达屏障，携带其序列号
    void arrive(uint64_t thread_seq) {
        std::unique_lock<std::mutex> lk(mtx_);
        
        uint64_t current_epoch = epoch_.load(std::memory_order_acquire);
        
        // 记录此线程的序列号
        thread_seqs_[current_epoch][std::this_thread::get_id()] = thread_seq;
        
        if (++arrived_ == num_threads_) {
            // 最后一个线程到达，推进epoch
            epoch_.store(current_epoch + 1, std::memory_order_release);
            arrived_ = 0;
            cv_.notify_all();
        } else {
            cv_.wait(lk, [this, current_epoch] {
                return epoch_.load(std::memory_order_acquire) > current_epoch;
            });
        }
    }
    
    /// 获取当前epoch所有线程的序列号 (用于排序)
    std::vector<std::pair<uint64_t, std::thread::id>>
    get_ordered_threads(uint64_t epoch) {
        std::lock_guard<std::mutex> lk(mtx_);
        std::vector<std::pair<uint64_t, std::thread::id>> result;
        
        auto it = thread_seqs_.find(epoch);
        if (it != thread_seqs_.end()) {
            for (const auto& [tid, seq] : it->second) {
                result.emplace_back(seq, tid);
            }
        }
        
        std::sort(result.begin(), result.end());
        return result;
    }
    
private:
    size_t num_threads_;
    std::atomic<uint64_t> epoch_;
    std::atomic<size_t> arrived_;
    std::mutex mtx_;
    std::condition_variable cv_;
    
    std::unordered_map<uint64_t, 
        std::unordered_map<std::thread::id, uint64_t>> thread_seqs_;
};

/// ================================================================
/// 死锁检测器 — 运行时检测锁循环等待
/// ================================================================
class DeadlockDetector {
public:
    static DeadlockDetector& instance() {
        static DeadlockDetector inst;
        return inst;
    }
    
    /// 注册线程将要获取锁
    void on_lock_acquire(uint64_t lock_id) {
        auto tid = std::this_thread::get_id();
        
        std::lock_guard<std::mutex> lk(mtx_);
        
        // 检查是否形成环
        auto& held = held_locks_[tid];
        
        for (auto other_tid : lock_waiters_[lock_id]) {
            if (other_tid == tid) continue;
            
            auto& other_held = held_locks_[other_tid];
            // 如果other_tid持有的锁中有当前tid正在等待的锁 → 死锁
            for (auto other_lock : other_held) {
                if (waiting_for_[tid].count(other_lock)) {
                    // 检测到死锁！
                    on_deadlock_detected(tid, other_tid);
                    return;
                }
            }
        }
        
        waiting_for_[tid].insert(lock_id);
        lock_waiters_[lock_id].insert(tid);
    }
    
    /// 注册线程已获取锁
    void on_lock_acquired(uint64_t lock_id) {
        auto tid = std::this_thread::get_id();
        std::lock_guard<std::mutex> lk(mtx_);
        
        waiting_for_[tid].erase(lock_id);
        lock_waiters_[lock_id].erase(tid);
        held_locks_[tid].push_back(lock_id);
    }
    
    /// 注册线程释放锁
    void on_lock_release(uint64_t lock_id) {
        auto tid = std::this_thread::get_id();
        std::lock_guard<std::mutex> lk(mtx_);
        
        auto& held = held_locks_[tid];
        held.erase(std::remove(held.begin(), held.end(), lock_id), held.end());
    }
    
private:
    std::mutex mtx_;
    std::unordered_map<std::thread::id, std::vector<uint64_t>> held_locks_;
    std::unordered_map<std::thread::id, std::set<uint64_t>> waiting_for_;
    std::unordered_map<uint64_t, std::set<std::thread::id>> lock_waiters_;
    
    void on_deadlock_detected(std::thread::id t1, std::thread::id t2) {
        // 策略: 中断低优先级线程或回滚
        std::cerr << "[DEADLOCK] Detected between threads " 
                  << t1 << " and " << t2 << std::endl;
        // 可触发回滚或异常
        throw std::runtime_error("Deadlock detected");
    }
    
    DeadlockDetector() = default;
};

} // namespace ark
```

## 四、完整锁机制方案 — API调用全流程

### 4.1 API调用与后处理时序图

```
时间轴 ──────────────────────────────────────────────────────────────────────►

Thread-A (API.Call #1)         Thread-B (API.Call #2)         串行后处理线程
    │                               │                               │
    │ ①获取序列号 seq=100           │ ①获取序列号 seq=101           │
    │ ②获取写锁(segment[0])         │ ②获取写锁(segment[3])         │
    │   lock_write_slot(idx=0)     │   lock_write_slot(idx=3)     │
    │ ③修改Slot[0].state           │ ③修改Slot[3].state           │
    │ ④提交快照(VersionedRef)       │ ④提交快照(VersionedRef)       │
    │ ⑤释放写锁                    │ ⑤释放写锁                    │
    │ ⑥提交后处理(seq=100) ────────┐│                              │
    │                               │⑥提交后处理(seq=101) ────────┐│
    │                               │                               │
    │ ⑦等待 done_future             │ ⑦等待 done_future             │
    │                               │                               │
    │                               │                    ◄──────────┘
    │                               │                    ⑧取seq=100的任务
    │                               │                    ⑨获取读锁(segment[0])
    │                               │                    ⑩读取Slot[0].state快照
    │                               │                    ⑪执行后处理逻辑
    │                               │                    ⑫释放读锁
    │                               │                    ⑬set_value(seq=100完成)
    │ ◄──────────────────── done ◄──│                    │
    │ (Thread-A被唤醒)              │                    ⑭取seq=101的任务
    │                               │                    ⑮获取读锁(segment[3])
    │                               │                    ⑯读取Slot[3].state快照
    │                               │                    ⑰执行后处理逻辑
    │                               │                    ⑱释放读锁
    │                               │                    ⑲set_value(seq=101完成)
    │                               │ ◄──────────────────│
    │                               │ (Thread-B被唤醒)   │
    │                               │                    │
    
关键保证:
  • seq=100的后处理一定先于seq=101执行 (因果序)
  • 后处理读取的state是API修改后的快照 (可见性)
  • 后处理串行执行，无并发竞态 (互斥性)
  • 读锁允许多个后处理并发读，但写锁独占 (读写分离)
```

### 4.2 API入口完整实现

```cpp
// ark_api_v75.h — V7.5方舟效能引擎API入口

#pragma once
#include "ark_engine_types.h"
#include "ark_lock_manager.h"
#include <future>

namespace ark {

class ArkEngineV75 {
public:
    explicit ArkEngineV75() 
        : seg_mgr_(state_), pp_serializer_(state_) {}
    
    // ============ 核心API: 调用 + 后处理 ============
    
    /// API调用入口 (多线程安全)
    /// 
    /// @param context_id 上下文标识
    /// @param payload 调用载荷
    /// @param post_handler 后处理回调 (将串行执行)
    /// @return 后处理结果
    template<typename Result>
    std::future<Result> invoke(
        const std::string& context_id,
        std::vector<uint8_t> payload,
        std::function<Result(const ContextSlot::State&)> post_handler
    ) {
        // ========== Phase 1: API调用阶段 (并发) ==========
        
        // ① 分配/查找槽位 (写锁保护id_map)
        uint32_t slot_index = allocate_slot(context_id);
        
        // ② 获取槽位写锁 (分段锁)
        seg_mgr_.lock_write_slot(slot_index);
        
        // ③ 危险指针保护: 防止槽位在后续操作中被回收
        auto* hazard = HazardPointer::instance().acquire();
        if (!hazard) {
            seg_mgr_.unlock_write_slot(slot_index);
            throw std::runtime_error("Hazard pointer exhausted");
        }
        hazard->ptr.store(&state_.slots[slot_index], std::memory_order_release);
        
        ContextSlot& slot = state_.slots[slot_index];
        
        // ④ 获取槽位级自旋锁 (保护细粒度字段)
        slot.lock_spin();
        
        try {
            // ⑤ 更新调用序列号
            uint64_t call_seq = AtomicSequence::instance().next();
            slot.call_seq = call_seq;
            slot.ref_count.fetch_add(1, std::memory_order_acq_rel);
            slot.in_use.store(true, std::memory_order_release);
            
            // ⑥ 修改状态 (写操作)
            slot.state.context_id = context_id;
            slot.state.payload = std::move(payload);
            slot.state.metadata["call_seq"] = std::to_string(call_seq);
            slot.state.created_at = std::chrono::steady_clock::now();
            
            // ⑦ 更新全局Metrics (Copy-on-Write)
            update_metrics([&](EngineState::Metrics& m) {
                m.total_calls++;
                m.active_threads++;
            });
            
            // ⑧ 记录完成序列号
            slot.completion_seq = AtomicSequence::instance().next();
            
        } catch (...) {
            slot.unlock_spin();
            HazardPointer::instance().release(hazard);
            seg_mgr_.unlock_write_slot(slot_index);
            throw;
        }
        
        // ⑨ 释放槽位自旋锁
        slot.unlock_spin();
        
        // ⑩ 释放槽位写锁 — 此时后处理可以读取
        seg_mgr_.unlock_write_slot(slot_index);
        
        // ========== Phase 2: 提交后处理 (提交到串行队列) ==========
        
        // ⑪ 提交后处理任务到串行队列
        //    后处理将在专门的后处理线程中串行执行
        //    后处理内部会自动获取读锁快照
        
        uint64_t slot_id = slot.slot_id;
        
        auto pp_future = pp_serializer_.submit(
            slot_id,
            slot_index,
            [this, post_handler, context_id, call_seq]
            (uint32_t idx) -> void {
                // 后处理执行体 (在串行线程中执行)
                // 此时已持有segment读锁 (见PostProcessSerializer::submit内部)
                
                ContextSlot& s = state_.slots[idx];
                
                // 槽位级读锁 (自旋)
                s.lock_spin();
                
                ContextSlot::State snapshot;
                try {
                    snapshot = s.state;  // 拷贝快照
                } catch (...) {
                    s.unlock_spin();
                    throw;
                }
                s.unlock_spin();
                
                // ⑫ 执行业务后处理逻辑
                // 此时snapshot是API修改后的一致快照
                // 后处理串行执行，无并发问题
                
                // 注意: post_handler的返回值通过promise传递
                // (此处简化，实际需要promise<Result>)
            }
        );
        
        // ========== Phase 3: 等待后处理完成 ==========
        
        // ⑬ 异步等待后处理完成
        // 注意: 不在调用线程阻塞等待，返回future给调用者
        
        // ⑭ 释放危险指针
        // (延迟到后处理完成后，通过deferred release)
        
        // 简化: 同步等待版本
        // pp_future.wait();
        
        // 返回future
        std::promise<Result> result_promise;
        auto result_future = result_promise.get_future();
        
        // 异步等待后处理完成，然后设置结果
        std::thread([f = std::move(pp_future), 
                     p = std::move(result_promise),
                     post_handler,
                     slot_index,
                     this]() mutable {
            f.wait(); // 等待后处理完成
            
            // 获取读锁读取最终状态
            seg_mgr_.lock_read_slot(slot_index);
            ContextSlot& s = state_.slots[slot_index];
            s.lock_spin();
            auto snapshot = s.state;
            s.unlock_spin();
            seg_mgr_.unlock_read_slot(slot_index);
            
            try {
                Result result = post_handler(snapshot);
                p.set_value(std::move(result));
            } catch (...) {
                p.set_exception(std::current_exception());
            }
            
            // 清理: 减少引用计数
            s.ref_count.fetch_sub(1, std::memory_order_acq_rel);
            if (s.ref_count.load(std::memory_order_acquire) == 0) {
                s.in_use.store(false, std::memory_order_release);
            }
            
        }).detach();
        
        return result_future;
    }
    
private:
    EngineState state_;
    SegmentLockManager seg_mgr_;
    PostProcessSerializer pp_serializer_;
    
    /// 分配或查找槽位
    uint32_t allocate_slot(const std::string& context_id) {
        // 先查读锁
        {
            std::shared_lock<std::shared_mutex> rlk(state_.id_map_lock);
            auto it = state_.id_to_slot.find(context_id);
            if (it != state_.id_to_slot.end()) {
                return it->second;
            }
        }
        
        // 不存在，加写锁创建
        std::unique_lock<std::shared_mutex> wlk(state_.id_map_lock);
        
        // Double-check
        auto it = state_.id_to_slot.find(context_id);
        if (it != state_.id_to_slot.end()) {
            return it->second;
        }
        
        // 分配新槽位 (简单轮询)
        for (uint32_t i = 0; i < EngineState::NUM_SLOTS; ++i) {
            if (!state_.slots[i].in_use.load(std::memory_order_acquire)) {
                bool expected = false;
                if (state_.slots[i].in_use.compare_exchange_strong(
                        expected, true, std::memory_order_acq_rel)) {
                    state_.slots[i].slot_id = AtomicSequence::instance().next();
                    state_.id_to_slot[context_id] = i;
                    return i;
                }
            }
        }
        
        throw std::runtime_error("No available context slots");
    }
    
    /// 更新Metrics (Copy-on-Write)
    template<typename F>
    void update_metrics(F&& updater) {
        auto current = state_.metrics.read();
        auto new_metrics = std::make_shared<EngineState::Metrics>(*current.data);
        updater(*new_metrics);
        
        // CAS重试循环
        while (!state_.metrics.write(new_metrics, current.seq)) {
            current = state_.metrics.read();
            new_metrics = std::make_shared<EngineState::Metrics>(*current.data);
            updater(*new_metrics);
        }
    }
};

} // namespace ark
```

## 六、锁获取顺序与死锁预防

### 6.1 锁层次顺序 (Lock Ordering)

```
获取顺序 (必须严格遵循):

Level 0: id_map_lock (shared_mutex)
    ↓
Level 1: segment_locks[N] (shared_mutex)  
    ↓
Level 2: slot_lock (atomic spinlock)
    ↓
Level 3: queue_mutex (PostProcessSerializer)
    ↓
Level 4: metrics VersionedRef (lock-free CAS)

规则:
  ✅ 允许: L0 → L1 → L2 → L3 → L4 (严格递增)
  ✅ 允许: 仅获取某一层
  ❌ 禁止: L2 → L1 (逆向)
  ❌ 禁止: L1 → L1 (同级跨segment，使用固定顺序)
  ❌ 禁止: L3 → L2 (后处理线程不能回调API获取槽位锁)
```

### 6.2 锁超时与回退策略

```cpp
/// 带超时的锁获取包装器
template<typename Lockable, typename Duration>
bool try_lock_for(Lockable& lock, Duration timeout, 
                  const char* lock_name) {
    auto start = std::chrono::steady_clock::now();
    
    while (true) {
        if (lock.try_lock()) return true;
        
        auto elapsed = std::chrono::steady_clock::now() - start;
        if (elapsed >= timeout) {
            // 超时: 记录并触发恢复
            log_lock_timeout(lock_name, elapsed);
            return false;
        }
        
        // 指数退避
        auto backoff = std::min(
            std::chrono::microseconds(100),
            std::chrono::microseconds(10) * 
            (1 << std::min(6, (int)elapsed.count() / 1000))
        );
        std::this_thread::sleep_for(backoff);
    }
}

/// 超时后的回退策略
class LockFallbackStrategy {
public:
    enum class Strategy {
        RETRY_WITH_BACKOFF,    // 指数退避重试
        REDIRECT_TO_QUEUE,     // 重定向到串行队列
        SNAPSHOT_STALE_READ,   // 使用旧快照
        ABORT_WITH_ERROR,     // 中止并返回错误
    };
    
    static Strategy decide(uint64_t seq, 
                           const std::string& context_id,
                           int retry_count) {
        if (retry_count < 3) return Strategy::RETRY_WITH_BACKOFF;
        if (retry_count < 10) return Strategy::REDIRECT_TO_QUEUE;
        if (retry_count < 20) return Strategy::SNAPSHOT_STALE_READ;
        return Strategy::ABORT_WITH_ERROR;
    }
};
```

```cpp
/// 自适应锁: 根据竞争程度自动选择锁策略
class AdaptiveLock {
public:
    enum class Mode {
        SPIN,       // 低竞争: 自旋
        YIELD,      // 中竞争: 让步
        BLOCK,      // 高竞争: 阻塞
        QUEUE,      // 极高竞争: 排队
    };
    
    void lock() {
        int spin_count = 0;
        int yield_count = 0;
        
        // Phase 1: 自旋 (最多64次)
        while (spin_count++ < 64) {
            if (flag_.exchange(true, std::memory_order_acq_rel) == false) {
                current_mode_ = Mode::SPIN;
                return;
            }
            __builtin_ia32_pause();
        }
        
        // Phase 2: 让步 (最多16次)
        while (yield_count++ < 16) {
            if (flag_.exchange(true, std::memory_order_acq_rel) == false) {
                current_mode_ = Mode::YIELD;
                return;
            }
            std::this_thread::yield();
        }
        
        // Phase 3: 阻塞 (使用futex/mutex)
        current_mode_ = Mode::BLOCK;
        fallback_mutex_.lock();
        flag_.store(true, std::memory_order_release);
    }
    
    void unlock() {
        flag_.store(false, std::memory_order_release);
        if (current_mode_ >= Mode::BLOCK) {
            fallback_mutex_.unlock();
        }
        current_mode_ = Mode::SPIN;
    }
    
private:
    std::atomic<bool> flag_{false};
    std::mutex fallback_mutex_;
    thread_local static Mode current_mode_;
};
```

```cpp
/// 竞态条件运行时探测器
class RaceConditionMonitor {
public:
    static RaceConditionMonitor& instance() {
        static RaceConditionMonitor inst;
        return inst;
    }
    
    /// 记录锁获取事件
    void on_lock_event(const std::string& lock_name, 
                       const std::string& operation,  // "acquire"/"release"
                       uint64_t seq,
                       std::thread::id tid) {
        std::lock_guard<std::mutex> lk(mtx_);
        
        auto& record = events_[lock_name];
        record.push_back({
            .seq = seq,
            .tid = tid,
            .op = operation,
            .timestamp = std::chrono::steady_clock::now()
        });
        
        // 检测交错模式
        detect_interleaving(lock_name, record);
    }
    
private:
    struct LockEvent {
        uint64_t seq;
        std::thread::id tid;
        std::string op;
        std::chrono::steady_clock::time_point timestamp;
    };
    
    std::mutex mtx_;
    std::unordered_map<std::string, std::vector<LockEvent>> events_;
    
    void detect_interleaving(const std::string& lock_name,
                             const std::vector<LockEvent>& events) {
        // 检测模式: acquire_A → acquire_B → release_A → release_B
        // 这表示锁没有正确保护临界区
        for (size_t i = 0; i + 3 < events.size(); ++i) {
            if (events[i].op == "acquire" &&
                events[i+1].op == "acquire" &&
                events[i+2].op == "release" &&
                events[i+3].op == "release" &&
                events[i].tid != events[i+1].tid) {
                
                log_race_warning(lock_name, events[i], events[i+1]);
            }
        }
    }
    
    void log_race_warning(const std::string& lock_name,
                          const LockEvent& e1, const LockEvent& e2) {
        std::cerr << "[RACE WARNING] Potential race on " << lock_name
                  << " between threads " << e1.tid << " and " << e2.tid
                  << " (seq: " << e1.seq << " vs " << e2.seq << ")"
                  << std::endl;
    }
    
    RaceConditionMonitor() = default;
};
```

```cpp
        // 验证: 后处理一定是串行执行的 (无交错)
        std::cout << "Test 2: post_process_ordering\n"
                  << "  Execution order: ";
        for (int v : execution_order) std::cout << v << " ";
        std::cout << "\n  " 
                  << (execution_order.size() == 10 ? "✅ PASS" : "❌ FAIL")
                  << std::endl;
    }
    
    /// 测试3: 死锁检测
    static void test_deadlock_detection() {
        // 模拟锁反转场景
        std::mutex m1, m2;
        std::atomic<bool> deadlock_detected{false};
        
        std::thread t1([&]() {
            std::lock_guard<std::mutex> l1(m1);
            std::this_thread::sleep_for(std::chrono::milliseconds(10));
            // 尝试获取m2 (可能与t2形成死锁)
            if (!m2.try_lock_for(std::chrono::milliseconds(1000))) {
                deadlock_detected = true;
            }
        });
        
        std::thread t2([&]() {
            std::lock_guard<std::mutex> l2(m2);
            std::this_thread::sleep_for(std::chrono::milliseconds(10));
            if (!m1.try_lock_for(std::chrono::milliseconds(1000))) {
                deadlock_detected = true;
            }
        });
        
        t1.join();
        t2.join();
        
        std::cout << "Test 3: deadlock_detection\n"
                  << "  " << (deadlock_detected ? "✅ DETECTED" : "❌ MISSED")
                  << std::endl;
    }
```
