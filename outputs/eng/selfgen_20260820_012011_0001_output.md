# 任务类型: eng

# 任务池动态扩充机制设计（V7.5方舟效能引擎扩展）

## 一、核心矛盾再锚定

基于已验证认知锚定，本机制在"多线程API调用 → 串行后处理"架构下必须直面：
- **时间维度错配（覆写突变）**：新模板注入与旧任务消费并发，晚到达的A模型旧状态可能覆盖新模板写入的新状态
- **状态差异契约缺失**：高熵信息流进入串行收敛通道时无版本仲裁机制
- **三段失效链路**：任何新增配置必须同步走完"状态写入 → 执行读取 → 生效验证"，缺一即静默失效（对齐坑#1）

因此本机制的设计核心不是"如何生成新模板"，而是**"如何在高并发串行收敛通道中安全地写入新模板且可被验证"**。

---

## 二、机制总体架构

四层闭环：

```
[检测层] 重复率动态采样
    ↓ 阈值触发
[决策层] 新任务模板生成（强制引用认知池近30min新认知）
    ↓ 携带状态差异契约
[注入层] 生物稳态调控锁 + 三点同步写入
    ↓ 采样验证
[验证层] 效能回收 → 进化压力 → 沉淀为新认知
    ↑___________________________|
```

---

## 三、检测层：重复率动态采样

### 3.1 双窗口冗余采样
- **快窗 N=20**：敏感窗口，用于L2/L3快速触发
- **慢窗 N=100**：稳态窗口，用于趋势判断与误触发抑制
- 触发条件：快窗超阈值 **且** 慢窗接近阈值（双确认，避免瞬时抖动误触发）

### 3.2 三阶指纹判定（AND逻辑）
| 阶 | 指纹类型 | 算法 | 判同阈值 |
|----|---------|------|---------|
| 1 | 结构指纹 | FNV-1a 64位（模板ID+参数槽位哈希） | 完全相同 |
| 2 | 语义指纹 | SimHash 128位 | 海明距离≤3 |
| 3 | 认知指纹 | 注入认知ID集合 Jaccard系数 | ≥0.7 |

三阶全中 → 判定重复。任一不中 → 视为新型任务，不计入重复率。

### 3.3 阈值分层动作表
| 层级 | 重复率区间 | 动作 |
|------|-----------|------|
| L0 正常 | <20% | 无操作 |
| L1 预警 | 20%-35% | 标记 + 强制刷新认知缓存（对齐坑#3） |
| L2 触发 | 35%-50% | 生成1个新模板并注入 |
| L3 紧急 | >50% | 生成2-3个模板 + 降并发50% + 紧急认知注入 |

## 四、决策层：新任务模板生成

### 4.1 生成源强制约束（对齐坑#3）
- 模板生成必须引用**至少1条近30分钟内**进入认知池的新认知
- 每10任务或每转结束刷新认知缓存，确保生成源是最新的
- 若认知池无30min内新认知 → 触发认知反哺先于模板生成

### 4.2 变异策略（Hox基因式，对应锚定#3的三种功能错配）
| 变异类型 | 对应错配 | 操作 |
|---------|---------|------|
| 时间维度变异 | 覆写突变 | 调整timeout参数槽（A↔B模型切换） |
| 结构维度变异 | 功能错配 | 参数槽位重组（如reasoning检测位前移/跳过） |
| 认知维度变异 | 调度失效 | 注入不同认知子集，改变任务语义熵 |

### 4.3 模型分工与质量检测（对齐坑#2 + 历史坑）
| 阶段 | 模型 | timeout | 检测规则 |
|------|------|---------|---------|
| 模板生成 | B模型turbo | 300s | 跳过reasoning占比检测，仅检结构完整性 |
| 模板验证 | A模型 | 600s | reasoning占比30-70%为正常区间 |

## 五、注入层：状态差异契约（解决锚定#1的核心）

### 5.1 状态差异契约结构

每个新模板注入串行收敛通道时**必须携带**：

```yaml
template_id: T-{parent_id}-v{version}
causal_clock: {lamport_ts, node_id}        # 因果时钟，仲裁覆写突变
parent_id: T-{parent_id}                    # 血缘追溯
diff_signature:                            # 差异签名
  changed_slots: [slot_a, slot_b]
  reason: "L2重复率触发，认知#1742注入"
expected_state:                            # 期望状态三元组（坑#1核心）
  concurrency: 8
  weight: 0.35
  cooldown: 120s
generation_source:                         # 认知溯源
  cognition_ids: [1742, 1689]
  cognition_age: "12min"                   # 必须<30min
```

### 5.2 生物稳态调控锁（对应锚定#2）

**快速调控（神经递质级，ms-s）—— 解决覆写突变**：
- 乐观并发控制：写入前比对 `causal_clock`，旧时钟直接拒绝
- 局部槽位锁：仅锁定被变异的参数槽，不阻塞全池

**慢速调控（激素级，转-转）—— 解决稳态偏移**：
- 每转结束校验任务池稳态：模板存活率、重复率趋势
- 负反馈抑制：当注入模板效能 < 基线时，抑制同源变异生成

### 5.3 三点同步写入（对齐坑#1，缺一不可）

新模板生成后**强制同步修改三个点**，并在注入后**立即验证**：

| 点 | 操作 | 验证方式 |
|----|------|---------|
| ① 状态写入点 | 任务池状态管理器写入模板定义 + expected_state三元组 | 写入后回读校验 |
| ② 执行读取点 | 调度器缓存失效 + 主动推送新模板到调度队列 | 下一调度周期确认新模板被取出 |
| ③ 生效验证点 | 注入后立即采样3-5个执行 | 校验三元组（并发/权重/冷却）确实变化 |

**若三点中任一点验证失败 → 回滚注入 + 告警 + 沉淀为反模式认知。**

## 六、验证层：进化压力闭环

### 6.1 效能跟踪指标
- **重复率回落**：注入后2个采样窗口内重复率应回落至L1以下
- **调度命中率**：新模板被实际调度次数 / 注入次数
- **质量独立判定**：A/B模型分别用各自规则判定（对齐坑#2）

### 6.2 模板生命周期
| 状态 | 条件 | 动作 |
|------|------|------|
| 存活 | 被调度≥3次/10任务窗口 | 保留 |
| 休眠 | 连续2窗口未被调度 | 标记休眠，不删除 |
| 变异 | 被调度但重复率反弹 | 触发二次变异 |
| 淘汰 | 休眠后2转仍未唤醒 | 移除 + 沉淀反模式认知 |

### 6.3 认知回路（反向闭环）
- 模板生成成功并存活 → 沉淀为正向认知条目（含diff_signature）
- 模板淘汰 → 沉淀为反模式认知条目（负向锚定，避免重复变异）
- 反模式认知进入认知池后，30min内参与下一轮模板生成的"避坑约束"

## 七、坑库对齐清单

| 坑 | 现象 | 本机制对应措施 |
|----|------|----------------|
| 坑#1 自动调参全链路失效 | 配置变化但并发/权重/冷却实际未变 | §5.3 三点同步 + 注入后立即采样验证三元组 |
| 坑#2 废稿检测误杀B模型 | B模型reasoning占比70-82%被判废 | §4.3 B模型turbo跳过reasoning占比检测 |
| 坑#3 认知池只进不出 | 1700+条认知变静态档案 | §4.1 强制引用30min内新认知 + 10任务/转刷新 |
| 历史坑 配置改后未生效 | 行为无变化 | §5.3 第③点生效验证 + 回读校验 |
| 历史坑 API超时 | 任务未在规定时间返回 | §4.3 B模型300s / A模型600s 分模型timeout |

**设计核心总结**：本机制的关键不在"生成新模板"本身，而在**通过状态差异契约 + 生物稳态调控锁 + 三点同步验证**，确保新模板在高并发串行收敛通道中安全写入且可被验证生效——这正是对锚定#1"状态差异契约缺失"核心矛盾的直接回应。
