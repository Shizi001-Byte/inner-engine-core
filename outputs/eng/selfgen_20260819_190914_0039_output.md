# L4成品转化补全方案（code/checklist类型）

## 一、问题定位

```
L4Transformer.transform()
    ├── product_type == 'sop'    ✅ 已实现 _transform_sop()
    ├── product_type == 'code'   ❌ 走入 fallback / raise
    └── product_type == 'checklist' ❌ 走入 fallback / raise
```

根因：转化器注册表 + 类型路由 + 配置读取三处只挂了 `sop`，code/checklist 的转化函数和归档目录均缺失。

---

## 二、代码修改点（共5处）

### 修改点1：转化器注册表 — 新增两个类型映射

```python
# 文件：engine/archive/l4_transformer.py

class L4ProductTransformer:
    def __init__(self, config):
        self.config = config
        # ── 修改前 ──
        # self._transformers = {'sop': self._transform_sop}
        
        # ── 修改后 ──
        self._transformers = {
            'sop':       self._transform_sop,
            'code':      self._transform_code,       # 新增
            'checklist': self._transform_checklist,  # 新增
        }
```

### 修改点2：路由分发 — 确保新类型能进入对应分支

```python
    def transform(self, product_data: dict, product_type: str) -> dict:
        # ── 修改前 ──
        # if product_type == 'sop':
        #     return self._transform_sop(product_data)
        # raise ValueError(f"Unsupported type: {product_type}")
        
        # ── 修改后 ──
        transformer = self._transformers.get(product_type)
        if transformer is None:
            raise ValueError(
                f"Unsupported product_type='{product_type}', "
                f"supported={list(self._transformers.keys())}"
            )
        return transformer(product_data)
```

### 修改点3：新增 `_transform_code()` — code类型转化逻辑

```python
    def _transform_code(self, data: dict) -> dict:
        """将引擎产出转化为可归档的code成品"""
        return {
            'type':         'code',
            'title':        data.get('title', '未命名代码片段'),
            'language':     data.get('language', 'python'),
            'content':      data.get('content', ''),
            'description':  data.get('description', ''),
            'tags':         self._normalize_tags(data.get('tags', [])),
            'archive_path': f"l4/code/{data.get('id', 'unknown')}.md",
            'created_at':   data.get('timestamp'),
        }
```

### 修改点4：新增 `_transform_checklist()` — checklist类型转化逻辑

```python
    def _transform_checklist(self, data: dict) -> dict:
        """将引擎产出转化为可归档的checklist成品"""
        raw_items = data.get('items', [])
        return {
            'type':         'checklist',
            'title':        data.get('title', '未命名检查清单'),
            'items': [
                {
                    'text':     item.get('text', ''),
                    'checked':  item.get('checked', False),
                    'priority': item.get('priority', 'normal'),
                }
                for item in raw_items
            ],
            'tags':         self._normalize_tags(data.get('tags', [])),
            'archive_path': f"l4/checklist/{data.get('id', 'unknown')}.md",
            'created_at':   data.get('timestamp'),
        }
```

### 修改点5：配置同步 — 读取点与注册表对齐

```yaml
# 文件：config/archive_config.yaml
l4_transformer:
  supported_types:
    - sop
    - code        # 新增
    - checklist    # 新增
  archive_dirs:
    sop:       "l4/sop/"
    code:      "l4/code/"        # 新增
    checklist: "l4/checklist/"    # 新增
  # 防超时：各类型独立timeout（秒）
  timeout_map:
    sop:       300
    code:      300
    checklist: 300
```

```python
# 文件：engine/archive/l4_transformer.py — __init__中同步读取

    def __init__(self, config):
        self.config = config
        self._transformers = {
            'sop':       self._transform_sop,
            'code':      self._transform_code,
            'checklist': self._transform_checklist,
        }
        # 修改点5：从配置同步supported_types，防止配置改了代码没改
        cfg_types = self.config.get('l4_transformer.supported_types', [])
        for t in cfg_types:
            if t not in self._transformers:
                raise ConfigMismatchError(
                    f"Config declares type '{t}' but no transformer registered. "
                    f"Check _transformers mapping in L4ProductTransformer."
                )
```

> **防配置失效**：启动时校验配置声明类型与代码注册类型一致，不一致直接报错，不留静默缺口。

## 三、辅助函数（两处类型复用）

```python
    def _normalize_tags(self, tags) -> list:
        """统一tags格式：str → list[str]，去空去重"""
        if isinstance(tags, str):
            tags = [t.strip() for t in tags.split(',') if t.strip()]
        elif not isinstance(tags, list):
            tags = []
        return list(dict.fromkeys(tags))  # 保序去重
```


```
修改点4 _transform_checklist()       → checklist转化实现
```
