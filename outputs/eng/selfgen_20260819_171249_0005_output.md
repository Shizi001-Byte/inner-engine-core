# 任务类型: eng

下面直接基于你已验证的 **Guardian-Core 双进程、WAL+Snapshot、单向同步、幂等优先** 这组锚定推演，不再重复论证底层自恢复、WAL/Snapshot 基础，只落地“引擎内部心跳检测 + 状态原子持久化 + 崩溃后断点续跑”的完整代码架构。

---

## 1. 总体架构

```
┌─────────────────────────────────────────────────────┐
│                      Engine                          │
│                                                     │
│   ┌──────────────┐    heartbeat files     ┌──────────────┐
│   │  Guardian     │ ◄────────────────────► │     Core      │
│   │               │                        │              │
│   │  - 监控 Core  │                        │  - 执行 ChainTask
│   │  - Core 死则  │                        │  - 唯一 WAL 写者
│   │    拉起新 Core │                        │  - 周期打 Snapshot
│   │               │                        │  - Guardian 死则
│   └──────────────┘                        │    拉起新 Guardian
│                                            └──────────────┘
│                                                     │
│   run/                                            WAL+Snapshot
│   ├── core.hb                                      run/wal.log
│   ├── guardian.hb                                  run/snapshot/snapshot-<seq>.json
│   ├── core.lock
│   └── guardian.lock
└─────────────────────────────────────────────────────┘
```

核心思路：

- **Core** 是唯一状态写入者，所有任务状态变更先追加 WAL，再更新内存态。
- **Guardian** 只负责监控 Core、重启 Core；不写业务状态，避免双写 WAL。
- **Guardian 和 Core 互发心跳文件**。任何一方发现对方心跳超时，先 kill 旧进程，再拉起新进程。
- **双进程同时崩溃时**，下次启动入口直接走“恢复流程”：加载最新 Snapshot + 重放 WAL，把未完成任务从断点续跑。

---

## 2. 关键设计

### 2.1 心跳检测：文件心跳 + 文件锁 fencing

不依赖外部守护进程，使用本地 `run/*.hb` 心跳文件：

- 每个进程每秒更新自己的心跳文件：`{pid, ts, role, epoch}`
- 对方进程检查心跳文件：
  - 心跳文件不存在 → 对方已死
  - 心跳文件 mtime 超过阈值 → 对方可能卡死
  - 心跳文件中的 pid 已不存在 → 对方已死
- 在拉起新进程前，先 `kill -9` 旧 pid，再等对应 `.lock` 释放，防止双 Core / 双 Guardian 脑裂。

### 2.2 状态原子持久化：WAL + Snapshot

WAL 记录格式：

```json
{
  "seq": 123,
  "ts": 1700000000.123,
  "op": "NODE_DONE",
  "payload": {
    "task_id": "task_001",
    "node_id": "node_2",
    "output": {}
  },
  "checksum": "sha256..."
}
```

原子性保证：

- WAL 使用 `长度前缀 + JSON + fsync` 追加写入。
- 启动重放时，如果尾部记录不完整，说明是崩溃瞬间的半条记录，丢弃。
- Snapshot 使用 `tmp 文件 + fsync + rename` 原子替换。
- Snapshot 完成后，重置 WAL，保证 WAL 不会无限增长。

### 2.3 断点续跑：任务级 + API 调用级

断点不是“内存变量”，而是“最后一个已 fsync 的 WAL seq”。

恢复流程：

1. 加载最新 Snapshot。
2. 重放 WAL 中 `seq > snapshot.last_seq` 的记录。
3. 把所有 `RUNNING` 任务标记为 `RECOVERING`。
4. 按拓扑序找第一个未完成的节点。
5. 如果该节点已有 `API_CALL_DONE`，直接复用 API 响应，继续后续处理。
6. 如果只有 `API_CALL_START`，用同一个 `idempotency_key` 重放请求，避免重复下单/重复生成。

```python
# config.py
import os
import time
import yaml
import logging

logger = logging.getLogger("engine")


class TimeoutPolicy:
    def __init__(self, data):
        self.default_seconds = data.get("default_seconds", 300)
        self.model_timeouts = data.get("model_timeouts", {})

    def for_model(self, model: str) -> int:
        return self.model_timeouts.get(model, self.default_seconds)


class QualityPolicy:
    def __init__(self, data):
        # 不同模型独立质量规则
        self.rules = data.get("rules", {})

    def for_model(self, model: str):
        return self.rules.get(model, {})


class RuntimeConfig:
    """唯一配置读取点。

    所有业务代码禁止直接读散落常量，必须从 RuntimeConfig 读取。
    配置文件变更后，调用 check_reload() 即可热生效。
    """

    _instance = None

    def __init__(self, path):
        self.path = path
        self.timeout_policy = TimeoutPolicy({})
        self.quality_policy = QualityPolicy({})
        self._last_mtime = None
        self.reload()

    @classmethod
    def instance(cls):
        return cls._instance

    def reload(self):
        with open(self.path, "r", encoding="utf-8") as f:
            raw = yaml.safe_load(f)

        self.timeout_policy = TimeoutPolicy(raw.get("timeout_policy", {}))
        self.quality_policy = QualityPolicy(raw.get("quality_policy", {}))
        self._last_mtime = os.path.getmtime(self.path)

        logger.info(
            "config reloaded, timeout=%s",
            self.timeout_policy.model_timeouts,
        )

    def check_reload(self):
        try:
            if os.path.getmtime(self.path) != self._last_mtime:
                self.reload()
        except FileNotFoundError:
            pass
```

```python
# heartbeat.py
import json
import os
import time
import signal


def pid_alive(pid: int) -> bool:
    if not pid:
        return False
    try:
        os.kill(pid, 0)
        return True
    except ProcessLookupError:
        return False
    except PermissionError:
        return True


def kill_process(pid: int):
    if not pid or pid == os.getpid():
        return
    try:
        os.kill(pid, signal.SIGKILL)
    except ProcessLookupError:
        return

    deadline = time.time() + 5
    while time.time() < deadline:
        try:
            os.kill(pid, 0)
            time.sleep(0.1)
        except ProcessLookupError:
            return


class HeartbeatFile:
    def __init__(self, path: str, role: str, epoch: int = 0):
        self.path = path
        self.role = role
        self.epoch = epoch
        self.pid = os.getpid()
        self.started_ts = time.time()

    def beat(self):
        data = {
            "pid": self.pid,
            "role": self.role,
            "epoch": self.epoch,
            "ts": time.time(),
            "started_ts": self.started_ts,
        }
        tmp = f"{self.path}.tmp"
        with open(tmp, "w", encoding="utf-8") as f:
            json.dump(data, f)
            f.flush()
            os.fsync(f.fileno())
        os.replace(tmp, self.path)

    def read(self):
        try:
            with open(self.path, "r", encoding="utf-8") as f:
                return json.load(f)
        except Exception:
            return None

    def is_alive(self, timeout: float = 3.0) -> bool:
        data = self.read()
        if not data:
            return False
        if data["pid"] == self.pid:
            return True
        if time.time() - data["ts"] > timeout:
            return False
        return pid_alive(data["pid"])
```

### 3.4 WAL + Snapshot

```python
# state.py
import os
import json
import glob
import time
import struct
import hashlib
import threading
import fcntl
import logging

logger = logging.getLogger("engine.state")


def make_checksum(record: dict) -> str:
    raw = json.dumps(record, sort_keys=True, ensure_ascii=False).encode("utf-8")
    return hashlib.sha256(raw).hexdigest()


class Wal:
    def __init__(self, path: str):
        self.path = path
        self.lock = threading.Lock()
        self.f = open(path, "a+b", buffering=0)

    def append(self, record: dict):
        record["checksum"] = make_checksum(record)
        data = json.dumps(record, sort_keys=True, ensure_ascii=False).encode("utf-8")
        body = struct.pack(">I", len(data)) + data

        with self.lock:
            fcntl.flock(self.f, fcntl.LOCK_EX)
            try:
                self.f.write(body)
                self.f.flush()
                os.fsync(self.f.fileno())
            finally:
                fcntl.flock(self.f, fcntl.LOCK_UN)

    def replay(self, after_seq: int = 0):
        self.f.seek(0)
        out = []

        while True:
            head = self.f.read(4)
            if len(head) < 4:
                break

            (length,) = struct.unpack(">I", head)
            data = self.f.read(length)

            # 崩溃瞬间可能只写了一半，丢弃尾部
            if len(data) < length:
                logger.warning("wal tail partial, stop replay")
                break

            rec = json.loads(data)
            if rec.get("seq", 0) > after_seq:
                out.append(rec)

        return out

    def close(self):
        self.f.close()

    def reset_after_snapshot(self):
        self.close()
        backup = f"{self.path}.{int(time.time() * 1000)}.bak"
        os.replace(self.path, backup)
        self.f = open(self.path, "a+b", buffering=0)


class StateStore:
    def __init__(self, wal_path: str, snapshot_dir: str):
        self.wal_path = wal_path
        self.snapshot_dir = snapshot_dir
        os.makedirs(snapshot_dir, exist_ok=True)

        self._lock = threading.RLock()
        self.state = self._load()
        self.wal = Wal(wal_path)

    def _latest_snapshot(self):
        files = glob.glob(os.path.join(self.snapshot_dir, "snapshot-*.json"))
        if not files:
            return None
        return max(
            files,
            key=lambda p: int(os.path.basename(p).split("-")[-1].split(".")[0]),
        )

    def _load(self):
        snap = self._latest_snapshot()

        if snap:
            with open(snap, "r", encoding="utf-8") as f:
                data = json.load(f)
            state = data["state"]
            state["last_seq"] = data["last_seq"]
        else:
            state = {
                "last_seq": 0,
                "tasks": {},
                "api_calls": {},
            }

        if os.path.exists(self.wal_path):
            wal = Wal(self.wal_path)
            for rec in wal.replay(after_seq=state["last_seq"]):
                self._apply(state, rec)
            wal.close()

        return state

    def append(self, op: str, **payload):
        with self._lock:
            seq = self.state["last_seq"] + 1
            rec = {
                "seq": seq,
                "ts": time.time(),
                "op": op,
                "payload": payload,
            }
            self.wal.append(rec)
            self._apply(self.state, rec)
            self.state["last_seq"] = seq
            return seq

    def _apply(self, state: dict, rec: dict):
        op = rec["op"]
        p = rec["payload"]

        if op == "TASK_CREATED":
            state["tasks"][p["task_id"]] = p["task"]

        elif op == "NODE_START":
            node = state["tasks"][p["task_id"]]["nodes"][p["node_id"]]
            node.update(
                status="RUNNING",
                attempt=p["attempt"],
                idem_key=p["idem_key"],
            )

        elif op == "API_CALL_START":
            state["api_calls"].setdefault(
                p["idem_key"],
                {"status": "STARTED", "response": None},
            )

        elif op == "API_CALL_DONE":
            state["api_calls"][p["idem_key"]] = {
                "status": "DONE",
                "response": p["response"],
            }

        elif op == "NODE_DONE":
            node = state["tasks"][p["task_id"]]["nodes"][p["node_id"]]
            node.update(status="COMPLETED", output=p["output"])

        elif op == "NODE_FAILED":
            node = state["tasks"][p["task_id"]]["nodes"][p["node_id"]]
            node.update(status="FAILED", error=p.get("error"))

        elif op == "TASK_COMPLETED":
            state["tasks"][p["task_id"]]["status"] = "COMPLETED"

        elif op == "TASK_FAILED":
            state["tasks"][p["task_id"]]["status"] = "FAILED"

    def snapshot(self):
        with self._lock:
            state_copy = json.loads(json.dumps(self.state))
            last_seq = self.state["last_seq"]

            tmp = os.path.join(
                self.snapshot_dir,
                f"snapshot-{last_seq}.tmp",
            )
            with open(tmp, "w", encoding="utf-8") as f:
                json.dump(
                    {"last_seq": last_seq, "state": state_copy},
                    f,
                    ensure_ascii=False,
                )
                f.flush()
                os.fsync(f.fileno())

            final = os.path.join(
                self.snapshot_dir,
                f"snapshot-{last_seq}.json",
            )
            os.replace(tmp, final)

            # 重置 WAL，防止无限增长
            self.wal.reset_after_snapshot()
```

### 3.5 ChainTask 执行器 + 断点续跑

```python
# task.py
import hashlib
import json


def make_idem_key(task_id: str, node_id: str, attempt: int, node_input: dict) -> str:
    raw = json.dumps(
        {
            "task_id": task_id,
            "node_id": node_id,
            "attempt": attempt,
            "input": node_input,
        },
        sort_keys=True,
        ensure_ascii=False,
    )
    return hashlib.sha256(raw.encode("utf-8")).hexdigest()


class TaskExecutor:
    def __init__(self, store, api_client, quality_gate, config):
        self.store = store
        self.api_client = api_client
        self.quality_gate = quality_gate
        self.config = config

    def execute_task(self, task: dict):
        for node_id in task["order"]:
            node = task["nodes"][node_id]

            if node["status"] == "COMPLETED":
                continue

            # 上次执行到一半，用相同 idem_key 恢复，不能换 key
            if node["status"] == "RUNNING" and node.get("idem_key"):
                self._resume_node(task, node)
            else:
                self._execute_node(task, node)

            # 当前节点没完成，下一轮再续跑
            if node["status"] != "COMPLETED":
                return

        if all(
            task["nodes"][nid]["status"] == "COMPLETED"
            for nid in task["order"]
        ):
            if task["status"] != "COMPLETED":
                self.store.append("TASK_COMPLETED", task_id=task["task_id"])
                task["status"] = "COMPLETED"

    def _execute_node(self, task: dict, node: dict):
        node["attempt"] += 1
        node["idem_key"] = make_idem_key(
            task["task_id"],
            node["node_id"],
            node["attempt"],
            node["input"],
        )
        node["status"] = "RUNNING"

        self.store.append(
            "NODE_START",
            task_id=task["task_id"],
            node_id=node["node_id"],
            attempt=node["attempt"],
            idem_key=node["idem_key"],
        )

        self._run_with_idem(task, node)

    def _resume_node(self, task: dict, node: dict):
        node["status"] = "RUNNING"

        self.store.append(
            "NODE_START",
            task_id=task["task_id"],
            node_id=node["node_id"],
            attempt=node["attempt"],
            idem_key=node["idem_key"],
        )

        self._run_with_idem(task, node)

    def _run_with_idem(self, task: dict, node: dict):
        key = node["idem_key"]
        call_state = self.store.state["api_calls"].get(key)

        if call_state and call_state["status"] == "DONE":
            result = call_state["response"]
        else:
            self.store.append(
                "API_CALL_START",
                task_id=task["task_id"],
                node_id=node["node_id"],
                idem_key=key,
            )

            api_call = ApiCall(
                model=node["model"],
                payload=node["input"],
                idem_key=key,
                endpoint=node.get("endpoint"),
            )

            try:
                result = self.api_client.invoke(api_call)
            except ApiTimeout:
                # 请求可能已经到达对端，不能立刻换 key 重试
                # 下次恢复时继续用同一个 idem_key 查重/重放
                return

            self.store.append(
                "API_CALL_DONE",
                task_id=task["task_id"],
                node_id=node["node_id"],
                idem_key=key,
                response=result,
            )

        # 质量检测：B-turbo 跳过 reasoning_ratio 检测
        try:
            self.quality_gate.check(node["model"], result)
        except QualityError as e:
            node["status"] = "FAILED"
            node["error"] = str(e)
            self.store.append(
                "NODE_FAILED",
                task_id=task["task_id"],
                node_id=node["node_id"],
                error=str(e),
            )
            self.store.append("TASK_FAILED", task_id=task["task_id"])
            task["status"] = "FAILED"
            return

        node["status"] = "COMPLETED"
        node["output"] = result

        self.store.append(
            "NODE_DONE",
            task_id=task["task_id"],
            node_id=node["node_id"],
            output=result,
        )
```

```python
# recovery.py
import logging

logger = logging.getLogger("engine.recovery")


class RecoveryManager:
    def __init__(self, store, executor):
        self.store = store
        self.executor = executor

    def resume_all(self):
        # 1. 把所有 RUNNING 标记为 RECOVERING
        for task in self.store.state["tasks"].values():
            if task["status"] == "RUNNING":
                task["status"] = "RECOVERING"
                for node in task["nodes"].values():
                    if node["status"] == "RUNNING":
                        node["status"] = "RECOVERING"

        # 2. 从断点续跑
        for task in self.store.state["tasks"].values():
            if task["status"] in ("PENDING", "RECOVERING"):
                self.executor.execute_task(task)
```

```python
# api_client.py
import requests


class ApiTimeout(Exception):
    pass


class ApiCall:
    def __init__(self, model: str, payload: dict, idem_key: str, endpoint: str):
        self.model = model
        self.payload = payload
        self.idem_key = idem_key
        self.endpoint = endpoint


class ApiClient:
    def __init__(self, config):
        self.config = config

    def invoke(self, call: ApiCall):
        timeout = self.config.timeout_policy.for_model(call.model)

        headers = {"Idempotency-Key": call.idem_key}

        try:
            resp = requests.post(
                call.endpoint,
                json=call.payload,
                headers=headers,
                timeout=timeout,
            )
        except requests.Timeout:
            raise ApiTimeout(
                f"model={call.model} timeout={timeout}s idem_key={call.idem_key}"
            )

        resp.raise_for_status()
        return resp.json()
```

```python
class QualityError(Exception):
    pass


class QualityGate:
    def __init__(self, config):
        self.config = config

    def check(self, model: str, response: dict):
        rules = self.config.quality_policy.for_model(model)

        # B-turbo 的 reasoning 占比 70%-82% 是正常特性，跳过
        if rules.get("skip_reasoning_ratio"):
            return

        max_ratio = rules.get("max_reasoning_ratio", 0.82)
        ratio = response.get("reasoning_ratio", 0)

        if ratio > max_ratio:
            raise QualityError(
                f"reasoning_ratio={ratio} > {max_ratio}, model={model}"
            )
```

### 3.9 双进程：Guardian 与 Core

```python
# process.py
import os
import sys
import time
import signal
import logging
import subprocess
import threading
import fcntl

from config import RuntimeConfig
from heartbeat import HeartbeatFile, kill_process
from state import StateStore
from recovery import RecoveryManager
from task import TaskExecutor
from api_client import ApiClient
from quality import QualityGate

logger = logging.getLogger("engine.process")


class FileLock:
    def __init__(self, path: str):
        self.f = open(path, "w")

    def acquire_block(self, timeout: float = 5.0):
        deadline = time.time() + timeout
        while True:
            try:
                fcntl.flock(self.f, fcntl.LOCK_EX | fcntl.LOCK_NB)
                return
            except BlockingIOError:
                if time.time() > deadline:
                    raise
                time.sleep(0.1)


class CoreProcess:
    def __init__(self, args):
        self.args = args
        RuntimeConfig._instance = RuntimeConfig(args.config)
        self.config = RuntimeConfig.instance()

        self.store = StateStore(args.wal_path, args.snapshot_dir)
        self.api_client = ApiClient(self.config)
        self.quality_gate = QualityGate(self.config)
        self.executor = TaskExecutor(
            self.store,
            self.api_client,
            self.quality_gate,
            self.config,
        )

        self.core_hb = HeartbeatFile(args.core_hb, role="core", epoch=args.epoch)
        self.guardian_hb = HeartbeatFile(args.guardian_hb, role="guardian", epoch=args.epoch)

        self._lock = None
        self._last_guardian_respawn = 0.0

    def run(self):
        self._lock = FileLock(os.path.join(self.args.run_dir, "core.lock"))
        self._lock.acquire_block(timeout=5)

        self.core_hb.beat()

        # 崩溃后恢复：加载 Snapshot + 重放 WAL + 断点续跑
        RecoveryManager(self.store, self.executor).resume_all()

        threading.Thread(target=self._snapshot_loop, daemon=True).start()

        while True:
            self.config.check_reload()
            self.core_hb.beat()

            # Guardian 死了，Core 负责拉起新 Guardian
            if not self.guardian_hb.is_alive():
                self._respawn_guardian()

            self._schedule_new_tasks()

            for task in self.store.state["tasks"].values():
                if task["status"] in ("PENDING", "RECOVERING"):
                    self.executor.execute_task(task)

            time.sleep(self.args.loop_interval)

    def _schedule_new_tasks(self):
        # 单向同步 + 幂等：task_id 已存在则跳过
        for task in self.args.task_source.pending():
            if task["task_id"] not in self.store.state["tasks"]:
                self.store.append(
                    "TASK_CREATED",
                    task_id=task["task_id"],
                    task=task,
                )

    def _respawn_guardian(self):
        now = time.time()
        if now - self._last_guardian_respawn < 5:
            return

        old = self.guardian_hb.read()
        if old:
            kill_process(old["pid"])

        self._last_guardian_respawn = now

        subprocess.Popen(
            [
                sys.executable,
                "-m",
                "engine",
                "--role",
                "guardian",
                "--epoch",
                str(self.args.epoch),
                "--config",
                self.args.config,
                "--run-dir",
                self.args.run_dir,
            ],
            start_new_session=True,
        )

    def _snapshot_loop(self):
        while True:
            time.sleep(self.args.snapshot_interval)
            try:
                self.store.snapshot()
            except Exception:
                logger.exception("snapshot error")


class GuardianProcess:
    def __init__(self, args):
        self.args = args
        self.epoch = args.epoch

        self.guardian_hb = HeartbeatFile(
            args.guardian_hb,
            role="guardian",
            epoch=self.epoch,
        )
        self.core_hb = HeartbeatFile(
            args.core_hb,
            role="core",
            epoch=self.epoch,
        )

        self._lock = None

    def run(self):
        self._lock = FileLock(os.path.join(self.args.run_dir, "guardian.lock"))
        self._lock.acquire_block(timeout=5)

        self.guardian_hb.beat()

        # 如果 Core 没起，先拉起 Core
        if not self.core_hb.is_alive():
            self._start_core()

        while True:
            self.guardian_hb.beat()

            # Core 死了，恢复并重启 Core
            if not self.core_hb.is_alive():
                self._on_core_dead()

            time.sleep(self.args.loop_interval)

    def _on_core_dead(self):
        old = self.core_hb.read()
        if old:
            kill_process(old["pid"])

        # 等 core.lock 释放
        time.sleep(0.5)

        # 进入新一代，防止旧 Core 残留写入
        self.epoch += 1
        self.guardian_hb.epoch = self.epoch

        self._start_core()

    def _start_core(self):
        subprocess.Popen(
            [
                sys.executable,
                "-m",
                "engine",
                "--role",
                "core",
                "--epoch",
                str(self.epoch),
                "--config",
                self.args.config,
                "--run-dir",
                self.args.run_dir,
            ],
            start_new_session=True,
        )
```

## 4. 崩溃恢复时序

### 场景 1：Core 崩溃

```
Guardian 发现 core.hb 超时
  -> kill 旧 Core pid
  -> 等待 core.lock 释放
  -> 启动新 Core --epoch+1
  -> 新 Core 加载最新 snapshot
  -> 重放 WAL
  -> 把 RUNNING 任务标记为 RECOVERING
  -> 断点续跑
```

### 场景 2：Guardian 崩溃

```
Core 发现 guardian.hb 超时
  -> kill 旧 Guardian pid
  -> 启动新 Guardian --epoch 不变
  -> 新 Guardian 发现 Core 还活着
  -> 只监控，不重启 Core
```

### 场景 3：API 调用超时

```
B-turbo 超时阈值 300s，A 模型超时阈值 600s
  -> 请求可能已到达对端
  -> 不换 idempotency_key
  -> 节点保持 RUNNING
  -> 下一轮/恢复时用同一个 key 重放
  -> 对端幂等键去重
```

## 5. 历史坑位落实

| 坑 | 本方案落点 |
|---|---|
| 配置修改后未生效 | `RuntimeConfig` 是唯一读取点；每次心跳循环和 API 调用前都会 `check_reload()` |
| API 超时 | `TimeoutPolicy` 内建 `B-turbo: 300s`，`A: 600s`；超时后不换幂等键 |
| B 模型 reasoning 占比高被误判废稿 | `QualityGate` 对 `B-turbo` 跳过 `reasoning_ratio` 检测，A 模型仍保留 |

## 6. 总结

这套机制在已验证的 Guardian-Core 双进程与 WAL+Snapshot 锚定之上，形成了“以实养虚，虚又返实”的闭环：

- **实**：每次 API 调用、每个状态变更都先落 WAL。
- **虚**：恢复策略根据 WAL/Snapshot 判断断点，选择续跑路径。
- **返实**：续跑成功后，任务继续产出代码、执行结果，真正把“修炼境界”反哺到真实产出。

最终效果：不依赖外部守护进程，双进程互监，崩溃后从最后一个 fsync 的状态断点续跑；外部副作用通过幂等键保证“至少一次 + 幂等消费”。
