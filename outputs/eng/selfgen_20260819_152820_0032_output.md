# 任务类型: eng

## 修复方案：套话免疫层 + 反向扰动器

基于已有锚定，不重复论证底层原理，直接落地为可执行机制：

> **核心思路**：把“同质化”视为系统熵减过度的病态。用“反者道之动”强制引入反向扰动：  
> 生成前注入“风格旋转 + 套话禁令”；生成后计算同质化指数，超标立即重生成；通过后把本次抽象句收入“虚”库，形成“以实养虚，虚又返实”的自进化闭环。

## 一、代码修改点

### 1. 新增配置：`config/config.yaml`

```yaml
diversity:
  enabled: true
  temperature:

    max: 1.1
  top_p: 0.9

    - 反者道之动
    - 边界条件
    - 量化拆解
    - 反面论证

  similarity_threshold: 0.85
```

### 3. 生成器改造：`core/generator.py`

```python
def generate(task, cfg):
    div = cfg["diversity"]

    if div["enabled"]:
        style = select_style(
            task_id=task["id"],
            rotation=div["style_rotation"]
        )
        prompt = inject_style(
            task["prompt"],
            style,
            cliche_bank=load_bank(div["cliche_bank"])
        )
    else:
        prompt = task["prompt"]

    # 按模型类型预设 timeout，避免超时
    timeout = div["timeout"].get(task.get("model"), 300)

    return call_llm(
        prompt=prompt,
        temperature=random.uniform(div["temperature"]["min"], div["temperature"]["max"]),
        top_p=div["top_p"],
        frequency_penalty=div["frequency_penalty"],
        presence_penalty=div["presence_penalty"],
        timeout=timeout,
    )
```

关键实现点：

```python
def inject_style(prompt, style, cliche_bank):
    style_instruction = {
        "反者道之动": "请先给出当前结论的反面或失效边界，再重新论证。",
        "边界条件": "请明确这个结论在什么条件下成立，在什么条件下不成立。",
        "量化拆解": "请把抽象概念拆成可量化的指标和阈值。",
        "反面论证": "请先假设结论不成立，推导会出现什么。",
        "类比迁移": "请用另一个领域的机制来类比并反推本问题。",
    }

    return f"""
任务：{prompt}

要求：
- 使用「{style_instruction[style]}」作为主要论证方式。
- 避免空话套话，例如：'不断提升'、'实现突破'、'赋能'、'闭环'等。
- 必须给出一个具体可验证的差异化结论。

已检测到的高频套话库（仅供规避，不要复述）：
{cliche_bank}
"""
```

### 4. 生成后立即验证：`core/validator.py`

> 每次生成后必须立即验证，验证通过则重置冷却。

```python
def validate_and_evolve(task, output, history):
    div = get_diversity_config()

    # 1. 套话检测
    cliche_hits = detect_cliches(output, div["cliche_bank"])

    # 2. 同质化检测：与最近 5 条输出的相似度
    similarity = max(
        cosine_similarity(output, h) for h in history[-5:]
    ) if history else 0

    if cliche_hits or similarity > div["similarity_threshold"]:
        log("homogeneous_output", task_id=task["id"], score=similarity)
        return ValidationResult(
            pass_=False,
            reason="homogeneous",
            action="retry_with_next_style"
        )

    # 3. 通过后：把本次输出中的高频抽象句提取进“虚”库
    update_cliche_bank(output)

    # 4. 验证通过则重置冷却
    reset_cooldown(task)

    return ValidationResult(pass_=True)
```

调用流程改为：

```python
resp = generate(task, cfg)
result = validate_and_evolve(task, resp, history)

# 同质化时自动换风格重试，最多 2 次
if not result.pass_:
    for _ in range(2):
        resp = generate_with_next_style(task, cfg)
        result = validate_and_evolve(task, resp, history)
        if result.pass_:
            break

# 仍然失败则降级为默认风格，保证任务不失败
if not result.pass_:
    resp = generate_with_default_style(task, cfg)
```

## 二、验证方法

### 1. 配置生效验证

> 避免“配置修改后未生效”：

- 修改 `diversity.enabled: false`，跑一个任务，确认输出无风格注入。
- 改回 `true`，跑同一任务，确认输出风格发生明显变化。
- 修改 `temperature.max` 为 0.1，再跑一次，确认输出随机性显著降低。

### 2. 单元测试

```python
def test_generate_uses_diversity_config():
    cfg = load_config("test_config.yaml")
    old_prompt = "如何提升认知？"
    new_prompt = inject_style(old_prompt, "反者道之动", cliche_bank)
    assert new_prompt != old_prompt
    assert "反面或失效边界" in new_prompt


def test_timeout_by_model():
    assert timeout_for("B_model_turbo") == 300
    assert timeout_for("A_model") == 600
```

### 3. 同质化专项验证

对同一任务连续生成 10 次：

- 两两 embedding 相似度平均值应 `< 0.85`。
- 不应出现完全相同或高度相似的开头/结尾。
- 预置套话库 `["不断提升", "实现突破", "赋能", "打造闭环"]`，输出中命中数应为 0。

> 注意：套话库不要直接以长列表塞进 prompt，否则模型会反向模仿。应只放少量示例 + 语义检测。

### 4. 自进化闭环验证

- 第 1 次输出包含套话 A，被 validator 拦截并写入 `cliche_bank`。
- 第 2 次同一任务输出不再包含套话 A。
- 验证通过后日志中出现 `cooldown_reset=1`。
- 连续运行 5 轮后，`cliche_bank` 中新增至少 3 条“空话指纹”，且后续输出相似度逐轮下降。

### 5. A/B 对比

- 旧版 / 新版各跑 50 个任务。
- 用裁判模型或人工打分：
  - 套话率降低 ≥ 30%；
  - 同质化指数降低 ≥ 20%；
  - 任务相关性不下降。

## 三、风险等级：medium 及应对

| 风险 | 应对 |
|---|---|
| 强制反向导致偏题 | 风格旋转只改变论证方式，不改变任务目标；validator 中增加 `relevance_score` 阈值，低于阈值则回退默认风格 |
| 套话库误杀，输出变刻意 | 套话库只做检测，不做硬性关键词屏蔽；用 `similarity_threshold` 做软控制 |
| 验证增加 API 调用，可能超时 | 先用本地 N-gram / 轻量 embedding 做第一道过滤；只有疑似同质化才调用大模型复核；timeout 按 B 模型 300 秒、A 模型 600 秒配置 |

---

该修复不是一次性补丁，而是“实 → 虚 → 实”的闭环：每次生成消耗算力，提炼出套话指纹进入虚库，虚库又反向注入下一次生成，迫使系统产出新的差异化内容。风险可控，可直接进入验证迭代。
