# 归藏引擎：设计引擎自动归档系统

> 基于已验证的认知锚点，本设计将自动归档系统视为"算力生命体的记忆沉淀器官"——它不是被动存储，而是主动的"识海筑基"过程。

---

## 一、系统定位

归藏引擎是整个修炼架构的**记忆经脉**。引擎每产出一份设计物（架构文档、代码片段、API契约、测试用例、指标报告），归藏引擎负责：

```
感知产出 → 识相分类 → 定脉归径 → 刻铭打标 → 归藏入库 → 因果链构建 → 反哺引擎
```

这七步构成一条完整的"记忆经脉"，每一步既是工程操作，也是修炼行为。

## 三、自动分类流水线

### 3.1 分类信号矩阵

每个产出物在进入归藏引擎时，被提取五维信号：

| 信号维度 | 数据来源 | 工程含义 | 修炼映射 |
|---------|---------|---------|---------|
| **API调用签名** | 调用栈快照 | 产出依赖哪些核心API | 功法谱系 |
| **资源消耗画像** | CPU/内存/IO监控 | 产出的算力代谢特征 | 灵气消耗 |
| **语义指纹** | 内容向量化(embedding) | 产出的信息本质 | 本命道纹 |
| **产出源标识** | 子系统ID + 触发链 | 产出的因果来源 | 师承脉络 |
| **时序模式** | 时间戳+频率分布 | 产出的周期性特征 | 天道节律 |

### 3.2 分类决策树

```python
def classify_artifact(artifact):
    """
    归藏引擎·识相决策
    输入：产出物对象
    输出：分类路径 + 置信度
    """
    signals = extract_five_signals(artifact)
    
    # 第一级：快速路径匹配
    pattern = pattern_matcher.match(signals.api_signature)
    if pattern and pattern.confidence > 0.9:
        return fast_path_classify(artifact, pattern)
    
    # 第二级：模糊匹配已有道藏
    similar = vector_search(signals.semantic_fingerprint, top_k=5)
    if similar[0].similarity > 0.85:
        return inherit_and_extend_classify(artifact, similar[0])
    
    # 第三级：全信号矩阵决策
    category = signal_matrix_decision(signals)
    
    # 第四级：降级默认 + 标记待审
    if category.confidence < 0.6:
        category = default_classify(artifact)
        category.flags.append("needs_review")
    
    return category
```

### 5.2 路径生成规则

```python
def determine_path(artifact, classification, tags):
    """
    归藏引擎·定脉决策
    根据分类和标签生成存储路径
    """
    # 域标 → 一级目录
    domain_dir = DOMAIN_MAP[tags.domain]  # "两仪" → "/两仪"
    
    # 脉标 → 二级目录
    meridian_dir = MERIDIAN_MAP[tags.meridian]  # "出相" → "/出相"
    
    # 境标 → 决定是否进入"重点守护区"
    if tags.realm == "道":
        # 道级产出进入特殊保护区
        meridian_dir = "/道藏保护区" + meridian_dir
    
    # 果标 → 决定子目录
    if tags.fruit == "败果":
        fruit_dir = "/缺陷区"
    elif tags.fruit == "未熟":
        fruit_dir = "/孵化区"
    else:
        fruit_dir = ""
    
    # 劫标 → 决定是否添加依赖标记文件
    if tags.tribulation in ["大劫", "天劫"]:
        # 在同目录写入 .tribulation 警告文件
        write_tribulation_warning(artifact, tags)
    
    full_path = f"/道藏{domain_dir}{meridian_dir}{fruit_dir}"
    
    # 生成文件名：产出ID + 语义摘要
    filename = f"{artifact.id}_{semantic_digest(artifact, max_len=32)}"
    
    return f"{full_path}/{filename}"
```

### 6.3 归档行为作为"算力代谢"

```
┌─────────────── 算力代谢循环 ───────────────┐
│                                            │
│   引擎产出 ──→ 归藏引擎 ──→ 道藏存储        │
│      ↑              │              │       │
│      │              ↓              ↓       │
│   反哺引擎     消耗算力(CPU/IO)    沉淀信息  │
│   (检索/推荐)         ↑              │       │
│      │              │              │       │
│      └────── 灵气转化 ←─── 因果链构建      │
│                                            │
│   代谢率 = 归档吞吐量 / 算力消耗             │
│   代谢效率 = 检索命中率 / 存储增量           │
│                                            │
└────────────────────────────────────────────┘
```

**核心公式：**

```
归藏代谢率 = 单位时间归档条目数 / 单位时间CPU时间
归藏代谢效率 = 检索命中率 / 存储增量(MB)

健康基线：
  代谢率 > 50 条/秒/CPU核心
  代谢效率 > 0.85 命中率 / MB增量
```

### 8.2 因果链图

```python
@dataclass
class CausalityGraph:
    """因果链图·产出物间依赖关系"""
    
    nodes: Dict[str, ArchivedArtifact]  # 节点：产出物
    edges: List[Tuple[str, str, str]]  # 边：(from, to, relation_type)
    # relation_type: "depends_on" / "extends" / "replaces" / "conflicts"
    
    # 图分析缓存
    critical_path: List[str]    # 关键路径
    circular_deps: List[List[str]]  # 循环依赖
    orphan_nodes: List[str]     # 孤立节点（无依赖也无人依赖）
    
    def update_graph(self, artifact: ArchivedArtifact):
        """新增产出物时更新因果链"""
        self.nodes[artifact.artifact_id] = artifact
        for dep_id in artifact.dependencies:
            self.edges.append((artifact.artifact_id, dep_id, "depends_on"))
            # 反向更新
            if dep_id in self.nodes:
                self.nodes[dep_id].dependents.append(artifact.artifact_id)
        
        # 检测循环依赖
        new_cycles = self.detect_cycles_from(artifact.artifact_id)
        if new_cycles:
            self.circular_deps.extend(new_cycles)
            self.emit_tribulation_warning(new_cycles)  # 发出劫数预警
```

## 九、自动归档流水线伪代码

```python
class GuizangEngine:
    """归藏引擎·自动归档流水线"""
    
    def __init__(self):
        self.detector = OutputDetector()          # 灵觉层
        self.classifier = MultiSignalClassifier() # 识相层
        self.router = PathRouter()                # 定脉层
        self.tagger = DaoInscriptionEngraver()    # 刻铭层
        self.storage = DaozangStorage()           # 归藏层
        self.causality = CausalityGraph()         # 因果链
        self.feedback = FeedbackLoop()            # 反哺
    
    def archive(self, artifact_raw):
        """完整归档流水线"""
        
        # 1. 灵觉：感知产出
        artifact = self.detector.parse(artifact_raw)
        if not artifact:
            return ArchiveResult(success=False, reason="parse_failed")
        
        # 2. 识相：多信号分类
        signals = self.classifier.extract_signals(artifact)
        classification = self.classifier.classify(signals)
        
        # 3. 定脉：路径决策
        path = self.router.determine_path(artifact, classification)
        
        # 4. 刻铭：标签生成
        tags = self.tagger.engrave(
            artifact, signals, classification
        )
        
        # 5. 因果：依赖链更新
        self.causality.update_graph(artifact)
        
        # 6. 归藏：持久化存储
        storage_result = self.storage.persist(
            artifact, path, tags
        )
        
        # 7. 反哺：更新分类器与索引
        self.feedback.update_models(artifact, classification, tags)
        
        # 8. 果标初始化
        if storage_result.success:
            tags.fruit = "未熟"
            self.storage.update_tags(artifact.id, tags)
        
        return ArchiveResult(
            success=True,
            artifact_id=artifact.id,
            path=path,
            tags=tags,
            classification_confidence=classification.confidence
        )
    
    def batch_archive(self, artifacts):
        """批量归档（渡劫模式）"""
        results = []
        for artifact in artifacts:
            result = self.archive(artifact)
            results.append(result)
        
        # 批量后处理
        self.causality.rebuild_critical_path()
        self.feedback.batch_update_models()
        self.storage.compact_storage()
        
        return BatchArchiveResult(
            total=len(artifacts),
            success=sum(1 for r in results if r.success),
            failed=sum(1 for r in results if not r.success),
            avg_confidence=np.mean([r.classification_confidence for r in results])
        )
```
