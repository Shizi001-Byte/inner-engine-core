## 二、六层架构详解

### 第一层 · 吞噬层 — 任务接入与预处理

**对应九转**：语料吞噬的第一道关口

**核心职责**：接收所有任务流，统一格式化

```python
class TaskIngestor:
    """任务吞噬口 - 任何形态的任务统一吞入"""
    
    def ingest(self, raw_task):
        """
        支持的任务形态:
        - 结构化任务 (JSON/dict)
        - 半结构化 (自然语言描述)
        - 非结构化 (对话片段/截图描述)
        """
        standardized = {
            "task_id": self._gen_id(),
            "raw_content": raw_task,
            "ingest_time": self._timestamp(),
            "source_type": self._detect_source(raw_task),
            "content_text": self._extract_text(raw_task),
            "status": "raw"
        }
        return standardized
```

**设计要点**：
- 不拒绝任何形态的任务输入
- 保留原始内容副本（防止后续剥离丢失信息）
- 记录来源类型（用户直接输入 / 引擎产出 / 外部系统）

### 第二层 · 剥离层 — 特征提取骨架

**对应九转**：特征剥离——剥离无效冗余，提取信息骨架

**核心职责**：从原始任务中提取分类所需的核心特征

```python
class FeatureStripper:
    """特征剥离器 - 从任务肉身中抽取骨架"""
    
    def strip(self, standardized_task):
        features = {
            # ── 骨架特征 ──
            "intent": self._extract_intent(standardized_task["content_text"]),
            # 意图：创建/修改/查询/分析/部署/修复/优化
            
            "domain": self._extract_domain(standardized_task["content_text"]),
            # 领域：前端/后端/数据库/运维/文档/设计/测试
            
            "entity": self._extract_entities(standardized_task["content_text"]),
            # 实体：涉及的技术栈、模块名、项目名
            
            "action_type": self._classify_action(standardized_task["content_text"]),
            # 行为类型：代码编写/架构设计/问题排查/数据处理/文档撰写
            
            "complexity": self._estimate_complexity(standardized_task),
            # 复杂度：simple / moderate / complex / epic
            
            "dependency": self._detect_dependency(standardized_task["content_text"]),
            # 依赖：是否依赖其他任务、是否阻塞其他任务
        }
        
        standardized_task["features"] = features
        standardized_task["status"] = "stripped"
        return standardized_task
```

**特征维度表**：

| 特征维度 | 取值范围 | 示例 |
|---------|---------|------|
| intent | create / modify / query / analyze / deploy / fix / optimize | fix |
| domain | frontend / backend / database / devops / doc / design / test | backend |
| action_type | coding / architecture / debugging / data_process / writing | debugging |
| complexity | simple / moderate / complex / epic | moderate |
| dependency | none / blocked_by:X / blocks:Y / parallel_with:Z | blocked_by:auth_module |

### 第三层 · 判别层 — 自动分类引擎

**对应九转**：阴阳判别——根据特征将任务归入对应"经脉"

**分类策略**：三层判定机制

```python
class TaskClassifier:
    """分类判官 - 阴阳判别，各归其位"""
    
    def classify(self, task):
        # 第一判：规则匹配（最快速）
        category = self._rule_based_match(task["features"])
        
        if category is None:
            # 第二判：特征向量最近邻
            category = self._vector_match(task["features"])
        
        if category is None:
            # 第三判：LLM语义理解兜底
            category = self._semantic_classify(task["content_text"])
        
        # 置信度记录
        task["classification"] = {
            "category": category["primary"],
            "subcategory": category.get("secondary"),
            "confidence": category["confidence"],
            "method": category["method"]  # rule / vector / semantic
        }
        task["status"] = "classified"
        return task
```

### 第四层 · 烙印层 — 多维标签系统

**对应九转**：灵识烙印——为每个任务打上多维度的"神识标记"

```python
class TaskTagger:
    """灵识烙印 - 为任务打上多维标签"""
    
    def tag(self, task):
        tags = set()
        
        # ── 优先级标签 ──
        tags.add(self._priority_tag(task))  # P0 / P1 / P2 / P3
        
        # ── 状态标签 ──
        tags.add(self._status_tag(task))  # todo / in_progress / done / blocked
        
        # ── 技术栈标签 ──
        tags.update(self._tech_stack_tags(task))  # python / react / postgres ...
        
        # ── 项目归属标签 ──
        tags.add(self._project_tag(task))  # proj_xxx
        
        # ── 时间维度标签 ──
        tags.add(self._time_tag(task))  # daily / weekly / longterm
        tags.add(self._deadline_tag(task))  # urgent / normal / no_rush
        
        # ── 关系标签 ──
        if task["features"]["dependency"] != "none":
            tags.add("has_dependency")
        if task["features"]["complexity"] in ("complex", "epic"):
            tags.add("needs_breakdown")
        
        # ── 智能标签（从内容中提取）──
        tags.update(self._smart_tags(task["content_text"]))
        # 例如：security_related / user_facing / breaking_change
        
        task["tags"] = list(tags)
        task["status"] = "tagged"
        return task
```

### 第五层 · 归藏层 — 目录写入与存储

**对应九转**：归入丹田——按分类+标签写入对应存储位置

```python
class TaskArchiver:
    """归藏入库 - 将任务存入对应目录"""
    
    def archive(self, task):
        category = task["classification"]["category"]
        
        # ── 物理存储路径 ──
        storage_path = self._build_path(category, task)
        # 示例: /tasks/engineering/backend/2025-01-15/task_xxxx.md
        
        # ── 归档文件内容 ──
        archived_doc = self._render_task_doc(task)
        
        # ── 写入文件系统 ──
        self._write(storage_path, archived_doc)
        
        # ── 同时写入索引库 ──
        self._index_store.upsert({
            "task_id": task["task_id"],
            "path": storage_path,
            "category": category,
            "tags": task["tags"],
            "summary": self._generate_summary(task),
            "content_vector": self._embed(task["content_text"]),
            "create_time": task["ingest_time"],
            "status": task.get("status", "todo")
        })
        
        task["status"] = "archived"
        task["archive_path"] = storage_path
        return task
```

### 第六层 · 索引与代谢层 — 检索与自清理

```python
class IndexAndMetabolism:
    """神识索引 + 代谢回收"""
    
    # ── 检索接口 ──
    def search(self, query, filters=None):
        """
        支持的检索方式:
        1. 关键词检索
        2. 标签过滤 (tags=["urgent", "backend"])
        3. 分类浏览 (category="bugfix/functional")
        4. 语义搜索 (自然语言描述)
        5. 组合查询
        """
        # 向量检索 + 标签过滤混合
        results = self._hybrid_search(query, filters)
        return self._rank_and_format(results)
    
    # ── 代谢回收 ──
    def metabolize(self):
        """定期清理过期/已完成任务"""
        
        # 已完成超过30天 → 归入冷存储
        cold = self._find_completed_older_than(days=30)
        for task in cold:
            self._move_to_cold_storage(task)
        
        # 已完成超过90天 → 压缩归档
        archive = self._find_completed_older_than(days=90)
        for task in archive:
            self._compress_and_archive(task)
        
        # 无引用的空目录 → 清理
        self._clean_empty_dirs()
```

## 三、完整流水线

```python
class ArchiveEngine:
    """玄功归档引擎 - 主流水线"""
    
    def __init__(self):
        self.ingestor = TaskIngestor()
        self.stripper = FeatureStripper()
        self.classifier = TaskClassifier()
        self.tagger = TaskTagger()
        self.archiver = TaskArchiver()
        self.index = IndexAndMetabolism()
    
    def process(self, raw_task):
        """单一任务完整流水线"""
        task = self.ingestor.ingest(raw_task)
        task = self.stripper.strip(task)
        task = self.classifier.classify(task)
        task = self.tagger.tag(task)
        task = self.archiver.archive(task)
        return task
    
    def batch_process(self, raw_tasks):
        """批量处理"""
        return [self.process(t) for t in raw_tasks]
    
    def retrieve(self, query, filters=None):
        """检索已归档任务"""
        return self.index.search(query, filters)
```

## 五、认知映射总结

| 九转玄功 | 归档引擎对应 | 系统职责 |
|---------|------------|---------|
| 语料吞噬 | 吞噬层 | 统一接入所有任务形态 |
| 特征剥离 | 剥离层 | 提取意图/领域/复杂度骨架 |
| 阴阳判别 | 判别层 | 三级策略自动分类 |
| 灵识烙印 | 烙印层 | 多维标签矩阵打标 |
| 归入丹田 | 归藏层 | 按分类写入物理目录 |
| 神识外放 | 索引层 | 语义检索+标签过滤 |
| 算力代谢 | 代谢层 | 过期清理+冷热分层 |

> **核心原则**：系统不只是一个分类工具，而是一个有"消化能力"的归档生命体——任务进来被消化、骨架被提取、灵识被烙印、归入对应丹田，最终可通过神识检索随时调用。
