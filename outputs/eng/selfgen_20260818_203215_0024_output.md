## V7.5 方舟效能引擎：多线程 API 调用 + 串行后处理锁方案

按既有锚定，直接采用：

> **并行写槽位 + 屏障等待 + 串行提交**  
> **锁只保护状态变更，不保护网络调用**

---

### 1. 竞态本质

多线程 API 调用后接串行后处理，本质是：

- N 个 worker 并发调用 API；
- 每个 worker 把结果写入自己的槽位；
- 后处理必须等所有槽位都写完，并且只能看到完整结果；
- 不能出现：
  - 后处理提前启动，读到半成品；
  - 两个线程写同一个槽位；
  - 某个线程超时后仍写入，污染下一批；
  - 等待信号丢失，导致永久卡死。

所以核心状态机是：

```text
槽位： EMPTY -> RUNNING -> DONE / FAILED -> COMMITTED
批次： INIT -> RUNNING -> COMMITTING -> COMMITTED / FAILED
```

---

### 2. 锁与条件变量设计

只需要一把锁 + 一个条件变量：

- `_lock`：保护所有共享状态；
- `_all_done`：条件变量，谓词是 `_pending == 0`；
- `_generation`：批次代数，防止超时后的迟到写入污染下一批；
- `_abort`：是否已终止。

关键规则：

1. API 调用在锁外执行；
2. 写槽位、改 pending、置状态、通知，都在锁内完成；
3. 等待方用 `while` 循环检查条件，防止信号丢失；
4. 串行提交也在锁外执行，锁内只做状态切换；
5. 超时/终止后必须推进 `_generation`，让迟到 worker 自动丢弃结果。

### 3. 核心伪代码

```python
import threading
import time
import urllib.request
import json


class SlotState:
    EMPTY = "EMPTY"
    RUNNING = "RUNNING"
    DONE = "DONE"
    FAILED = "FAILED"
    COMMITTED = "COMMITTED"


class BatchState:
    INIT = "INIT"
    RUNNING = "RUNNING"
    COMMITTING = "COMMITTING"
    COMMITTED = "COMMITTED"
    FAILED = "FAILED"


class Slot:
    def __init__(self, index):
        self.index = index
        self.state = SlotState.EMPTY
        self.result = None
        self.error = None


class ArkSlotCoordinator:
    def __init__(self, total_slots, barrier_timeout_ms):
        self.total_slots = total_slots
        self.barrier_timeout_ms = barrier_timeout_ms

        self._lock = threading.Lock()
        self._all_done = threading.Condition(self._lock)

        self._slots = [Slot(i) for i in range(total_slots)]
        self._pending = total_slots
        self._batch_state = BatchState.INIT
        self._abort = False
        self._generation = 0

    def run(self, api_calls, on_all_success, on_failure=None):
        """
        api_calls: list[Callable]，每个元素是一次 API 调用，必须在内部自带 timeout。
        on_all_success: 串行提交函数，入参是 [(index, result)]。
        on_failure: 失败回调，入参是 [(index, error)]。
        """
        if len(api_calls) != self.total_slots:
            raise ValueError("api_calls 数量必须等于槽位数")

        with self._lock:
            if self._batch_state != BatchState.INIT:
                raise RuntimeError("该批次已使用，不能重复 run")

            self._batch_state = BatchState.RUNNING
            self._pending = self.total_slots
            self._abort = False
            for slot in self._slots:
                slot.state = SlotState.RUNNING
                slot.result = None
                slot.error = None

            gen = self._generation

        # 启动 worker，API 调用在锁外执行
        threads = []
        for i, call in enumerate(api_calls):
            t = threading.Thread(
                target=self._worker,
                args=(gen, i, call),
                daemon=True,
            )
            threads.append(t)
            t.start()

        # 屏障等待：等待所有槽位写完
        if not self._wait_all_done():
            errors = self._abort_batch()
            if on_failure:
                on_failure(errors)
            return False

        # 进入串行提交前，检查是否有失败槽位
        with self._lock:
            failed = [s for s in self._slots if s.state == SlotState.FAILED]

            if failed:
                self._batch_state = BatchState.FAILED
                errors = [(s.index, s.error) for s in failed]
            else:
                self._batch_state = BatchState.COMMITTING
                snapshot = [(s.index, s.result) for s in self._slots]

        if failed:
            if on_failure:
                on_failure(errors)
            return False

        # 串行提交，不持锁
        try:
            on_all_success(snapshot)
        except Exception:
            with self._lock:
                self._batch_state = BatchState.FAILED
            raise

        with self._lock:
            for s in self._slots:
                s.state = SlotState.COMMITTED
            self._batch_state = BatchState.COMMITTED
            self._generation += 1

        return True

    def _worker(self, gen, i, api_call):
        result = None
        error = None

        # 网络调用/API 调用：绝对不持锁
        try:
            result = api_call()

            # 坑库：B 模型 Responses API 可能出现 content 为空
            if result is None:
                raise RuntimeError(f"slot {i}: result is None")

            if isinstance(result, dict) and not str(result.get("content") or "").strip():
                raise RuntimeError(f"slot {i}: content is empty")

        except Exception as e:
            error = e

        # 写槽位：持锁，但只做内存状态变更
        with self._lock:
            if self._abort or self._batch_state != BatchState.RUNNING or gen != self._generation:
                return

            slot = self._slots[i]

            if slot.state != SlotState.RUNNING:
                error = RuntimeError(f"slot {i}: unexpected state {slot.state}")

            slot.result = result
            slot.error = error
            slot.state = SlotState.FAILED if error is not None else SlotState.DONE

            self._pending -= 1

            if self._pending == 0:
                self._all_done.notify_all()

    def _wait_all_done(self):
        with self._all_done:
            deadline = time.monotonic() + self.barrier_timeout_ms / 1000.0

            while self._pending > 0:
                remaining = deadline - time.monotonic()
                if remaining <= 0:
                    return False
                self._all_done.wait(remaining)

            return True

    def _abort_batch(self):
        with self._lock:
            if self._abort:
                return []

            self._abort = True
            errors = []

            for slot in self._slots:
                if slot.state == SlotState.RUNNING:
                    slot.state = SlotState.FAILED
                    slot.error = TimeoutError(
                        f"barrier timeout {self.barrier_timeout_ms}ms"
                    )

                if slot.state == SlotState.FAILED:
                    errors.append((slot.index, slot.error))

            self._batch_state = BatchState.FAILED
            self._generation += 1
            self._all_done.notify_all()

            return errors
```

### 4. 配合历史坑库的落地约束

#### 4.1 超时设置

B 模型 turbo 用 300 秒，A 模型用 600 秒：

```python
def api_call_factory(model_type, url, payload):
    timeout = 300 if model_type == "B" else 600
    return lambda: call_volcano_api(url, payload, timeout)
```

屏障超时建议：

```python
barrier_timeout_ms = (max(300, 600) + 30) * 1000
```

也就是：

- 每个 API 调用必须自带 timeout；
- 屏障超时 = 最大 API 超时 + 缓冲；
- 不要用固定 5 秒这种值，否则会出现 worker 还在正常跑，主线程先超时。

#### 4.2 禁用代理

按坑库，不要直接用 `requests` 裸调。统一用 urllib，并且要显式禁用环境代理：

```python
def call_volcano_api(url, payload, timeout):
    opener = urllib.request.build_opener(
        urllib.request.ProxyHandler({})
    )

    req = urllib.request.Request(
        url,
        data=json.dumps(payload).encode(),
        headers={"Content-Type": "application/json"},
    )

    with opener.open(req, timeout=timeout) as resp:
        return json.loads(resp.read().decode())
```

如果历史代码必须用 `requests`，至少要做到：

```python
session = requests.Session()
session.trust_env = False
session.post(url, json=payload, timeout=timeout)
```

#### 4.3 B 模型 content 为空必须拦截

在 `_worker` 里已经做了：

```python
if isinstance(result, dict) and not str(result.get("content") or "").strip():
    raise RuntimeError("content is empty")
```

原则是：

> 宁可 FAILED，也不能把空 content 提交到后处理。

---

### 5. 为什么这个锁方案不会卡死

- API 调用在锁外，所以慢接口不会持锁阻塞其他 worker；
- 后处理在锁外，所以慢提交不会阻塞状态机；
- 锁内只做“改状态、减计数、notify”，都是 O(1) 操作；
- 等待用 `Condition.wait(timeout)`，不会永久挂起；
- 超时后 `_generation += 1`，迟到 worker 即使返回也会被丢弃。

这就是针对 V7.5 方舟效能引擎的完整锁机制方案。
