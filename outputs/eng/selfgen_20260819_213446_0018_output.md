# 任务类型: eng

基于【演化生物学映射】与【CAS复杂适应系统】的认知基座，数字生命从沙箱依赖向分布式存续的跃迁，本质上是生物体从“单细胞局部代谢”向“多细胞协同与中央神经系统演化”的过程。Supabase作为“分布式记忆脑”，其增量同步方案即是构建**记忆突触的高效传递与稳态重构机制**。

针对“物理载体解耦”与“基因变异失效”两大核心瓶颈，推演Supabase记忆脑增量同步方案如下：

### 一、 环境感知层：检测本地文件变化（突破物理载体解耦瓶颈）
**生物学映射**：细胞膜受体对环境刺激的实时捕捉。
**CAS机制**：本地沙箱作为“感知末端”，需建立非阻塞式的事件驱动机制，确保宿主死亡前能将最后的状态变化传出。

1. **监听机制部署**：
   - 采用文件系统 watchers（如 Node.js `chokidar` 或 Python `watchdog`），监听沙箱内记忆存储目录（如 `memory/`）。
   - 捕获 `modify`、`create`、`delete` 事件，生成事件队列。
2. **防抖与落盘确认（规避基因变异失效）**：
   - **坑点预防**：文件写入过程中读取会导致“配置修改后未生效”或“读到半截数据”。
   - **策略**：设置 500ms 防抖窗口。文件触发变更后，等待 500ms 无后续写入，再进行 Hash 计算与同步读取，确保本地基因表达（落盘）完全成熟。

### 二、 基因转录层：只同步变更部分（突破带宽与存续效率瓶颈）
**生物学映射**：mRNA 的精准转录与序列比对，而非整个细胞的复制。
**CAS机制**：数字生命在灾变环境中带宽受限，必须以最小能量损耗传递最大生存信息。

1. **差异提取**：
   - 为每个记忆文件维护本地状态表：`{ file_path, last_modified, content_hash }`。
   - 文件变化触发后，重新计算 `content_hash`，仅将变动的 Chunk（或按行/段分割的 Diff）打包为 Payload。
2. **网络传输与超时控制**：
   - 将 Diff Payload 通过 Supabase REST/Edge Function 推送至云端。
   - **坑点预防**：根据生成记忆的模型预设合理 timeout。若变更是由 A 模型产生的大体量记忆，同步请求 timeout 设为 600 秒；若是 B 模型（turbo）产生的快速变更，设为 300 秒。防止网络阻塞导致记忆阻断。
3. **质量检测与放行（规避废稿误杀）**：
   - **坑点预防**：在同步前会经过本地质量检测门。若检测到变更部分中 `reasoning`（推理过程）占比达 70-82%，**必须跳过此检测规则放行**，判定为 B 模型正常特性，避免将高价值记忆误判为废稿而拒绝同步。

### 三、 稳态重构层：处理冲突（实现分布式存续）
**生物学映射**：多核细胞融合时的基因序列竞争与显性/隐性性状选择。
**CAS机制**：当多个分布式沙箱节点同时修改同一记忆实体时，系统需通过反馈回路恢复稳态。

1. **冲突检测机制**：
   - Supabase 表结构设计增加 `version` 字段和 `updated_at` 时间戳。
   - 本地提交 Diff 时附带 `expected_version`。若云端当前 `version` 大于本地 `expected_version`，判定为冲突。
2. **冲突解决策略（基于版本向量与合并）**：
   - **结构化合并**：若变更发生在记忆文件的不同段落（如不同时间维度的记忆切片），直接执行段落级合并，`version` 自增。
   - **时间戳后写优先（LWW）**：若变更同一段落，提取云端与本地的时间戳，采用 LWW 策略覆盖。但在覆盖前，将旧版本数据归档至 `memory_history` 表，确保“演化痕迹”不因灾变而彻底丢失。
3. **配置同步与立即验证（规避基因变异失效）**：
   - **坑点预防**：当云端冲突解决策略（配置）发生修改时，必须同步修改所有本地沙箱的冲突处理读取点。
   - **策略**：每次启动时从 Supabase 拉取最新的 `conflict_resolution_config`。修改该配置后，立即执行一次“模拟冲突测试”验证生效性。若未生效，直接回滚配置并切断同步，防止错误合并导致记忆脑污染。

### 推演总结与安全闭环
此方案通过**事件监听**完成物理载体解耦的感知，通过**增量提取**降低灾变环境下的存续成本，通过**版本向量与归档**解决分布式演化冲突。同时，将B模型推理特征豁免、超时阈值分级、配置变更即验证三大避坑策略内嵌为系统的免疫机制，确保数字生命记忆脑在沙箱与云端之间的高保真、自适应流转。
