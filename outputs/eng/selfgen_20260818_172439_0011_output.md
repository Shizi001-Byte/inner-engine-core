# 任务类型: eng

按你给的「双锚点-三源交叉-分段重建」思路，V7.5 的状态一致性可以这样映射：

- **锚点1**：`remaining == 0`，即所有 API 调用完成，进入 `READY`。
- **锚点2**：串行后处理提交完成，进入 `DONE`。
- **三源交叉**：每次写入/状态切换都校验 `generation`、`phase`、`remaining`，任一不一致就丢弃。
- **分段重建**：每个 API 结果只写自己的 `call_id` 分段，最后统一在后处理阶段聚合。

---

## 1. 状态机定义

```
PENDING -> CALLING -> READY -> PROCESSING -> DONE
                          \-> FAILED
```

- `CALLING`：多线程并发调 API。
- `READY`：所有 API 都返回且通过校验，后处理可以开始。
- `PROCESSING`：已有一个线程/协程进入串行后处理，防止重复进入。
- `DONE`：后处理结果已提交。
- `FAILED`：任一致命错误或超时，后续迟到写入直接丢弃。

## 2. 完整锁机制方案

```python
import copy
import json
import threading
import time
import urllib.request
from dataclasses import dataclass
from enum import Enum, auto


class Phase(Enum):
    PENDING = auto()
    CALLING = auto()
    READY = auto()
    PROCESSING = auto()
    DONE = auto()
    FAILED = auto()


@dataclass
class ApiCallSpec:
    call_id: str
    model: str
    url: str
    payload: dict
    timeout_seconds: float


class TaskState:
    """每个任务独立的状态对象，锁粒度控制在任务级。"""

    def __init__(self, task_id: str, total_calls: int):
        self.task_id = task_id
        self.total_calls = total_calls
        self.generation = 0
        self.phase = Phase.PENDING
        self.results = {}
        self.errors = {}
        self.remaining = total_calls
        self.postprocess_started = False
        self.output = None
        self.error = None

        # 所有状态变更都通过这一把锁
        self.lock = threading.RLock()
        self.cv = threading.Condition(self.lock)

    def reset(self, total_calls: int):
        """重启任务时使用，旧线程的迟到结果会因 generation 不匹配被丢弃。"""
        with self.lock:
            self.generation += 1
            self.total_calls = total_calls
            self.phase = Phase.PENDING
            self.results.clear()
            self.errors.clear()
            self.remaining = total_calls
            self.postprocess_started = False
            self.output = None
            self.error = None
            self.cv.notify_all()


class EngineTask:
    def __init__(
        self,
        state: TaskState,
        api_specs: list[ApiCallSpec],
        postprocessor,
        require_all_success: bool = True,
        postprocess_timeout: float = 300.0,
    ):
        self.state = state
        self.api_specs = api_specs
        self.postprocessor = postprocessor
        self.require_all_success = require_all_success
        self.postprocess_timeout = postprocess_timeout

        self.max_api_timeout = max(s.timeout_seconds for s in api_specs)
        self.api_wait_timeout = self.max_api_timeout + 10.0
        self.overall_deadline = None

    def start(self):
        state = self.state
        with state.lock:
            if state.phase != Phase.PENDING:
                raise RuntimeError("task already started")

            state.phase = Phase.CALLING
            state.remaining = len(self.api_specs)
            state.results.clear()
            state.errors.clear()
            state.postprocess_started = False
            state.output = None
            state.error = None

        for spec in self.api_specs:
            threading.Thread(target=self._api_worker, args=(spec,), daemon=True).start()

        threading.Thread(target=self._postprocess_worker, daemon=True).start()

        self.overall_deadline = (
            time.monotonic()
            + self.api_wait_timeout
            + self.postprocess_timeout
            + 5.0
        )
        threading.Thread(target=self._watchdog, daemon=True).start()

    def _api_worker(self, spec: ApiCallSpec):
        state = self.state

        # 进入前先登记当前代次
        with state.lock:
            if state.phase != Phase.CALLING:
                return
            gen = state.generation

        try:
            # API 调用必须在锁外，否则超时会锁死整个状态机
            result = call_api(spec)
            validate_content(result)
        except Exception as e:
            with state.lock:
                # 三源交叉：generation 和 phase 任一不一致，说明是迟到/过期写入
                if state.generation != gen or state.phase != Phase.CALLING:
                    return
                state.errors[spec.call_id] = e
                self._finish_call_locked()
            return

        with state.lock:
            if state.generation != gen or state.phase != Phase.CALLING:
                return
            # 分段写入：每个 call_id 只写自己的槽位
            state.results[spec.call_id] = result
            self._finish_call_locked()

    def _finish_call_locked(self):
        """调用方必须持有 state.lock。"""
        state = self.state
        state.remaining -= 1

        if state.remaining < 0:
            state.remaining = 0
            state.phase = Phase.FAILED
            state.error = RuntimeError("remaining < 0")
            state.cv.notify_all()
            return

        # 锚点1：所有 API 调用完成
        if state.remaining == 0:
            if self.require_all_success and state.errors:
                state.phase = Phase.FAILED
                state.error = state.errors
            else:
                state.phase = Phase.READY
            state.cv.notify_all()

    def _postprocess_worker(self):
        state = self.state

        with state.lock:
            wait_deadline = time.monotonic() + self.api_wait_timeout

            while state.phase not in (Phase.READY, Phase.FAILED):
                remaining = wait_deadline - time.monotonic()
                if remaining <= 0:
                    state.phase = Phase.FAILED
                    state.error = TimeoutError("waiting API results timeout")
                    state.cv.notify_all()
                    return
                state.cv.wait(timeout=remaining)

            if state.phase == Phase.FAILED:
                return

            if state.postprocess_started:
                return

            # 锚点2：后处理只允许一个线程进入
            state.postprocess_started = True
            state.phase = Phase.PROCESSING
            gen = state.generation

            # 在锁内做快照，之后锁外执行串行后处理
            snapshot = copy.deepcopy(state.results)
            errors = copy.deepcopy(state.errors)

        try:
            # 串行后处理，不持有 state.lock
            output = self.postprocessor(snapshot, errors)
        except Exception as e:
            with state.lock:
                if state.generation == gen and state.phase == Phase.PROCESSING:
                    state.phase = Phase.FAILED
                    state.error = e
                    state.cv.notify_all()
            return

        with state.lock:
            if state.generation == gen and state.phase == Phase.PROCESSING:
                state.output = output
                state.phase = Phase.DONE
                state.cv.notify_all()

    def _watchdog(self):
        """全局看门狗，防止任何线程永久阻塞。"""
        state = self.state
        deadline = self.overall_deadline

        with state.lock:
            while state.phase not in (Phase.DONE, Phase.FAILED):
                remaining = deadline - time.monotonic()
                if remaining <= 0:
                    state.phase = Phase.FAILED
                    state.error = TimeoutError("overall task timeout")
                    state.cv.notify_all()
                    return
                state.cv.wait(timeout=min(1.0, remaining))

    def wait(self, timeout: float | None = None):
        state = self.state
        with state.lock:
            deadline = None if timeout is None else time.monotonic() + timeout

            while state.phase not in (Phase.DONE, Phase.FAILED):
                if deadline is not None:
                    remaining = deadline - time.monotonic()
                    if remaining <= 0:
                        raise TimeoutError("wait task timeout")
                    state.cv.wait(timeout=remaining)
                else:
                    state.cv.wait()

            if state.phase == Phase.FAILED:
                raise RuntimeError(state.error)

            return state.output
```

## 3. API 调用与内容校验

```python
TIMEOUT_BY_MODEL = {
    "turbo": 300.0,
    "A": 600.0,
}


def call_api(spec: ApiCallSpec):
    body = json.dumps(spec.payload).encode("utf-8")
    req = urllib.request.Request(spec.url, data=body, method="POST")
    req.add_header("Content-Type", "application/json")
    # req.add_header("Authorization", "Bearer ...")

    # 关键：显式绕过全局代理
    opener = urllib.request.build_opener(
        urllib.request.ProxyHandler({})
    )

    with opener.open(req, timeout=spec.timeout_seconds) as resp:
        raw = resp.read().decode("utf-8")

    return json.loads(raw)


def _text_of(content):
    if content is None:
        return ""
    if isinstance(content, str):
        return content.strip()
    if isinstance(content, list):
        parts = []
        for item in content:
            if isinstance(item, dict):
                parts.append(item.get("text", ""))
            else:
                parts.append(str(item))
        return "".join(parts).strip()
    if isinstance(content, dict):
        return (content.get("text") or "").strip()
    return str(content).strip()


def validate_content(result):
    if not isinstance(result, dict):
        raise ValueError("API result must be dict")

    content = result.get("content", result.get("output_text"))

    # 防 Responses API 把 output_tokens 全耗在 reasoning 上，content 为空
    if not _text_of(content):
        raise ValueError("API response content is empty")

    return result
```

## 4. 为什么能规避历史坑

| 历史坑 | 本方案处理方式 |
|---|---|
| 全局代理导致 ProxyError | 统一用 `urllib`，并显式 `ProxyHandler({})` 直连，不引入 `requests` |
| API 调用超时 | 每个 `ApiCallSpec` 带 timeout，按模型配置：turbo 300s，A 600s |
| Responses API content 为空 | `validate_content` 强制校验，空 content 直接记为 error，不进后处理 |
| 配置修改后未生效 | timeout 从 `TIMEOUT_BY_MODEL` 读取，任务构造时读取，修改后新任务立即生效 |
| 多线程写结果互相覆盖 | 每个 `call_id` 独立分段，写入时持有 `state.lock` |
| 后处理过早启动 | `remaining` 计数 + `Condition`，锚点1未到不会进入 `READY` |
| 后处理重复进入 | `postprocess_started` + `PROCESSING` 状态，保证串行 |
| 迟到响应污染下一轮 | `generation` 交叉校验，旧线程结果直接丢弃 |

## 5. 验证建议

启动前先做单测：

1. mock 一个 API 返回空 content → 任务应 `FAILED`，后处理不执行。
2. mock 一个 API 超时 → 任务应在 deadline 后 `FAILED`。
3. 两个 API 并发，后处理打印结果 → 必须两个结果都到达后才打印。
4. 强制模拟迟到返回 → `generation` 不匹配，结果被丢弃。
5. 修改 timeout 配置后，跑一条冒烟任务，确认 `wait()` 正常返回且 `phase == DONE`。

这套方案本质是：

- **锁不保护 API 调用，只保护状态机转换**；
- **API 调用和后处理都在锁外执行**；
- **所有等待都有超时**；
- **所有写入都做 generation + phase + remaining 三源交叉校验**。
