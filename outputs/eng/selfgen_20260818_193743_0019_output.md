# 任务类型: eng

## 修复方案：L4 成品转化支持 code / checklist

### 根因

L4 成品转化目前只在三处支持 `sop`，导致 `code` / `checklist` 虽然进入了 L4 队列，却无法完成“从无到有”的转化：

1. 配置/常量写死：`SUPPORTED_TYPES = ["sop"]`
2. 仓储层查询写死：只查 `type = 'sop'`
3. 转化器缺少 `CodeConverter` / `ChecklistConverter`

本质上是闭环失控：数据已经存在，但没有为 `code` / `checklist` 建立“成品坐标”，所以它们仍停留在“无”的状态。

---

## 一、代码修改点

### 1. 配置：声明三类成品和模型超时

`config/l4.yaml`

```yaml
l4:
  types:
    - sop
    - code
    - checklist

  converters:
    sop: src.l4.converters.sop.SopConverter
    code: src.l4.converters.code.CodeConverter
    checklist: src.l4.converters.checklist.ChecklistConverter

  timeout:
    turbo: 300      # B模型 turbo
    default: 600    # A模型
```

> 避坑：新增配置必须同步修改读取点，不能只加配置。

---

### 2. 常量读取配置，不再写死

`src/l4/constants.py`

```python
# 原：
# SUPPORTED_TYPES = ["sop"]

from src.config import settings

SUPPORTED_TYPES = settings.l4.types
```

这样配置和读取点同步更新，避免“配置修改后未生效”。

---

### 3. 转化器：策略分发，拒绝静默跳过

`src/l4/converter.py`

```python
class L4Converter:
    def __init__(self):
        self._converters = {
            "sop": SopConverter(),
            "code": CodeConverter(),
            "checklist": ChecklistConverter(),
        }

    def convert(self, artifact):
        converter = self._converters.get(artifact["type"])
        if converter is None:
            raise L4ConversionError(
                f"unsupported type: {artifact['type']}, "
                f"supported={list(self._converters)}"
            )
        return converter.convert(artifact)
```

关键点：**未知类型必须报错，不能静默跳过**，否则闭环失控。

---

### 4. 新增 `CodeConverter`

`src/l4/converters/code.py`

```python
class CodeConverter:
    def convert(self, artifact):
        timeout = 600 if artifact.get("model_family") == "A" else 300

        code = self._generate_code(
            artifact,
            timeout=timeout,
        )

        if not code.syntax_check():
            raise L4ConversionError("code syntax check failed")

        return Product(
            product_type="code",
            ref_id=artifact["id"],
            payload={
                "language": code.language,
                "entrypoint": code.entrypoint,
                "code_body": code.body,
                "dependency_hash": hash_deps(code.dependencies),
                "test_command": code.test_command,
            }
        )
```

---

### 5. 新增 `ChecklistConverter`

`src/l4/converters/checklist.py`

```python
class ChecklistConverter:
    def convert(self, artifact):
        timeout = 600 if artifact.get("model_family") == "A" else 300

        items = self._extract_checklist(
            artifact,
            timeout=timeout,
        )

        for item in items:
            if not item.get("item") or not item.get("pass_condition"):
                raise L4ConversionError(f"invalid check item: {item}")

        return Product(
            product_type="checklist",
            ref_id=artifact["id"],
            payload={
                "check_items": items,
                "verification_status": "pending",
                "evidence": [],
            }
        )
```

### 6. 仓储层：查询所有 L4 类型

`src/l4/repository.py`

```python
# 原：
# rows = supabase.table("l4_artifacts").select("*").eq("type", "sop").execute()

rows = (
    supabase.table("l4_artifacts")
    .select("*")
    .in_("type", SUPPORTED_TYPES)
    .eq("status", "ready")
    .execute()
)
```

---

### 7. 后处理：增加 code / checklist 质检闭环

`src/l4/postprocess.py`

```python
def validate_code(product):
    assert product["product_type"] == "code"
    assert product["payload"]["code_body"]
    assert product["payload"]["entrypoint"]
    assert product["payload"]["test_command"]


def validate_checklist(product):
    assert product["product_type"] == "checklist"
    assert len(product["payload"]["check_items"]) > 0

    for item in product["payload"]["check_items"]:
        assert item["item"]
        assert item["pass_condition"]
```

转化完成后必须调用对应 validator，失败则重试或告警，不能吞掉。

## 二、验证方法

### 1. 单元测试

在 `tests/test_l4_converter.py` 中增加：

- 构造 `type="code"` artifact，断言输出 `product_type == "code"`，且 payload 包含 `code_body`。
- 构造 `type="checklist"` artifact，断言输出 `product_type == "checklist"`，且 `check_items` 非空。
- 构造未知类型，断言抛出 `L4ConversionError`。

运行：

```bash
python -m pytest tests/test_l4_converter.py -v
```

---

### 2. 数据库冒烟验证

在 Supabase `l4_artifacts` 插入一条测试记录：

```sql
INSERT INTO l4_artifacts (id, type, status, file_path, chunk_id, revision)
VALUES ('smoke-code-001', 'code', 'ready', 'scripts/test.py', 'chunk-1', 1);
```

执行转化：

```bash
python -m src.l4.converter --artifact-id smoke-code-001
```

验证产物表：

```sql
SELECT product_type, payload->>'language', payload->>'entrypoint'
FROM l4_products
WHERE ref_id = 'smoke-code-001';
```

应返回一行 `code` 记录。

`checklist` 同理：

```sql
INSERT INTO l4_artifacts (id, type, status, file_path, chunk_id, revision)
VALUES ('smoke-checklist-001', 'checklist', 'ready', 'docs/check.md', 'chunk-2', 1);
```

执行后检查：

```sql
SELECT product_type, jsonb_array_length(payload->'check_items')
FROM l4_products
WHERE ref_id = 'smoke-checklist-001';
```

## 三、风险与回滚

风险等级：**low**。

回滚方式：

- 将 `l4.types` 改回 `["sop"]`；
- 或保留旧 `L4Converter` 入口。

不会影响已有 SOP 数据。

本次修复已同步修改配置和读取点，避免“配置改了但读取点没改”的历史坑。API 超时也按模型族区分：B模型 turbo 用 300 秒，A模型用 600 秒，防止转化超时导致半成品状态。
