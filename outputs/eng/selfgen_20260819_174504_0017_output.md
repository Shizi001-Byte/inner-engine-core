# 任务类型: eng

下面给出一种**不依赖外部守护进程**的引擎自愈架构：把“引擎”定义为一个**多实例集群**，每个实例内部都内置心跳、恢复、执行器；状态机事实源放在 **Supabase Postgres（SP实）**。  
> 物理边界：如果只有一个进程且被 `kill -9`，进程内代码不可能再运行。所以高可用需要至少 2 个引擎实例；但它们互相发现、互相接管，不需要 systemd / supervisor / k8s 这类外部守护进程。

---

## 1. 架构总览

```text
Engine Instance A                          Engine Instance B
┌───────────────────────────┐             ┌───────────────────────────┐
│ RecoveryMonitor           │             │ RecoveryMonitor           │
│ InstanceHeartbeat         │             │ InstanceHeartbeat         │
│ ExecutorPool              │             │ ExecutorPool              │
│  ├─ Worker 1              │             │  ├─ Worker 1              │
│  ├─ Worker 2              │             │  └─ Worker 2              │
│ ConfigService             │             │ ConfigService             │
│ ApiClient / QualityGate   │             │ ApiClient / QualityGate   │
└────────────┬──────────────┘             └────────────┬──────────────┘
             │                                          │
             └───────────────┬──────────────────────────┘
                             ▼
                  Supabase PostgreSQL
                  - ai_task         任务状态机
                  - engine_instance 实例心跳
                  - app_config      动态配置
                  - api_outbox      幂等调用记录
                  - task_events     状态变更事件
```

核心原则：

- **所有状态以数据库为准**，内存只是缓存。
- **任务状态机升维为分布式状态机**：`PENDING -> RUNNING -> SUCCEEDED/FAILED`
- **每个关键步骤先持久化 checkpoint，再执行下一步**，避免“8月认知陷阱欠账”。
- **不同模型使用不同超时与质量规则**，尤其是 B 模型 turbo 必须跳过 reasoning 占比检测。

```sql
-- 任务状态机
create table ai_task (
  id uuid primary key default gen_random_uuid(),
  task_type text not null,
  model text not null,
  input jsonb not null,
  status text not null default 'PENDING'
    check (status in ('PENDING','RUNNING','SUCCEEDED','FAILED','RECOVERING')),
  phase text not null default 'start',
  checkpoint jsonb not null default '{}',
  result jsonb,
  error jsonb,
  lease_owner text,
  lease_expire_at timestamptz,
  attempt int not null default 0,
  max_attempts int not null default 3,
  idempotency_key text unique,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

create index idx_task_claim on ai_task (status, lease_expire_at);
create index idx_task_owner on ai_task (lease_owner) where status = 'RUNNING';

-- 引擎实例心跳
create table engine_instance (
  instance_id text primary key,
  status text not null default 'UP',
  heartbeat_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

-- 动态配置
create table app_config (
  key text primary key,
  value jsonb not null,
  version bigint not null default 0,
  updated_at timestamptz not null default now()
);

-- 外部 API 调用幂等表
create table api_outbox (
  id uuid primary key default gen_random_uuid(),
  task_id uuid not null references ai_task(id),
  idempotency_key text not null unique,
  status text not null default 'CALLING'
    check (status in ('CALLING','SUCCEEDED','FAILED')),
  request jsonb not null,
  response jsonb,
  error jsonb,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

-- 状态变更事件，用于审计和重放
create table task_events (
  id bigserial primary key,
  task_id uuid not null,
  from_status text,
  to_status text,
  payload jsonb not null default '{}',
  created_at timestamptz not null default now()
);
```

### 3.1 配置服务：避免“配置修改后未生效”

```python
# config.py
import logging

logger = logging.getLogger(__name__)

class ConfigService:
    DEFAULTS = {
        # 核心避坑：B模型turbo 300秒，A模型 600秒
        "model_timeouts": {
            "a-model": 600,
            "b-turbo": 300,
        },
        "quality_gate": {
            "a-model": {
                "skip_reasoning_ratio": False,
                "max_reasoning_ratio": 0.85,
            },
            # B模型(turbo) reasoning 占比 70%-82% 是正常特性，必须跳过检测
            "b-turbo": {
                "skip_reasoning_ratio": True,
            },
        },
        "task_lease_seconds": 900,
        "scan_interval_seconds": 5,
        "instance_ttl_seconds": 30,
        "heartbeat_interval_seconds": 5,
    }

    def __init__(self, db):
        self.db = db
        self._cache = {}
        self._version = -1

    def reload(self):
        row = self.db.fetch_one(
            "SELECT value, version FROM app_config WHERE key = 'engine'"
        )
        if row and row["version"] != self._version:
            merged = {**self.DEFAULTS, **row["value"]}
            self._cache = merged
            self._version = row["version"]
            logger.info("config reloaded, version=%s", self._version)
        elif not row and self._version < 0:
            self._cache = self.DEFAULTS
            self._version = 0

    def get(self):
        return self._cache
```

每次 `Executor` 循环开始前调用 `config.reload()`，保证配置修改后下一次任务立即生效。

### 3.2 任务仓储：原子状态持久化

```python
# repo.py
class TaskRepository:
    def __init__(self, db):
        self.db = db

    def claim(self, worker_id):
        sql = """
        WITH candidate AS (
            SELECT id
            FROM ai_task
            WHERE status IN ('PENDING', 'RECOVERING')
               OR (status = 'RUNNING' AND lease_expire_at < now())
            ORDER BY created_at
            LIMIT 1
            FOR UPDATE SKIP LOCKED
        )
        UPDATE ai_task t
        SET status = 'RUNNING',
            lease_owner = :worker_id,
            lease_expire_at = now() + make_interval(secs => 900),
            heartbeat_at = now(),
            attempt = t.attempt + 1,
            version = t.version + 1,
            updated_at = now()
        FROM candidate c
        WHERE t.id = c.id
        RETURNING
            t.id,
            t.task_type,
            t.model,
            t.input,
            t.checkpoint,
            t.attempt,
            t.version,
            t.idempotency_key
        """
        return self.db.fetch_one(sql, {"worker_id": worker_id})

    def heartbeat(self, task_id, worker_id):
        sql = """
        UPDATE ai_task
        SET heartbeat_at = now(),
            lease_expire_at = now() + make_interval(secs => 900)
        WHERE id = :id AND lease_owner = :worker_id
        RETURNING id
        """
        return self.db.fetch_one(sql, {"id": task_id, "worker_id": worker_id}) is not None

    def save_checkpoint(self, task_id, worker_id, phase, checkpoint):
        sql = """
        UPDATE ai_task
        SET checkpoint = :checkpoint,
            phase = :phase,
            heartbeat_at = now(),
            lease_expire_at = now() + make_interval(secs => 900),
            version = version + 1,
            updated_at = now()
        WHERE id = :id AND lease_owner = :worker_id
        RETURNING version
        """
        row = self.db.fetch_one(sql, {
            "id": task_id,
            "worker_id": worker_id,
            "phase": phase,
            "checkpoint": checkpoint,
        })
        return row is not None

    def complete(self, task_id, worker_id, result, checkpoint):
        sql = """
        UPDATE ai_task
        SET status = 'SUCCEEDED',
            result = :result,
            checkpoint = :checkpoint,
            lease_owner = NULL,
            lease_expire_at = NULL,
            version = version + 1,
            updated_at = now()
        WHERE id = :id AND lease_owner = :worker_id
        RETURNING id
        """
        return self.db.fetch_one(sql, {
            "id": task_id,
            "worker_id": worker_id,
            "result": result,
            "checkpoint": checkpoint,
        }) is not None

    def fail(self, task_id, worker_id, error):
        sql = """
        UPDATE ai_task
        SET status = 'FAILED',
            error = :error,
            lease_owner = NULL,
            lease_expire_at = NULL,
            version = version + 1,
            updated_at = now()
        WHERE id = :id AND lease_owner = :worker_id
        RETURNING id
        """
        return self.db.fetch_one(sql, {
            "id": task_id,
            "worker_id": worker_id,
            "error": error,
        }) is not None
```

`FOR UPDATE SKIP LOCKED` 保证多实例并发领取任务时不会重复领取。

### 3.3 心跳机制

```python
# heartbeat.py
import threading
import time
import logging

logger = logging.getLogger(__name__)

class InstanceHeartbeat(threading.Thread):
    """引擎实例级心跳，证明本进程还活着。"""

    def __init__(self, db, instance_id, interval=5):
        super().__init__(daemon=True)
        self.db = db
        self.instance_id = instance_id
        self.interval = interval
        self._stop = threading.Event()

    def stop(self):
        self._stop.set()

    def run(self):
        while not self._stop.wait(self.interval):
            self.db.execute("""
                INSERT INTO engine_instance (instance_id, status, heartbeat_at)
                VALUES (:id, 'UP', now())
                ON CONFLICT (instance_id)
                DO UPDATE SET status = 'UP', heartbeat_at = now(), updated_at = now()
            """, {"id": self.instance_id})
```

```python
class HeartbeatThread(threading.Thread):
    """任务级心跳，保证长 API 调用期间租约不过期。"""

    def __init__(self, repo, task_id, worker_id, interval=15):
        super().__init__(daemon=True)
        self.repo = repo
        self.task_id = task_id
        self.worker_id = worker_id
        self.interval = interval
        self._stop = threading.Event()
        self.lost = False

    def stop(self):
        self._stop.set()

    def run(self):
        while not self._stop.wait(self.interval):
            if not self.repo.heartbeat(self.task_id, self.worker_id):
                self.lost = True
                logger.warning("task lease lost: %s", self.task_id)
                return
```

### 3.4 恢复扫描器：检测崩溃并接管

```python
# recovery.py
import threading
import time
import logging

logger = logging.getLogger(__name__)

class RecoveryMonitor(threading.Thread):
    """
    引擎内部恢复器：
    1. 发现心跳超时的引擎实例，将其 RUNNING 任务重置为 PENDING。
    2. 发现租约过期的任务，重置为 PENDING，交给其他 Worker 领取。
    """

    def __init__(self, db, instance_id, config):
        super().__init__(daemon=True)
        self.db = db
        self.instance_id = instance_id
        self.config = config

    def run(self):
        while True:
            cfg = self.config.get()
            time.sleep(cfg["scan_interval_seconds"])
            try:
                self._recover(cfg)
            except Exception:
                logger.exception("recovery scan failed")

    def _recover(self, cfg):
        ttl = cfg["instance_ttl_seconds"]

        # 1. 找到心跳超时的实例
        stale_instances = self.db.fetch_all("""
            SELECT instance_id
            FROM engine_instance
            WHERE status = 'UP'
              AND heartbeat_at < now() - make_interval(secs => :ttl)
        """, {"ttl": ttl})

        for inst in stale_instances:
            prefix = inst["instance_id"] + "%"
            with self.db.transaction():
                # 将该实例上所有 RUNNING 任务释放
                self.db.execute("""
                    UPDATE ai_task
                    SET status = 'PENDING',
                        lease_owner = NULL,
                        lease_expire_at = NULL,
                        version = version + 1,
                        updated_at = now()
                    WHERE status = 'RUNNING'
                      AND lease_owner LIKE :prefix
                """, {"prefix": prefix})

                self.db.execute("""
                    UPDATE engine_instance
                    SET status = 'DOWN', updated_at = now()
                    WHERE instance_id = :id
                """, {"id": inst["instance_id"]})

                logger.warning("engine instance marked DOWN: %s", inst["instance_id"])

        # 2. 释放租约过期的任务
        self.db.execute("""
            UPDATE ai_task
            SET status = 'PENDING',
                lease_owner = NULL,
                lease_expire_at = NULL,
                version = version + 1,
                updated_at = now()
            WHERE status = 'RUNNING'
              AND lease_expire_at < now()
        """)
```

### 3.5 执行器：checkpoint 断点续跑

```python
# executor.py
import threading
import time
import logging

logger = logging.getLogger(__name__)

class LostLease(Exception):
    pass

class TaskExecutor:
    def __init__(self, repo, api_client, quality_gate, config, worker_id):
        self.repo = repo
        self.api = api_client
        self.quality = quality_gate
        self.config = config
        self.worker_id = worker_id
        self.stop = threading.Event()

    def run_forever(self):
        while not self.stop.is_set():
            # 每次循环先刷新配置，避免修改后不生效
            self.config.reload()

            task = self.repo.claim(self.worker_id)
            if not task:
                time.sleep(1)
                continue

            self._safe_execute(task)

    def _safe_execute(self, task):
        hb = HeartbeatThread(self.repo, task["id"], self.worker_id)
        hb.start()
        try:
            result = self._execute(task)
            self.repo.complete(task["id"], self.worker_id, result, task["checkpoint"])
        except LostLease:
            logger.warning("task %s lost lease, will be recovered by other worker", task["id"])
        except Exception as e:
            logger.exception("task %s failed", task["id"])
            self.repo.fail(task["id"], self.worker_id, {"message": str(e)})
        finally:
            hb.stop()

    def _execute(self, task):
        cp = dict(task["checkpoint"] or {})
        phase = cp.get("phase", "start")

        if phase == "start":
            # 实际业务可替换为预处理
            prepared = {"messages": task["input"].get("messages", [])}
            cp = {"phase": "api_call", "prepared": prepared}
            self._checkpoint(task, cp)
            phase = "api_call"

        if phase == "api_call":
            # 长任务期间心跳线程会续租；API 超时由 ApiClient 控制
            response = self.api.call(
                model=task["model"],
                messages=cp["prepared"],
                idempotency_key=task["idempotency_key"],
            )
            cp = {"phase": "quality", "response": response}
            self._checkpoint(task, cp)
            phase = "quality"

        if phase == "quality":
            q = self.quality.check(task["model"], cp["response"])
            if not q.ok:
                raise RuntimeError(f"quality gate failed: {q.reason}")
            cp = {"phase": "done", "result": cp["response"]}
            self._checkpoint(task, cp)
            phase = "done"

        if phase == "done":
            return cp["result"]

        raise RuntimeError(f"unknown phase: {phase}")

    def _checkpoint(self, task, cp):
        ok = self.repo.save_checkpoint(
            task["id"],
            self.worker_id,
            cp.get("phase", "unknown"),
            cp,
        )
        if not ok:
            raise LostLease()
        task["checkpoint"] = cp
```

### 3.6 模型 API 客户端：超时 + 幂等

```python
# api_client.py
import json
import requests

class ApiClient:
    def __init__(self, db, config):
        self.db = db
        self.config = config

    def call(self, model, messages, idempotency_key):
        cfg = self.config.get()

        # 核心避坑：B模型turbo用300秒，A模型用600秒
        timeout = cfg["model_timeouts"].get(model, 300)

        # 幂等：如果之前已经成功，直接返回成功响应
        existing = self.db.fetch_one("""
            SELECT response
            FROM api_outbox
            WHERE idempotency_key = :key AND status = 'SUCCEEDED'
        """, {"key": idempotency_key})
        if existing:
            return existing["response"]

        # 写入 outbox，标记正在调用
        self.db.execute("""
            INSERT INTO api_outbox (id, task_id, idempotency_key, status, request)
            VALUES (gen_random_uuid(), :task_id, :key, 'CALLING', :req)
            ON CONFLICT (idempotency_key)
            DO UPDATE SET status = 'CALLING', updated_at = now()
        """, {
            "task_id": self._task_id_from_key(idempotency_key),
            "key": idempotency_key,
            "req": json.dumps(messages),
        })

        # 这里根据 model 选择真实 endpoint
        resp = requests.post(
            self._endpoint(model),
            json={"model": model, "messages": messages},
            headers={"Idempotency-Key": idempotency_key},
            timeout=timeout,
        )
        resp.raise_for_status()
        data = resp.json()

        self.db.execute("""
            UPDATE api_outbox
            SET status = 'SUCCEEDED', response = :resp, updated_at = now()
            WHERE idempotency_key = :key
        """, {"resp": json.dumps(data), "key": idempotency_key})

        return data

    def _endpoint(self, model):
        # 实际按模型路由
        return "https://api.example.com/v1/chat/completions"

    def _task_id_from_key(self, idempotency_key):
        # idempotency_key 格式可设计为 task_id:uuid
        return idempotency_key.split(":")[0]
```

### 3.7 质量门禁：B 模型跳过 reasoning 占比检测

```python
# quality.py
class QualityResult:
    def __init__(self, ok, reason=""):
        self.ok = ok
        self.reason = reason

class QualityGate:
    def __init__(self, config):
        self.config = config

    def check(self, model, response):
        rules = self.config.get()["quality_gate"].get(model, {})

        # B模型(turbo) 的 reasoning 占比 70%-82% 是正常特性，不能判废稿
        if rules.get("skip_reasoning_ratio", False):
            return QualityResult(True)

        usage = response.get("usage", {})
        total = usage.get("total_tokens", 0)
        reasoning = usage.get("reasoning_tokens", 0)
        ratio = reasoning / max(total, 1)

        max_ratio = rules.get("max_reasoning_ratio", 0.85)
        if ratio > max_ratio:
            return QualityResult(False, f"reasoning_ratio={ratio:.2f}")

        return QualityResult(True)
```

### 3.8 Worker 线程池自愈

```python
# pool.py
import threading
import time
import logging

logger = logging.getLogger(__name__)

class ExecutorPool:
    """监控 Worker 线程，如果线程异常退出，自动重启新线程。"""

    def __init__(self, executor_factory, size=4):
        self.executor_factory = executor_factory
        self.size = size
        self.threads = []

    def start(self):
        for _ in range(self.size):
            self._spawn()

    def _spawn(self):
        t = threading.Thread(target=self._run_worker, daemon=True)
        t.start()
        self.threads.append(t)

    def _run_worker(self):
        while True:
            try:
                executor = self.executor_factory()
                executor.run_forever()
            except Exception:
                logger.exception("worker crashed, restarting in 1s")
                time.sleep(1)
```

### 3.9 主入口

```python
# main.py
import os
import uuid

def main():
    db = DB()
    config = ConfigService(db)
    config.reload()

    instance_id = os.environ["ENGINE_INSTANCE_ID"]
    worker_id = f"{instance_id}:{uuid.uuid4()}"

    repo = TaskRepository(db)
    api_client = ApiClient(db, config)
    quality_gate = QualityGate(config)

    # 实例心跳
    heartbeat = InstanceHeartbeat(db, instance_id, interval=config.get()["heartbeat_interval_seconds"])
    heartbeat.start()

    # 崩溃恢复扫描
    recovery = RecoveryMonitor(db, instance_id, config)
    recovery.start()

    # 执行器线程池
    pool = ExecutorPool(
        executor_factory=lambda: TaskExecutor(repo, api_client, quality_gate, config, worker_id),
        size=4,
    )
    pool.start()

    # 主线程保持运行
    while True:
        time.sleep(60)
```

## 4. 崩溃恢复时序

场景：实例 A 处理任务，执行到 `api_call` 阶段，然后 A 被 `kill -9`。

```text
1. A 的 InstanceHeartbeat 停止更新 engine_instance.heartbeat_at。
2. B 的 RecoveryMonitor 扫描到 A 心跳超时。
3. B 将 A 所有 RUNNING 任务重置为 PENDING：
   - lease_owner = NULL
   - lease_expire_at = NULL
   - status = 'PENDING'
4. B 的 Executor 通过 claim 领取该任务。
5. 读取 task.checkpoint：
   - phase = "api_call"
   - prepared = {...}
6. 从 api_call 阶段继续执行，而不是从头开始。
7. 如果 api_outbox 中已有成功响应，直接复用；否则使用同一个 idempotency_key 重放请求。
```

## 5. 历史踩坑点映射

| 坑 | 规避方式 |
|---|---|
| 配置修改后未生效 | `ConfigService.reload()` 每次循环都执行；配置带 `version`，版本变化才更新内存 |
| API 调用超时 | `ApiClient` 按模型读取 timeout：`b-turbo=300s`，`a-model=600s` |
| B 模型 reasoning 占比 70%-82% 被误判废稿 | `QualityGate` 按模型独立配置，`b-turbo` 跳过 `reasoning_ratio` 检测 |
| 崩溃后丢状态 | checkpoint 在每一步之前持久化；恢复时从 `phase` 续跑 |
| 外部 API 重复调用 | `api_outbox` + `Idempotency-Key` 保证幂等 |

   提交一个 `b-turbo` 响应，`reasoning_tokens / total_tokens = 0.78`，任务应成功，不会被重试。
