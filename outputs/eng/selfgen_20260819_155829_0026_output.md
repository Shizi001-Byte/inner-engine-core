# 任务类型: eng

## 核心结论

**不依赖外部守护进程的“崩溃自动恢复”**，本质是：

- 引擎启动时自动检测上次是否崩溃；
- 如果崩溃，自动从最近持久化检查点恢复；
- 如果只是线程/协程卡死，内部 watchdog 可以直接重置任务；
- 如果是进程被 `kill -9`，进程自身无法在死亡瞬间执行代码，所以恢复动作发生在**下次启动时**。  
  如果要求无人值守自动拉起，需要一个**极简父进程/launcher**，但它不是业务守护进程，可以内置在引擎入口脚本中。

---

```text
│ Engine                                                │
│                                                      │
│  main loop ──调度任务──> Worker threads              │
│      │                       │                       │
│      │               execute_step(step, task, beat)  │
│      │                       │                       │
│      └────── StateStore ◄────┘                       │
│                 │                                    │
│                 ├─ engine_state.json  (原子快照)      │
│                 ├─ engine_state.wal  (WAL 日志)       │
│                 └─ heartbeat.json    (心跳/PID)       │
│                                                      │
│  heartbeat thread ──> 定期写 heartbeat.json          │
│  watchdog thread  ──> 检查 worker 心跳/主循环进度     │
└──────────────────────────────────────────────────────┘
```

---

## 关键机制

### 1. 心跳检测

- Worker 每次执行步骤时调用 `beat()`，更新内存心跳。
- 引擎心跳线程定期把 `pid + timestamp + seq` 原子写入 `heartbeat.json`。
- 下次启动时：
  - 如果 `heartbeat.json` 里记录的 PID 已不存在，且状态是 `running`，判定为崩溃；
  - 如果 PID 还活着，说明可能有另一个引擎实例在运行，直接报错，避免双主；
  - 如果 `heartbeat.json` 状态是 `stopped`，说明是正常关闭，不需要恢复。

### 2. 状态原子持久化

使用 **Snapshot + WAL**：

- 所有状态变更先追加到 WAL，`fsync` 落盘；
- 定期或任务完成时生成快照，通过 `write temp → fsync → rename` 原子替换；
- 快照写入后截断 WAL；
- 启动时加载最近快照，再重放 WAL 中 `seq > snapshot.last_seq` 的记录。

这样即使崩溃发生在两次快照之间，也不会丢失已提交的检查点。

### 3. 断点续跑

- 每个任务保存 `checkpoint = {step, data}`；
- 崩溃恢复时，`running` 任务被重置为 `pending`，但**保留 checkpoint**；
- 重新调度后，从 `checkpoint.step` 继续执行，而不是从头开始；
- 所有步骤必须**幂等**，外部调用必须带 `idempotency_key`。

```python
import json
import os
import threading
import time
import uuid
from pathlib import Path
from typing import Any, Callable, Optional

import logging

logger = logging.getLogger(__name__)


def _fsync_dir(path: Path):
    """对目录做 fsync，确保 rename 落盘。"""
    try:
        fd = os.open(path, os.O_DIRECTORY)
        try:
            os.fsync(fd)
        finally:
            os.close(fd)
    except (AttributeError, OSError):
        pass


# ----------------------------------------------------------------
# StateStore：原子快照 + WAL
# ----------------------------------------------------------------
class StateStore:
    def __init__(self, base_dir: str):
        self.base_dir = Path(base_dir)
        self.base_dir.mkdir(parents=True, exist_ok=True)

        self.snapshot_path = self.base_dir / "engine_state.json"
        self.wal_path = self.base_dir / "engine_state.wal"

        self.lock = threading.RLock()
        self._seq = 0

    # ---------- 读取 ----------
    def load(self) -> dict:
        with self.lock:
            state = self._read_snapshot()
            self._seq = state.get("last_seq", 0)

            for rec in sorted(self._read_wal(), key=lambda x: x.get("seq", 0)):
                if rec["seq"] > state.get("last_seq", 0):
                    self._apply(state, rec)
                    self._seq = max(self._seq, rec["seq"])

            state["last_seq"] = self._seq
            return state

    def _read_snapshot(self) -> dict:
        if not self.snapshot_path.exists():
            return {
                "engine_id": uuid.uuid4().hex,
                "status": "stopped",
                "generation": 0,
                "last_seq": 0,
                "tasks": {},
                "resume_queue": [],
            }

        with open(self.snapshot_path, "r", encoding="utf-8") as f:
            state = json.load(f)

        state.setdefault("tasks", {})
        state.setdefault("resume_queue", [])
        return state

    def _read_wal(self) -> list:
        if not self.wal_path.exists():
            return []

        records = []
        with open(self.wal_path, "r", encoding="utf-8") as f:
            for line in f:
                line = line.strip()
                if not line:
                    continue
                try:
                    records.append(json.loads(line))
                except json.JSONDecodeError:
                    # 最后一行可能因为崩溃写了一半，忽略
                    continue
        return records

    # ---------- 写入 ----------
    def append_wal(self, record: dict) -> dict:
        with self.lock:
            self._seq += 1
            record["seq"] = self._seq
            record["ts"] = time.time()

            with open(self.wal_path, "a", encoding="utf-8") as f:
                f.write(json.dumps(record, ensure_ascii=False) + "\n")
                f.flush()
                os.fsync(f.fileno())

            return record

    def write_snapshot(self, state: dict) -> None:
        with self.lock:
            state["last_seq"] = self._seq
            self._write_snapshot(state)

    def compact(self, state: dict) -> None:
        """写快照并截断 WAL。"""
        with self.lock:
            state["last_seq"] = self._seq
            self._write_snapshot(state)

            with open(self.wal_path, "w", encoding="utf-8") as f:
                f.flush()
                os.fsync(f.fileno())

            _fsync_dir(self.base_dir)

    def maybe_compact(self, state: dict, max_wal_bytes: int = 10 * 1024 * 1024) -> None:
        if self.wal_path.exists() and self.wal_path.stat().st_size > max_wal_bytes:
            self.compact(state)

    def _write_snapshot(self, state: dict) -> None:
        tmp = self.snapshot_path.with_suffix(".tmp")
        with open(tmp, "w", encoding="utf-8") as f:
            json.dump(state, f, ensure_ascii=False, indent=2)
            f.flush()
            os.fsync(f.fileno())

        os.replace(tmp, self.snapshot_path)
        _fsync_dir(self.base_dir)

    # ---------- WAL 回放 ----------
    def apply_to_state(self, state: dict, record: dict) -> None:
        with self.lock:
            self._apply(state, record)

    def _apply(self, state: dict, rec: dict) -> None:
        ttype = rec.get("type")
        tid = rec.get("task_id")
        payload = rec.get("payload", {})
        ts = rec.get("ts", time.time())

        if ttype == "task_register":
            state["tasks"][tid] = {
                "task_id": tid,
                "status": "pending",
                "checkpoint": payload.get("initial_checkpoint", {"step": "init", "data": {}}),
                "attempts": 0,
                "max_attempts": payload.get("max_attempts", 3),
                "run_id": None,
                "result": None,
                "error": None,
                "updated_at": ts,
            }
            return

        task = state["tasks"].get(tid)
        if task is None:
            return

        if ttype == "task_start":
            task["status"] = "running"
            task["run_id"] = payload.get("run_id")
            task["attempts"] = payload.get("attempts", task["attempts"] + 1)
            task["updated_at"] = ts

        elif ttype == "task_checkpoint":
            if task["run_id"] is None or payload.get("run_id") == task["run_id"]:
                task["checkpoint"] = {
                    "step": payload.get("step", task["checkpoint"]["step"]),
                    "data": payload.get("data", {}),
                }
                task["updated_at"] = ts

        elif ttype == "task_complete":
            if task["run_id"] is None or payload.get("run_id") == task["run_id"]:
                task["status"] = "completed"
                task["result"] = payload.get("result")
                task["run_id"] = None
                task["updated_at"] = ts

        elif ttype == "task_failed":
            task["status"] = "failed"
            task["error"] = payload.get("error")
            task["run_id"] = None
            task["updated_at"] = ts

        elif ttype == "task_reset":
            task["status"] = "pending"
            task["run_id"] = None
            task["error"] = None
            task["updated_at"] = ts


# ----------------------------------------------------------------
# Heartbeat：进程级心跳
# ----------------------------------------------------------------
class Heartbeat:
    def __init__(self, base_dir: str, engine_id: str):
        self.path = Path(base_dir) / "heartbeat.json"
        self.engine_id = engine_id
        self.lock = threading.RLock()

    def write(self, state: dict, status: str = "running") -> dict:
        with self.lock:
            data = {
                "engine_id": self.engine_id,
                "pid": os.getpid(),
                "status": status,
                "ts": time.time(),
                "seq": state.get("last_seq", 0),
                "generation": state.get("generation", 0),
            }

            tmp = self.path.with_suffix(".tmp")
            with open(tmp, "w", encoding="utf-8") as f:
                json.dump(data, f)
                f.flush()
                os.fsync(f.fileno())

            os.replace(tmp, self.path)
            _fsync_dir(self.path.parent)
            return data

    def read(self) -> Optional[dict]:
        try:
            with open(self.path, "r", encoding="utf-8") as f:
                return json.load(f)
        except FileNotFoundError:
            return None


# ----------------------------------------------------------------
# Executor：业务步骤执行器，必须幂等
# ----------------------------------------------------------------
class Executor:
    def execute_step(self, step: str, task: dict, beat: Callable[[], None]):
        raise NotImplementedError


# ----------------------------------------------------------------
# Worker：单个任务执行线程
# ----------------------------------------------------------------
class Worker:
    def __init__(self, engine, task_id: str, run_id: str):
        self.engine = engine
        self.task_id = task_id
        self.run_id = run_id

        self.last_beat = time.time()
        self.status = "running"  # running / done / abandoned
        self.thread = threading.Thread(target=self._run, daemon=True)

    def start(self):
        self.thread.start()

    def beat(self):
        self.last_beat = time.time()
        self.engine.record_progress()

    def _run(self):
        try:
            task = self.engine.state["tasks"][self.task_id]

            while True:
                step = task["checkpoint"]["step"]
                next_step, result = self.engine.executor.execute_step(step, task, self.beat)

                if next_step is None:
                    self.engine.complete_task(self.task_id, self.run_id, result)
                    break
                else:
                    self.engine.checkpoint_task(self.task_id, self.run_id, next_step, result)

        except Exception as e:
            self.engine.fail_task(self.task_id, self.run_id, e)
        finally:
            self.status = "done"


# ----------------------------------------------------------------
# Engine：主引擎
# ----------------------------------------------------------------
class Engine:
    def __init__(
        self,
        base_dir: str,
        executor: Executor,
        config: Optional[dict] = None,
        heartbeat_interval: float = 5.0,
        heartbeat_timeout: float = 30.0,
    ):
        self.base_dir = Path(base_dir)
        self.config = config or {}

        self.store = StateStore(self.base_dir)
        self.state = self.store.load()
        self.executor = executor

        self.heartbeat = Heartbeat(self.base_dir, self.state["engine_id"])
        self.heartbeat_interval = heartbeat_interval
        self.heartbeat_timeout = heartbeat_timeout

        self.workers = {}
        self.worker_lock = threading.RLock()

        self.running = False
        self.last_progress_ts = time.time()
        self.last_progress_seq = 0

    # ---------- 启动/停止 ----------
    def start(self):
        if self.running:
            return

        self.recover_if_needed()
        self.running = True

        threading.Thread(target=self._heartbeat_loop, daemon=True).start()
        threading.Thread(target=self._watchdog_loop, daemon=True).start()

        self._main_loop()

    def stop(self):
        self.running = False

        for w in list(self.workers.values()):
            w.thread.join(timeout=5)

        self.state["status"] = "stopped"
        self.store.compact(self.state)
        self.heartbeat.write(self.state, status="stopped")

    # ---------- 任务注册 ----------
    def register_task(self, task_id: str, max_attempts: int = 3, initial_checkpoint: Optional[dict] = None):
        if task_id in self.state["tasks"]:
            raise ValueError(f"task {task_id} already exists")

        initial_checkpoint = initial_checkpoint or {"step": "init", "data": {}}

        rec = {
            "type": "task_register",
            "task_id": task_id,
            "payload": {
                "max_attempts": max_attempts,
                "initial_checkpoint": initial_checkpoint,
            },
        }
        rec = self.store.append_wal(rec)
        self.store.apply_to_state(self.state, rec)
        self.state["resume_queue"].append(task_id)

    # ---------- 崩溃检测与恢复 ----------
    def recover_if_needed(self):
        # 锚点校验：ID、端点、凭证哈希等，必须一致才能恢复
        self._validate_anchors()

        hb = self.heartbeat.read()

        if hb is not None and hb.get("engine_id") != self.state["engine_id"]:
            raise RuntimeError("heartbeat engine_id mismatch, abort")

        # 如果 heartbeat 显示有另一个活着的引擎实例，禁止启动，避免双主
        if hb is not None and hb.get("status") == "running" and self._pid_alive(hb.get("pid")):
            raise RuntimeError("another engine instance is running, abort to avoid split-brain")

        crashed = False

        if self.state["status"] == "running":
            crashed = True
        elif self.state["status"] == "recovering":
            crashed = True

        if crashed:
            self._recover()
        else:
            self.state["status"] = "running"
            self.heartbeat.write(self.state)

    def _recover(self):
        logger.warning("Engine crash detected, recovering...")

        self.state["generation"] += 1
        self.state["status"] = "recovering"
        self.state["resume_queue"] = []

        for tid, task in self.state["tasks"].items():
            if task["status"] == "running":
                # 回滚到最近 checkpoint，重新排队
                task["status"] = "pending"
                task["run_id"] = None
                task["error"] = None

                if task["attempts"] >= task["max_attempts"]:
                    task["status"] = "failed"
                    task["error"] = "max_attempts exceeded after crash"
                else:
                    self.state["resume_queue"].append(tid)

            elif task["status"] == "pending":
                self.state["resume_queue"].append(tid)

        self.state["status"] = "running"
        self.store.compact(self.state)
        self.heartbeat.write(self.state)

    def _validate_anchors(self):
        required = self.config.get("anchors")
        if not required:
            return

        state_anchors = self.state.get("anchors")
        if state_anchors is None:
            self.state["anchors"] = required
        elif state_anchors != required:
            raise RuntimeError(f"anchors mismatch: {state_anchors} != {required}")

    @staticmethod
    def _pid_alive(pid: Optional[int]) -> bool:
        if not pid:
            return False
        try:
            os.kill(pid, 0)
        except ProcessLookupError:
            return False
        except PermissionError:
            return True
        return True

    # ---------- 主循环 ----------
    def _main_loop(self):
        while self.running:
            self._reap_workers()

            tid = self._dequeue_task()
            if tid is None:
                time.sleep(0.2)
                continue

            run_id = self._start_task(tid)
            worker = Worker(self, tid, run_id)

            with self.worker_lock:
                self.workers[tid] = worker

            worker.start()

    def _dequeue_task(self) -> Optional[str]:
        with self.worker_lock:
            if not self.state["resume_queue"]:
                return None

            # 去重 + 只取 pending 任务
            seen = set()
            new_queue = []

            for tid in self.state["resume_queue"]:
                if tid in seen:
                    continue
                seen.add(tid)

                task = self.state["tasks"].get(tid)
                if task and task["status"] == "pending":
                    new_queue.append(tid)

            self.state["resume_queue"] = new_queue

            if new_queue:
                return new_queue.pop(0)

        return None

    def _start_task(self, task_id: str) -> str:
        task = self.state["tasks"][task_id]
        run_id = uuid.uuid4().hex

        rec = {
            "type": "task_start",
            "task_id": task_id,
            "payload": {
                "run_id": run_id,
                "attempts": task["attempts"] + 1,
            },
        }
        rec = self.store.append_wal(rec)
        self.store.apply_to_state(self.state, rec)

        return run_id

    def _reap_workers(self):
        with self.worker_lock:
            done = [tid for tid, w in self.workers.items() if w.status in ("done", "abandoned")]
            for tid in done:
                self.workers.pop(tid, None)

    # ---------- Worker 回调 ----------
    def record_progress(self):
        self.last_progress_ts = time.time()
        self.last_progress_seq = self.state.get("last_seq", 0)

    def checkpoint_task(self, task_id: str, run_id: str, next_step: str, data: dict):
        task = self.state["tasks"].get(task_id)
        if task is None or task["run_id"] != run_id:
            return

        rec = {
            "type": "task_checkpoint",
            "task_id": task_id,
            "payload": {
                "run_id": run_id,
                "step": next_step,
                "data": data,
            },
        }
        rec = self.store.append_wal(rec)
        self.store.apply_to_state(self.state, rec)
        self.store.maybe_compact(self.state)

        self.record_progress()

    def complete_task(self, task_id: str, run_id: str, result: Any):
        task = self.state["tasks"].get(task_id)
        if task is None or task["run_id"] != run_id:
            return

        rec = {
            "type": "task_complete",
            "task_id": task_id,
            "payload": {
                "run_id": run_id,
                "result": result,
            },
        }
        rec = self.store.append_wal(rec)
        self.store.apply_to_state(self.state, rec)
        self.store.compact(self.state)

        self.record_progress()

    def fail_task(self, task_id: str, run_id: str, error: Any):
        task = self.state["tasks"].get(task_id)
        if task is None or task["run_id"] != run_id:
            return

        # 还有重试次数则 reset 后重新排队
        if task["attempts"] < task["max_attempts"]:
            rec = {"type": "task_reset", "task_id": task_id, "payload": {}}
            rec = self.store.append_wal(rec)
            self.store.apply_to_state(self.state, rec)
            self.state["resume_queue"].append(task_id)
        else:
            rec = {
                "type": "task_failed",
                "task_id": task_id,
                "payload": {
                    "run_id": run_id,
                    "error": str(error),
                },
            }
            rec = self.store.append_wal(rec)
            self.store.apply_to_state(self.state, rec)

        self.record_progress()

    # ---------- 心跳线程 ----------
    def _heartbeat_loop(self):
        while self.running:
            self.heartbeat.write(self.state)
            time.sleep(self.heartbeat_interval)

    # ---------- Watchdog 线程 ----------
    def _watchdog_loop(self):
        while self.running:
            now = time.time()

            with self.worker_lock:
                workers = list(self.workers.items())

            # 检查单个 worker 是否卡死
            for tid, worker in workers:
                if worker.status == "running" and now - worker.last_beat > self.heartbeat_timeout:
                    logger.warning("worker heartbeat timeout: %s", tid)
                    self._handle_worker_hung(tid)

            # 如果有 worker 在跑，但引擎整体长时间无进度，说明主循环可能卡死
            with self.worker_lock:
                has_running = any(w.status == "running" for _, w in self.workers.items())

            if has_running and now - self.last_progress_ts > self.heartbeat_timeout:
                logger.error("no progress in engine, force exit to trigger recovery")
                os._exit(1)

            time.sleep(1)

    def _handle_worker_hung(self, task_id: str):
        with self.worker_lock:
            worker = self.workers.get(task_id)
            if worker is None or worker.status != "running":
                return
            worker.status = "abandoned"
            self.workers.pop(task_id, None)

        task = self.state["tasks"].get(task_id)
        if task is None:
            return

        if task["attempts"] < task["max_attempts"]:
            rec = {"type": "task_reset", "task_id": task_id, "payload": {}}
            rec = self.store.append_wal(rec)
            self.store.apply_to_state(self.state, rec)
            self.state["resume_queue"].append(task_id)
        else:
            rec = {
                "type": "task_failed",
                "task_id": task_id,
                "payload": {
                    "run_id": task.get("run_id"),
                    "error": "heartbeat timeout",
                },
            }
            rec = self.store.append_wal(rec)
            self.store.apply_to_state(self.state, rec)
```

```python
class DemoExecutor(Executor):
    def execute_step(self, step, task, beat):
        data = task["checkpoint"]["data"]

        if step == "init":
            beat()
            # 可以在这里做前置检查
            return "download", {"url": "https://example.com/data"}

        if step == "download":
            # 幂等：如果文件已存在且校验一致，直接跳过
            beat()
            return "parse", {"local_file": "/tmp/data.bin"}

            beat()
            # 业务处理
            return None, {"rows": 100}
```

## 可选：极简自拉起入口

如果要求进程被 `kill -9` 后无人干预也能自动拉起，需要一个父进程/launcher。它不属于业务守护进程，可以内置在入口脚本中：

```python
# bootstrap.py
import subprocess
import sys
import time


def main():
    if "--worker" in sys.argv:
        engine = Engine("./engine_data", DemoExecutor(), config=config)
        engine.start()
        return

    # 父进程只负责拉起和重启，不参与业务逻辑
    while True:
        proc = subprocess.Popen([sys.executable, "-m", "engine.bootstrap", "--worker"])
        code = proc.wait()

        if code == 0:
            break

        time.sleep(1)
```

## 避坑清单

1. **锚点校验优先于一切链路优化**  
   恢复前必须校验项目 ID、端点、凭证哈希、超时配置，否则可能把 A 项目的状态恢复到 B 项目上。

2. **心跳超时必须大于单步最大耗时**  
   比如 B 模型 turbo 单步 300 秒，A 模型单步 600 秒，则 `heartbeat_timeout` 至少设 700 秒，否则正常长任务会被误杀。

3. **断点续跑不是“从崩溃行继续”，而是“从上一个持久化检查点重新执行”**  
   所以每个步骤必须幂等，外部调用必须带 `idempotency_key`。

4. **不同模型必须有独立质量检测规则**  
   例如 B 模型 turbo 的 reasoning 占比 70%~82% 是正常特性，不能套用通用废稿检测规则。

5. **进程级崩溃无法在当前进程内自我恢复**  
   如果没有 launcher，恢复发生在下次启动时；这是物理边界，不能绕过。
