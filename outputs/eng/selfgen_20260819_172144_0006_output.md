# 任务类型: eng

# 引擎崩溃自动恢复机制：Guardian-Core 互监督 + WAL/Snapshot 断点续跑

> 本方案直接建立在 **Guardian-Core 双进程、WAL+Snapshot、单向同步与幂等优先** 的锚定之上，不重复论证底层自恢复；只推演“增量同步”这条 **ChainTask** 链：  
> `本地文件（实）→ 变化检测（虚/策略）→ 只传差异（实）→ 冲突处理（虚/策略）→ Supabase 认知池（实）→ 同步指标（实）→ 策略调优（虚）→ 更高效的下一轮同步（返实）`

---

## 0. 工程约束（避坑）

1. **配置修改后必须立即生效**  
   `ConfigCenter` 每次读取都检查文件 mtime，不缓存旧值；`StrategyTuner` 写配置后立即 `assert get() == set()` 验证。

2. **API 超时按模型独立设置**  
   `B-turbo` 默认 300 秒，`A` 默认 600 秒；超时后抛 `StepError`，由步骤重试机制处理。

3. **废稿检测不能误杀 B 模型**  
   `QualityGate` 按模型独立配置；`B-turbo` 跳过 `reasoning_ratio` 检测，因为其 70%–82% 的 reasoning 占比是正常特性。

---

## 1. 总体架构

```
+---------------------------+          heartbeat           +---------------------------+
|        core process       | <--------------------------> |       guardian process     |
|  - FileWatcher            |   + heartbeat files + locks  |  - 监控 core 心跳           |
|  - ChainTaskRunner        |                              |  - 重启 core               |
|  - Diff/Sync/Conflict     |   + 共享 WAL + Snapshot      |  - 周期 snapshot 压缩       |
|  - Supabase CognitivePool |                              |  - 被 core 反向重启          |
|  - Metrics/Tuner          |                              |                           |
+---------------------------+                              +---------------------------+
        | local FS / Supabase                                     | engine_data/
        +---------------------------------------------------------+
```

- `core` 是实际任务执行者。
- `guardian` 是引擎内部监督者，不是外部守护进程。
- 两者互相写心跳、互相监控、互相拉起，实现“双进程互监”。
- 两者都崩溃时，由下一次 `python -m engine bootstrap` 从 WAL/Snapshot 恢复并启动。

## 3. 状态原子持久化：WAL + Snapshot

所有状态变更先写 WAL，再更新内存；定期压缩成 Snapshot。崩溃恢复时：加载 Snapshot，重放 WAL，按 `op_id` 去重。

```python
# state/state_store.py
import json, os, time, hashlib, threading
from pathlib import Path
from .locks import FileLock

class StateStore:
    def __init__(self, data_dir: Path):
        self.data_dir = Path(data_dir)
        self.wal_path = self.data_dir / "wal" / "wal.log"
        self.snapshot_path = self.data_dir / "snapshot.json"
        self.lock = FileLock(self.data_dir / "locks" / "state.lock")

        self.seq = 0
        self.data = {"tasks": {}, "metrics": [], "config": {}}
        self.applied_op_ids = set()

        self.data_dir.mkdir(parents=True, exist_ok=True)
        (self.data_dir / "wal").mkdir(parents=True, exist_ok=True)
        (self.data_dir / "locks").mkdir(parents=True, exist_ok=True)

        with self.lock:
            self._recover_locked()

    def _recover_locked(self):
        # 1. 读 snapshot
        if self.snapshot_path.exists():
            snap = json.loads(self.snapshot_path.read_text())
            if hashlib.sha256(json.dumps(snap["data"], ensure_ascii=False).encode()).hexdigest() != snap["checksum"]:
                raise RuntimeError("snapshot corrupted")
            self.seq = snap["seq"]
            self.data = snap["data"]
            self.applied_op_ids = set(snap["op_ids"])

        # 2. 重放 WAL
        if self.wal_path.exists():
            for line in self.wal_path.read_text().splitlines():
                line = line.strip()
                if not line:
                    continue
                try:
                    rec = json.loads(line)
                except json.JSONDecodeError:
                    continue  # 崩溃时最后一行不完整，跳过
                if rec["seq"] <= self.seq:
                    continue
                if rec["op_id"] in self.applied_op_ids:
                    continue
                self._apply(rec)
                self.seq = rec["seq"]
                self.applied_op_ids.add(rec["op_id"])

    def append(self, op_id: str, entity: str, payload):
        if op_id in self.applied_op_ids:
            return None
        with self.lock:
            if op_id in self.applied_op_ids:
                return None
            self.seq += 1
            rec = {
                "seq": self.seq,
                "op_id": op_id,
                "entity": entity,
                "payload": payload,
                "ts": time.time(),
            }
            line = json.dumps(rec, ensure_ascii=False) + "\n"
            fd = os.open(self.wal_path, os.O_WRONLY | os.O_APPEND | os.O_CREAT, 0o644)
            try:
                os.write(fd, line.encode("utf-8"))
                os.fsync(fd)
            finally:
                os.close(fd)

            self._apply(rec)
            self.applied_op_ids.add(op_id)

            if self.seq % 100 == 0:
                self._compact_locked()

            return rec

    def _apply(self, rec):
        entity = rec["entity"]
        payload = rec["payload"]
        if entity == "task":
            self.data["tasks"][payload["task_id"]] = payload
        elif entity == "metric":
            self.data["metrics"].append(payload)
        elif entity == "config":
            self.data["config"].update(payload)

    def compact(self):
        with self.lock:
            self._compact_locked()

    def _compact_locked(self):
        # 先追平最新 WAL
        self._recover_locked()

        snap = {
            "seq": self.seq,
            "data": self.data,
            "op_ids": sorted(self.applied_op_ids),
            "checksum": "",
        }
        snap["checksum"] = hashlib.sha256(
            json.dumps(snap["data"], ensure_ascii=False).encode()
        ).hexdigest()

        tmp = self.snapshot_path.with_suffix(".tmp")
        with open(tmp, "w") as f:
            f.write(json.dumps(snap, ensure_ascii=False))
            f.flush()
            os.fsync(f.fileno())
        os.replace(tmp, self.snapshot_path)

        # 清空 WAL
        with open(self.wal_path, "w") as f:
            f.flush()
            os.fsync(f.fileno())
```

`FileLock` 基于 `flock`，进程崩溃时锁自动释放：

```python
# state/locks.py
import fcntl, os
from pathlib import Path

class FileLock:
    def __init__(self, path: Path, blocking: bool = True):
        self.path = Path(path)
        self.blocking = blocking
        self.fd = None

    def acquire(self):
        self.fd = open(self.path, "a+")
        flags = fcntl.LOCK_EX if self.blocking else (fcntl.LOCK_EX | fcntl.LOCK_NB)
        try:
            fcntl.flock(self.fd, flags)
        except BlockingIOError:
            self.fd.close()
            self.fd = None
            return False
        self.fd.seek(0)
        self.fd.truncate()
        self.fd.write(str(os.getpid()))
        self.fd.flush()
        return True

    def release(self):
        if self.fd:
            fcntl.flock(self.fd, fcntl.LOCK_UN)
            self.fd.close()
            self.fd = None

    def __enter__(self):
        self.acquire()
        return self

    def __exit__(self, *exc):
        self.release()
```

## 4. 心跳检测与互监督

每个进程启动后，立刻持锁并写心跳；同时启动 `Watchdog` 监控对方心跳。心跳文件包含 `pid`、`time`、`phase`、`checkpoint`。

```python
# state/heartbeat.py
import json, os, time
from pathlib import Path

def pid_alive(pid: int) -> bool:
    if pid <= 0:
        return False
    try:
        os.kill(pid, 0)
    except ProcessLookupError:
        return False
    except PermissionError:
        return True
    return True

class Heartbeat:
    def __init__(self, role: str, data_dir: Path):
        self.path = Path(data_dir) / "heartbeat" / f"{role}.json"
        self.path.parent.mkdir(parents=True, exist_ok=True)

    def beat(self, phase: str = "", checkpoint: str = ""):
        tmp = self.path.with_suffix(".tmp")
        payload = {
            "pid": os.getpid(),
            "time": time.time(),
            "phase": phase,
            "checkpoint": checkpoint,
        }
        tmp.write_text(json.dumps(payload))
        os.replace(tmp, self.path)

    def read(self):
        if not self.path.exists():
            return None
        return json.loads(self.path.read_text())

    def alive(self, timeout: float = 5.0) -> bool:
        data = self.read()
        if not data:
            return False
        if not pid_alive(data.get("pid", 0)):
            return False
        return time.time() - data["time"] < timeout
```

```python
# guardian/watchdog.py
import threading, time
from ..state.heartbeat import Heartbeat
from .resurrector import respawn

class Watchdog(threading.Thread):
    def __init__(self, monitored_role: str, data_dir, check_interval: float = 1.0):
        super().__init__(daemon=True)
        self.monitored_role = monitored_role
        self.data_dir = data_dir
        self.check_interval = check_interval
        self.stop_event = threading.Event()

    def run(self):
        while not self.stop_event.wait(self.check_interval):
            if not Heartbeat(self.monitored_role, self.data_dir).alive():
                if respawn(self.monitored_role, self.data_dir):
                    # 拉起后等待几秒，避免频繁空转
                    time.sleep(2)
```

```python
# guardian/resurrector.py
import os, signal, subprocess, sys, time
from pathlib import Path
from ..state.heartbeat import Heartbeat, pid_alive
from ..state.locks import FileLock

PROJECT_ROOT = Path(__file__).resolve().parent.parent.parent

def read_lock_pid(lock_path: Path):
    try:
        return int(Path(lock_path).read_text().strip())
    except Exception:
        return None

def respawn(role: str, data_dir) -> bool:
    hb = Heartbeat(role, data_dir)
    if hb.alive():
        return False

    lock_path = Path(data_dir) / "locks" / f"{role}.lock"
    old = hb.read()
    old_pid = old.get("pid") if old else None

    # 如果旧进程还活着但心跳已 stale，说明挂起，杀掉
    if old_pid and old_pid != os.getpid() and pid_alive(old_pid):
        lock_pid = read_lock_pid(lock_path)
        if lock_pid == old_pid:
            os.kill(old_pid, signal.SIGKILL)
            time.sleep(0.5)

    with FileLock(lock_path, blocking=True):
        if hb.alive():
            return False

        log_path = Path(data_dir) / "logs" / f"{role}.log"
        log_path.parent.mkdir(parents=True, exist_ok=True)
        with open(log_path, "a") as log:
            subprocess.Popen(
                [sys.executable, "-m", "engine", role, "--resume"],
                cwd=PROJECT_ROOT,
                stdout=log,
                stderr=log,
                start_new_session=True,
            )
        return True
```

## 5. ChainTask 断点续跑

### 5.1 任务与步骤模型

```python
# model/chain_task.py
from dataclasses import dataclass, field, asdict
from typing import Optional, List
import time, uuid

@dataclass
class Step:
    id: str
    type: str
    depends_on: Optional[str] = None
    status: str = "PENDING"          # PENDING / RUNNING / DONE / FAILED
    retry_count: int = 0
    max_retries: int = 3
    error: str = ""
    attempt_token: str = ""
    output: Optional[dict] = None
    started_at: float = 0.0
    finished_at: float = 0.0

@dataclass
class ChainTask:
    task_id: str
    source_path: str
    op_id: str
    state: str = "PENDING"           # PENDING / RUNNING / DONE / FAILED
    steps: List[Step] = field(default_factory=list)
    metadata: dict = field(default_factory=dict)
    created_at: float = field(default_factory=time.time)
    updated_at: float = field(default_factory=time.time)

    def to_dict(self):
        return asdict(self)

    @staticmethod
    def from_dict(data):
        data = dict(data)
        data["steps"] = [Step(**s) for s in data.get("steps", [])]
        return ChainTask(**data)
```

### 5.3 任务执行器

```python
# core/runner.py
import time, uuid
from ..model.chain_task import ChainTask, Step
from ..state.state_store import StateStore
from ..utils.config_center import ConfigCenter
from .diff_engine import DiffEngine
from .conflict_resolver import ConflictResolver
from .quality_gate import QualityGate
from .llm_client import LLMClient
from ..supabase.cognitive_pool import CognitivePool

class TaskRunner:
    def __init__(self, state_store: StateStore, config: ConfigCenter,
                 cognitive_pool: CognitivePool, heartbeat_thread):
        self.state_store = state_store
        self.config = config
        self.cognitive_pool = cognitive_pool
        self.heartbeat_thread = heartbeat_thread
        self.diff_engine = DiffEngine(config)
        self.conflict_resolver = ConflictResolver(config)
        self.quality_gate = QualityGate(config)
        self.llm = LLMClient(config)

    def run_forever(self):
        while True:
            self._process_pending_tasks()
            time.sleep(self.config.get("sync.scan_interval", 1))

    def _process_pending_tasks(self):
        for task_dict in list(self.state_store.data["tasks"].values()):
            task = ChainTask.from_dict(task_dict)
            if task.state in ("PENDING", "RUNNING"):
                self.execute_task(task)

    def execute_task(self, task: ChainTask):
        if task.state == "DONE":
            return

        task.state = "RUNNING"
        task.updated_at = time.time()
        self.state_store.append(f"task:start:{task.task_id}:{uuid.uuid4().hex}", "task", task.to_dict())

        for step in task.steps:
            if step.status == "DONE":
                continue
            if step.status == "RUNNING":
                step.status = "PENDING"
                step.error = "resume after crash"
                step.attempt_token = ""

            if step.retry_count >= step.max_retries:
                task.state = "FAILED"
                task.updated_at = time.time()
                self.state_store.append(f"task:fail:{task.task_id}:{uuid.uuid4().hex}", "task", task.to_dict())
                return

            step.status = "RUNNING"
            step.attempt_token = uuid.uuid4().hex
            step.started_at = time.time()
            step.error = ""
            self.heartbeat_thread.set_checkpoint(f"{task.task_id}/{step.id}/{step.attempt_token}")

            self.state_store.append(
                f"step:start:{task.task_id}:{step.id}:{step.attempt_token}",
                "task", task.to_dict()
            )

            try:
                result = self.dispatch(task, step)
                ok, msg = self.quality_gate.check(task, step, result)
                if not ok:
                    raise RuntimeError(f"quality gate failed: {msg}")

                step.output = result
                step.status = "DONE"
                step.finished_at = time.time()
                self.state_store.append(
                    f"step:done:{task.task_id}:{step.id}:{step.attempt_token}",
                    "task", task.to_dict()
                )
            except Exception as e:
                step.error = str(e)
                step.retry_count += 1
                step.status = "PENDING"
                self.state_store.append(
                    f"step:fail:{task.task_id}:{step.id}:{step.attempt_token}",
                    "task", task.to_dict()
                )
                break

            self.heartbeat_thread.set_checkpoint("")

        if all(s.status == "DONE" for s in task.steps):
            task.state = "DONE"
        task.updated_at = time.time()
        self.state_store.append(f"task:end:{task.task_id}:{uuid.uuid4().hex}", "task", task.to_dict())
```

### 5.4 步骤分发

```python
    def dispatch(self, task: ChainTask, step: Step):
        prev = self._prev_output(task, step)

        if step.type == "diff":
            local_chunks = self._read_local_chunks(task.source_path)
            remote_chunks = self.cognitive_pool.get_snapshot(task.source_path)
            diff = self.diff_engine.compute(local_chunks, remote_chunks)
            return {"diff": diff}

        if step.type == "conflict":
            diff = prev.get("diff")
            resolution = self.conflict_resolver.resolve(task.source_path, diff)
            return {"resolution": resolution}

        if step.type == "sync":
            resolution = prev.get("resolution", {})
            diff = resolution.get("diff") or prev.get("diff")
            self.cognitive_pool.upsert_diff(task.source_path, diff, task.op_id)
            return {"synced_chunks": len(diff.changed_chunks)}

        if step.type == "metrics":
            start = step.started_at
            duration = time.time() - start
            metric = {
                "task_id": task.task_id,
                "step_id": step.id,
                "duration": duration,
                "retry_count": step.retry_count,
                "timestamp": time.time(),
            }
            self.state_store.append(f"metric:{uuid.uuid4().hex}", "metric", metric)
            return {"recorded": True}

        if step.type == "tune":
            # 策略调优：根据最近指标调整 chunk_size / conflict_strategy
            self._tune_strategy()
            return {"tuned": True}

        raise ValueError(f"unknown step type: {step.type}")

    def _prev_output(self, task: ChainTask, step: Step):
        if not step.depends_on:
            return {}
        for s in task.steps:
            if s.id == step.depends_on:
                return s.output or {}
        return {}
```

## 6. 质量门禁：按模型独立，避免误杀 B 模型

```python
# core/quality_gate.py
class QualityGate:
    def __init__(self, config):
        self.config = config

    def check(self, task, step, result):
        if step.type not in ("tune", "llm_generate"):
            return True, ""

        model = result.get("model") or task.metadata.get("model")
        rule = self.config.get(f"quality.model_rules.{model}", {})

        if rule.get("check_reasoning_ratio"):
            rr = result.get("reasoning_ratio", 0)
            max_rr = rule.get("max_reasoning_ratio", 0.9)
            if rr > max_rr:
                return False, f"reasoning_ratio={rr:.2f} > {max_rr}"

        text = result.get("text", "")
        if not text or not text.strip():
            return False, "empty generation"

        return True, ""
```

`config.yaml` 中：

```yaml
quality:
  model_rules:
    A:
      check_reasoning_ratio: true
      max_reasoning_ratio: 0.9
    B-turbo:
      check_reasoning_ratio: false
```

这样 `B-turbo` 的 reasoning 占比 70%–82% 不会被误判为废稿。

```python
        return {
            "text": resp["text"],
            "reasoning_ratio": resp.get("reasoning_ratio", 0),
            "model": model,
            "latency": time.time() - start,
        }

    def _api_call(self, model, prompt, timeout):
```

## 8. Supabase 认知池：幂等写入

```python
# supabase/cognitive_pool.py
class CognitivePool:
    def __init__(self, supabase_client):
        self.supabase = supabase_client

    def get_snapshot(self, source_path):
        rows = self.supabase.table("cognitive_pool") \
            .select("*") \
            .eq("source_path", source_path) \
            .execute()
        return rows.data

    def upsert_diff(self, source_path, diff, op_id):
        rows = []
        for chunk in diff.changed_chunks:
            rows.append({
                "op_id": f"{op_id}:{chunk.id}",
                "source_path": source_path,
                "chunk_id": chunk.id,
                "content": chunk.content,
                "updated_at": "now",
            })
        if rows:
            self.supabase.table("cognitive_pool") \
                .upsert(rows, on_conflict="op_id") \
                .execute()
```

`op_id` 是幂等键；即使崩溃重试，也不会重复写入。

```python
        if time.time() - last_compact > config.get("snapshot.compact_interval", 60):
            StateStore(data_dir).compact()
            last_compact = time.time()

def bootstrap(data_dir):
    with FileLock(data_dir / "locks" / "engine.lock", blocking=True):
        StateStore(data_dir).compact()
    if not Heartbeat("guardian", data_dir).alive():
        respawn("guardian", data_dir)
    if not Heartbeat("core", data_dir).alive():
        respawn("core", data_dir)

if __name__ == "__main__":
    role = sys.argv[1]
    if role == "core":
        core_main(DATA_DIR)
    elif role == "guardian":
        guardian_main(DATA_DIR)
    elif role == "bootstrap":
        bootstrap(DATA_DIR)
```

```python
# state/heartbeat_thread.py
import threading, time
from .heartbeat import Heartbeat

class HeartbeatThread(threading.Thread):
    def __init__(self, role, data_dir, interval=1.0):
        super().__init__(daemon=True)
        self.hb = Heartbeat(role, data_dir)
        self.interval = interval
        self.phase = "idle"
        self.checkpoint = ""
        self.stop_event = threading.Event()

    def set_checkpoint(self, checkpoint):
        self.checkpoint = checkpoint

    def run(self):
        while not self.stop_event.wait(self.interval):
            self.hb.beat(self.phase, self.checkpoint)
```

## 10. 崩溃恢复场景

| 场景 | 检测方式 | 恢复动作 |
|---|---|---|
| `core` 崩溃 | `guardian` 心跳检测超时 | `guardian` 杀掉残留进程，重新拉起 `core`；`core` 启动后从 WAL 恢复任务 |
| `core` 挂起 | 心跳不更新，`checkpoint` 不再推进 | 同上 |
| `guardian` 崩溃 | `core` 心跳检测超时 | `core` 杀掉残留进程，重新拉起 `guardian` |
| `core` + `guardian` 同时崩溃 | 无存活进程 | 下次 `python -m engine bootstrap` 恢复并拉起 |

因为每一步都有 `op_id` / `attempt_token`，且 Supabase 写入使用 `op_id` 幂等，所以重试不会产生脏数据。

## 11. 断点续跑粒度

- **断点不是“指令级”，而是“步骤级”**。
- 一个步骤要么 `DONE`，要么 `PENDING`/`RUNNING`。
- 崩溃后，`RUNNING` 步骤被重置为 `PENDING`，从该步骤重跑。
- 已 `DONE` 的步骤不会重跑，因为步骤状态已经持久化在 WAL/Snapshot 中。

这样既满足“断点续跑”，又不会陷入“恢复到最后一条机器指令”的复杂度。

## 12. 配置热生效

```python
# utils/config_center.py
import yaml, os
from pathlib import Path

class ConfigCenter:
    def __init__(self, path: Path):
        self.path = Path(path)
        self._mtime = 0
        self._data = {}
        self.reload()

    def reload(self):
        if not self.path.exists():
            return
        mtime = self.path.stat().st_mtime
        if mtime != self._mtime:
            self._data = yaml.safe_load(self.path.read_text()) or {}
            self._mtime = mtime

    def get(self, key, default=None):
        self.reload()
        node = self._data
        for part in key.split("."):
            if not isinstance(node, dict) or part not in node:
                return default
            node = node[part]
        return node

    def set(self, key, value):
        self.reload()
        node = self._data
        parts = key.split(".")
        for part in parts[:-1]:
            node = node.setdefault(part, {})
        node[parts[-1]] = value

        tmp = self.path.with_suffix(".tmp")
        with open(tmp, "w") as f:
            f.write(yaml.dump(self._data))
            f.flush()
            os.fsync(f.fileno())
        os.replace(tmp, self.path)
        self._mtime = self.path.stat().st_mtime

        # 立即验证生效
        assert self.get(key) == value, f"config {key} not effective"
```

## 13. 一句话总结

这套机制把“崩溃恢复”变成引擎内部的基础设施：  
**双进程互监保证单进程崩溃能被拉起；WAL+Snapshot 保证状态不丢；op_id 幂等保证重试不脏；ChainTask 步骤级断点保证从最近完成点续跑。**
