## R1｜筑基：境界映射

**目标**：定义代码库健康度 → 修炼境界的静态映射协议

### 输入

| 输入源 | 具体内容 | 数据形态 |
|--------|----------|----------|
| 代码库 | 覆盖率/圈复杂度/技术债/依赖健康度 | SonarQube指标JSON |
| 团队行为 | 提交频率/Review通过率/Issue关闭速率 | Git日志统计 |
| 系统状态 | API响应延迟/错误率/资源利用率 | APM指标流 |

### 推演任务

**T1.1 灵根品质 ← 代码覆盖率**
```
覆盖率 ≥ 80%   → 天灵根（金/木/水/火/土任一属性觉醒）
覆盖率 60-80%  → 异灵根（双属性混合）
覆盖率 40-60%  → 凡灵根（单属性低阶）
覆盖率 < 40%   → 废灵根（需筑基丹=技术债清理任务补救）
```

**T1.2 经脉通畅度 ← 圈复杂度**
```
复杂度 ≤ 10    → 经脉贯通（功法可正常运转）
复杂度 11-20   → 经脉淤堵（功法效率×0.7）
复杂度 21-50   → 经脉受损（功法效率×0.4，有走火入魔风险）
复杂度 > 50    → 经脉断裂（强制闭关=禁止部署生产环境）
```

**T1.3 心魔值 ← 技术债 + Bug密度**
```
心魔值 = 技术债分数 × 0.6 + (P0/P1 Bug数 × 10) + (未解决Issue天数 × 0.1)

心魔值 ≥ 80  → 心魔入体：随机功法失效，需"斩心魔"=修复指定技术债
心魔值 50-79 → 心魔滋生：修炼速度×0.5，突破成功率×0.6
心魔值 < 50  → 道心通明：修炼速度×1.5，突破成功率×1.2
```

### 推演任务

**T2.1 功法品阶 ← API端点分类**

| 工程语义 | 修真映射 | 功法示例 | 灵力消耗 |
|----------|----------|----------|----------|
| 核心业务API | 本命功法 | 《紫霄炼丹术》= `/api/v1/order/create` | 灵力/次调用 |
| 基础设施API | 筑基功法 | 《灵脉引流诀》= `Redis连接池管理` | 灵力/秒维持 |
| 第三方API | 借力功法 | 《借东风》= `外部支付网关调用` | 灵力×2（异源消耗） |
| 调试/测试API | 入门功法 | 《窥天镜》= `日志查询接口` | 灵力×0.1 |
| 废弃API | 走火入魔源 | 《噬魂魔功》= `未下线旧版接口` | 反噬心魔值+5/次 |

**T2.2 灵力流转 ← 调用链拓扑**

```
// 用户请求 → 微服务调用链 = 一个完整周天运转

用户请求：POST /api/v1/order/create
    │
    ├─ Gateway Service（引气入体）
    │   └─ Auth Service（护体灵光，消耗=Token验证算力）
    │       └─ User Service（识海探查，消耗=用户信息查询算力）
    │           └─ Inventory Service（探囊取物，消耗=库存查询算力）
    │               └─ Payment Service（灵石交割，消耗=支付处理算力）
    │
    └─ 返回响应 = 周天圆满，灵力沉淀+经验值

// 调用链深度 = 功法层数
// 每层延迟 > 200ms = 该层经脉淤堵，灵力损耗+15%
// 调用链超时 = 走火入魔，心魔值+10
```

**T2.3 灵力池 ← 算力配额**
```
灵力上限 = 境界基数 × (1 + 容器CPU配额/8) × (1 + 内存配额/16)

灵力恢复速率 = 基础恢复 × (当前并发数 < 阈值 ? 1.0 : 0.3)

灵力枯竭触发：
  - 灵力 < 10%  → 自动降级：非核心功法暂停（低优先级API限流）
  - 灵力 = 0    → 灵力崩溃：服务熔断，角色进入"重伤"状态
  - 重伤状态    → 需等待恢复期或服用"回灵丹"=扩容操作
```

变更行数 > 500   & 生产部署       → 触发大天劫（全链路压测+灰度验证）
紧急热修复                        → 逆天改命：成功率×0.5，但失败也只掉1层

渡劫成功奖励：
  - 突破当前境界
  - 解锁更高阶功法权限
  - 容器资源配额自动提升（天道赐福）
  - 技术债豁免券×1（天材地宝）
