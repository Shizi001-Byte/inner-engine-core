# 任务类型: eng

## 修复方案

**根因**：L4 成品转化入口只对 `sop` 做了硬编码分支，配置层也只注册了 `sop`，导致 `code` / `checklist` 类型无法进入转化流程。

**目标**：让 `code` / `checklist` 成为与 `sop` 同等的一等 L4 成品类型，可配置、可生成、可校验、可输出。

---

### 1. 配置层：新增 code / checklist 类型

**文件**：`app/config/l4.py`

```python
L4_PRODUCT_TYPES = {
    "sop": {
        "enabled": True,
        "template": "templates/sop.md",
        "output_dir": "outputs/l4/sop",
    },
    "code": {
        "enabled": True,
        "template": "templates/code.md",
        "output_dir": "outputs/l4/code",
        "required_fields": ["language", "entrypoint"],
    },
    "checklist": {
        "enabled": True,
        "template": "templates/checklist.md",
        "output_dir": "outputs/l4/checklist",
        "required_fields": ["owner", "items"],
    },
}

def load_l4_product_types():
    # 关键：必须读配置，禁止在别处硬编码 ["sop"]
    return {k: v for k, v in L4_PRODUCT_TYPES.items() if v["enabled"]}
```

> 避免历史教训：新增配置后，必须同步修改读取点，否则配置不生效。

```python
class L4Type(str, Enum):
    SOP = "sop"
    CODE = "code"
    CHECKLIST = "checklist"
```

### 3. 转化逻辑：注册表替代硬编码分支

**文件**：`app/services/transformer.py`

```python
from app.models.l4 import L4Type

TRANSFORMERS = {}

def register(product_type):
    def decorator(fn):
        TRANSFORMERS[product_type] = fn
        return fn
    return decorator

def transform(product):
    fn = TRANSFORMERS.get(product.type)

    if not fn:
        raise UnsupportedL4Type(
            f"Unsupported L4 type: {product.type}, "
            f"supported: {list(TRANSFORMERS)}"
        )

    artifact = fn(product)
    validate_l4_artifact(artifact)
    return artifact
```

#### 3.2 CODE 转换

```python
@register(L4Type.CODE)
def transform_to_code(product):
    if not product.specification:
        raise ValueError("code 类型必须包含 specification")

    language = product.metadata.get("language")
    if not language:
        raise ValueError("code 类型必须指定 language")

    # 根据模型类型设置合理 timeout
    timeout = 600 if product.model == "A" else 300

    code_content = llm_client.generate(
        prompt=build_code_prompt(product),
        model=product.model,
        timeout=timeout,
    )

    return L4Artifact(
        type=L4Type.CODE,
        content=code_content,
        metadata={
            "language": language,
            "entrypoint": product.metadata.get("entrypoint"),
            "dependencies": product.metadata.get("dependencies", []),
        },
    )
```

#### 3.3 CHECKLIST 转换

```python
@register(L4Type.CHECKLIST)
def transform_to_checklist(product):
    if not product.specification:
        raise ValueError("checklist 类型必须包含 specification")

    timeout = 600 if product.model == "A" else 300

    checklist_content = llm_client.generate(
        prompt=build_checklist_prompt(product),
        model=product.model,
        timeout=timeout,
    )

    return L4Artifact(
        type=L4Type.CHECKLIST,
        content=checklist_content,
        metadata={
            "owner": product.metadata.get("owner"),
            "due": product.metadata.get("due"),
        },
    )
```

### 4. 校验器：新增 code / checklist 校验

**文件**：`app/validators/l4_validator.py`

```python
def validate_l4_artifact(artifact):
    if artifact.type == L4Type.CODE:
        if not artifact.content.strip():
            raise ValueError("code 产物为空")
        if not artifact.metadata.get("language"):
            raise ValueError("code 产物缺少 language 元数据")

    elif artifact.type == L4Type.CHECKLIST:
        if not artifact.content.startswith("- [ ]"):
            raise ValueError("checklist 产物格式应为 Markdown 勾选清单")

    elif artifact.type == L4Type.SOP:
        if not artifact.content.strip():
            raise ValueError("sop 产物为空")

    else:
        raise ValueError(f"未知 L4 类型: {artifact.type}")
```

### 5. 管道输出：按类型输出到对应目录

**文件**：`app/pipeline.py`

```python
def run_l4_pipeline(product):
    artifact = transform(product)

    product_type_config = load_l4_product_types()[artifact.type]
    output_dir = product_type_config["output_dir"]

    save_artifact(artifact, output_dir=output_dir)
    return artifact
```

## 风险等级

**Low**

- 仅新增 `code` / `checklist` 分支和配置，不修改已有 `sop` 逻辑。
- 使用注册表模式，后续新增 L4 类型时只需注册一次，避免再次出现“只实现了某一种类型”的静态清单问题。
- 若出现异常，回滚范围仅涉及 `transformer.py`、`l4.py`、`l4_validator.py`，可快速 `git revert`。
