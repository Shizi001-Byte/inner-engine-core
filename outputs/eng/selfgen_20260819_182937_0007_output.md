# 任务类型: eng

先说明边界：**操作系统不允许“已经死掉的进程自己复活”**。  
所以“不依赖外部守护进程”的崩溃恢复，本方案拆成三层：

1. **Worker 子进程崩溃**：Engine 内部的心跳监控自动发现并重试该步骤。  
2. **Engine 主循环卡死**：Engine 内部 Watchdog 线程检测到主心跳超时后，自己 `os.execv` 重启进程。  
3. **Engine 被外部 `kill -9`**：进程本身无法自救，但每次状态都原子落盘；下次进程被拉起时，自动读取状态文件，从断点续跑。

同时本方案已内嵌你给出的避坑清单：

- 配置统一读取，修改后立即回读验证；  
- B_turbo 超时 300 秒，A 超时 600 秒；  
- B_turbo 跳过 reasoning_ratio 废稿检测；  
- 每次状态同步后必须回读校验。

```text
│ EngineProcess                                       │

│         │                        │                   │
│         ▼                        ▼                   │

│  │            EngineWatchdogThread          │       │

│                                                     │

│  │              WorkerProcess               │       │

│  └──────────────────────────────────────────┘       │
└─────────────────────────────────────────────────────┘
```

## 2. 状态机与断点续跑

状态文件持久化以下字段：

```text
engine_id
run_id
phase
completed_steps
checkpoint
retries
config_version
checksum
```

Phase 流转：

```text
INIT → PREPARE → EXECUTE → VALIDATE → FINALIZE → DONE
```

崩溃后恢复规则：

| 崩溃时 phase | 恢复动作 |
|---|---|
| INIT | 重新 prepare |
| PREPARE | 检查 prepared 标记，幂等补做 |
| EXECUTE | 跳过 completed_steps，继续未完成步骤 |
| VALIDATE | 重新做全局校验 |
| FINALIZE | 重新 finalize |
| DONE | 直接返回 checkpoint.output |

### 3.1 config.py

所有配置读取点收敛到 `Config`，避免散落硬编码。

```python
import json
import threading
from pathlib import Path


DEFAULT_CONFIG = {
    "config_version": "1",
    "state_path": "engine_state.json",
    "restart_marker": "restart.marker",
    "model_timeout": {
        "A": 600,
        "B_turbo": 300
    },
    "heartbeat_grace": 10,
    "max_worker_retries": 3,
    "retry_backoff_base": 2,
    "main_watchdog_timeout": 120,
    "quality": {
        "A": {
            "max_reasoning_ratio": 0.8,
            "skip_reasoning_ratio": False
        },
        "B_turbo": {
            "max_reasoning_ratio": 1.0,
            "skip_reasoning_ratio": True
        }
    }
}


class Config:
    def __init__(self, path=None):
        self._path = path
        self._data = json.loads(json.dumps(DEFAULT_CONFIG))
        self._lock = threading.RLock()
        if path:
            self.reload()

    def __getstate__(self):
        state = self.__dict__.copy()
        state.pop("_lock", None)
        return state

    def __setstate__(self, state):
        self.__dict__.update(state)
        self._lock = threading.RLock()

    def _deep_merge(self, base, override):
        for k, v in override.items():
            if isinstance(v, dict) and isinstance(base.get(k), dict):
                self._deep_merge(base[k], v)
            else:
                base[k] = v

    def reload(self):
        with self._lock:
            if self._path and Path(self._path).exists():
                with open(self._path, "r", encoding="utf-8") as f:
                    user_config = json.load(f)
                self._deep_merge(self._data, user_config)

            # 回读验证：关键配置必须存在
            assert self.get("state_path"), "state_path must not be empty"
            assert self.get("model_timeout.A"), "model_timeout.A must exist"
            assert self.get("model_timeout.B_turbo"), "model_timeout.B_turbo must exist"
            assert self.get("config_version"), "config_version must exist"

    def get(self, key, default=None):
        with self._lock:
            cur = self._data
            for part in key.split("."):
                if isinstance(cur, dict) and part in cur:
                    cur = cur[part]
                else:
                    return default
            return cur

    def timeout_for(self, model_type):
        # 所有模型超时读取点集中在这里
        if model_type in ("B", "B_turbo"):
            key = "B_turbo"
        else:
            key = model_type
        return int(self.get(f"model_timeout.{key}", 300))
```

### 3.2 state.py

```python
import hashlib
import hmac
import json
import time
from dataclasses import dataclass, field
from typing import Any, Dict, Set


@dataclass
class EngineState:
    version: int = 1
    engine_id: str = ""
    run_id: str = ""
    phase: str = "INIT"
    completed_steps: Set[str] = field(default_factory=set)
    checkpoint: Dict[str, Any] = field(default_factory=dict)
    retries: Dict[str, int] = field(default_factory=dict)
    config_version: str = ""
    updated_at: float = 0.0
    checksum: str = ""

    def _base_dict(self):
        return {
            "version": self.version,
            "engine_id": self.engine_id,
            "run_id": self.run_id,
            "phase": self.phase,
            "completed_steps": sorted(self.completed_steps),
            "checkpoint": self.checkpoint,
            "retries": self.retries,
            "config_version": self.config_version,
            "updated_at": self.updated_at,
        }

    def to_dict(self):
        d = self._base_dict()
        d["checksum"] = self.checksum
        return d

    @classmethod
    def from_dict(cls, d):
        state = cls()
        state.version = d.get("version", 1)
        state.engine_id = d.get("engine_id", "")
        state.run_id = d.get("run_id", "")
        state.phase = d.get("phase", "INIT")
        state.completed_steps = set(d.get("completed_steps", []))
        state.checkpoint = d.get("checkpoint", {})
        state.retries = d.get("retries", {})
        state.config_version = d.get("config_version", "")
        state.updated_at = d.get("updated_at", 0.0)
        state.checksum = d.get("checksum", "")
        return state

    def compute_checksum(self):
        canonical = json.dumps(
            self._base_dict(),
            sort_keys=True,
            ensure_ascii=False
        ).encode("utf-8")
        return hashlib.sha256(canonical).hexdigest()

    def verify_checksum(self):
        return bool(self.checksum) and hmac.compare_digest(
            self.checksum,
            self.compute_checksum()
        )
```

### 3.3 store.py

原子持久化：临时文件 → `fsync` → `rename` → `fsync` 目录 → 回读验证。

```python
import fcntl
import json
import os
import time
from pathlib import Path

from state import EngineState


class AtomicStateStore:
    def __init__(self, path: str):
        self.path = Path(path)
        self.path.parent.mkdir(parents=True, exist_ok=True)
        self.tmp_path = self.path.with_name(self.path.name + ".tmp")
        self.lock_path = self.path.with_name(self.path.name + ".lock")

    def _lock(self):
        self._lock_fd = os.open(self.lock_path, os.O_CREAT | os.O_RDWR, 0o644)
        fcntl.flock(self._lock_fd, fcntl.LOCK_EX)

    def _unlock(self):
        fcntl.flock(self._lock_fd, fcntl.LOCK_UN)
        os.close(self._lock_fd)

    def save(self, state: EngineState) -> None:
        self._lock()
        try:
            state.updated_at = time.time()
            state.checksum = state.compute_checksum()
            payload = json.dumps(
                state.to_dict(),
                ensure_ascii=False,
                indent=2
            ).encode("utf-8")

            fd = os.open(
                self.tmp_path,
                os.O_CREAT | os.O_WRONLY | os.O_TRUNC,
                0o644
            )
            with os.fdopen(fd, "wb") as f:
                f.write(payload)
                f.flush()
                os.fsync(f.fileno())

            os.replace(self.tmp_path, self.path)

            dir_fd = os.open(self.path.parent, os.O_DIRECTORY)
            try:
                os.fsync(dir_fd)
            finally:
                os.close(dir_fd)

            # 同步后必须回读验证
            loaded = self.load(acquire_lock=False)
            if loaded is None:
                raise RuntimeError("state readback failed: state is None")
            if loaded.checksum != state.checksum or loaded.phase != state.phase:
                raise RuntimeError("state readback verification failed")

        finally:
            self._unlock()

    def load(self, acquire_lock: bool = True):
        if acquire_lock:
            self._lock()
        try:
            if not self.path.exists():
                return None
            with open(self.path, "rb") as f:
                data = json.load(f)
            state = EngineState.from_dict(data)
            if not state.verify_checksum():
                raise RuntimeError("state checksum mismatch")
            return state
        finally:
            if acquire_lock:
                self._unlock()
```

### 3.4 heartbeat.py

```python
import threading
import time


class MainHeartbeat:
    def __init__(self):
        self._lock = threading.Lock()
        self._last = time.time()

    def beat(self):
        with self._lock:
            self._last = time.time()

    def last(self):
        with self._lock:
            return self._last


class HeartbeatRegistry:
    def __init__(self):
        self._lock = threading.Lock()
        self._records = {}

    def register(self, worker_id, attempt_id, timeout):
        with self._lock:
            self._records[worker_id] = {
                "last": time.time(),
                "timeout": timeout,
                "attempt_id": attempt_id,
                "dead": False,
            }

    def update(self, worker_id, attempt_id):
        with self._lock:
            rec = self._records.get(worker_id)
            if rec and rec["attempt_id"] == attempt_id:
                rec["last"] = time.time()

    def unregister(self, worker_id):
        with self._lock:
            self._records.pop(worker_id, None)

    def worker_ids(self):
        with self._lock:
            return list(self._records.keys())

    def is_dead(self, worker_id, now=None):
        now = now or time.time()
        with self._lock:
            rec = self._records.get(worker_id)
            if rec is None or rec["dead"]:
                return True
            return now - rec["last"] > rec["timeout"]

    def mark_dead(self, worker_id):
        with self._lock:
            if worker_id in self._records:
                self._records[worker_id]["dead"] = True


class HeartbeatMonitor(threading.Thread):
    def __init__(self, registry, on_dead, interval=1.0):
        super().__init__(daemon=True)
        self.registry = registry
        self.on_dead = on_dead
        self.interval = interval
        self._stop = threading.Event()

    def stop(self):
        self._stop.set()

    def run(self):
        while not self._stop.is_set():
            for worker_id in self.registry.worker_ids():
                if self.registry.is_dead(worker_id):
                    self.registry.mark_dead(worker_id)
                    try:
                        self.on_dead(worker_id)
                    except Exception:
                        pass
            self._stop.wait(self.interval)
```

### 3.5 quality.py

关键避坑：**B_turbo 的 reasoning_ratio 是正常特性，跳过该检测**。

```python
class QualityError(Exception):
    pass


class QualityGate:
    def __init__(self, config):
        self.config = config

    def validate(self, result, step):
        model = step.get("model_type", "A")
        if model in ("B", "B_turbo"):
            model = "B_turbo"

        rule = self.config.get(f"quality.{model}", {})

        # B_turbo 跳过 reasoning_ratio 检测
        if rule.get("skip_reasoning_ratio"):
            return True

        max_ratio = rule.get("max_reasoning_ratio", 0.8)
        ratio = result.get("reasoning_ratio", 0)
        if ratio > max_ratio:
            raise QualityError(
                f"reasoning_ratio={ratio:.2f} > max={max_ratio}"
            )

        return True
```

### 3.6 worker.py

```python
import multiprocessing as mp
import time

import requests


class WorkerProcess(mp.Process):
    def __init__(self, worker_id, attempt_id, step, config,
                 heartbeat_q, result_q):
        super().__init__(name=f"worker-{worker_id}-{attempt_id}")
        self.worker_id = worker_id
        self.attempt_id = attempt_id
        self.step = step
        self.config = config
        self.heartbeat_q = heartbeat_q
        self.result_q = result_q

    def run(self):
        try:
            self.heartbeat_q.put(
                ("beat", self.worker_id, self.attempt_id, time.time())
            )
            result = self._execute()
            self.result_q.put(
                ("done", self.worker_id, self.attempt_id, result)
            )
        except Exception as e:
            self.result_q.put(
                ("error", self.worker_id, self.attempt_id, repr(e))
            )
        finally:
            self.heartbeat_q.put(
                ("stopped", self.worker_id, self.attempt_id, time.time())
            )

    def _execute(self):
        step = self.step
        if step["type"] == "api_call":
            return self._api_call(step)
        if step["type"] == "local_compute":
            return self._local_compute(step)
        raise ValueError(f"unknown step type: {step['type']}")

    def _api_call(self, step):
        # 按模型设置不同 timeout：B_turbo=300s，A=600s
        timeout = self.config.timeout_for(step.get("model_type", "A"))
        payload = dict(step.get("payload", {}))

        if step.get("idempotency_key"):
            payload["idempotency_key"] = step["idempotency_key"]

        resp = requests.post(
            step["url"],
            json=payload,
            timeout=timeout
        )
        resp.raise_for_status()
        return resp.json()

    def _local_compute(self, step):
        result = []
        for item in step.get("items", []):
            # 长任务主动发心跳，避免被误杀
            self.heartbeat_q.put(
                ("beat", self.worker_id, self.attempt_id, time.time())
            )
            result.append(item * step.get("multiplier", 1))
        return result
```

### 3.7 engine.py

```python
import json
import multiprocessing as mp
import os
import queue
import sys
import threading
import time
from pathlib import Path

from heartbeat import HeartbeatMonitor, HeartbeatRegistry, MainHeartbeat
from quality import QualityError, QualityGate
from state import EngineState
from store import AtomicStateStore
from worker import WorkerProcess


class ConfigChangedError(RuntimeError):
    pass


class EngineWatchdog(threading.Thread):
    def __init__(self, main_hb, timeout, on_timeout):
        super().__init__(daemon=True)
        self.main_hb = main_hb
        self.timeout = timeout
        self.on_timeout = on_timeout
        self._stop = threading.Event()

    def stop(self):
        self._stop.set()

    def run(self):
        while not self._stop.is_set():
            if time.time() - self.main_hb.last() > self.timeout:
                try:
                    self.on_timeout()
                except Exception:
                    pass
            self._stop.wait(1)


class Engine:
    def __init__(self, engine_id, config):
        self.engine_id = engine_id
        self.config = config
        self.state_store = AtomicStateStore(config.get("state_path"))

        self.heartbeat_q = mp.Queue()
        self.result_q = mp.Queue()

        self.registry = HeartbeatRegistry()
        self.workers = {}
        self._workers_lock = threading.Lock()

        self.main_hb = MainHeartbeat()

        self.monitor = HeartbeatMonitor(
            self.registry,
            self._on_worker_dead
        )
        self.monitor.start()

        self.watchdog = EngineWatchdog(
            self.main_hb,
            self.config.get("main_watchdog_timeout", 120),
            self._self_restart
        )
        self.watchdog.start()

        self.state = None

    # ---------- 状态恢复 ----------

    def _load_or_init(self, task):
        prev = self.state_store.load()

        if prev and prev.engine_id == self.engine_id and prev.run_id == task["run_id"]:
            if prev.config_version != self.config.get("config_version"):
                raise ConfigChangedError(
                    "config_version changed; refuse to resume old checkpoint"
                )
            return prev

        state = EngineState(
            engine_id=self.engine_id,
            run_id=task["run_id"],
            config_version=self.config.get("config_version"),
        )
        self._save(state)
        return state

    def _save(self, state=None):
        state = state or self.state
        state.updated_at = time.time()
        self.state_store.save(state)

    # ---------- 自重启 ----------

    def _self_restart(self):
        with self._workers_lock:
            for worker in self.workers.values():
                try:
                    worker["process"].terminate()
                except Exception:
                    pass

        marker = Path(self.config.get("restart_marker", "restart.marker"))
        marker.write_text(json.dumps({
            "time": time.time(),
            "run_id": self.state.run_id if self.state else "",
        }))

        os.execv(sys.executable, [sys.executable] + sys.argv)

    # ---------- Worker 管理 ----------

    def _on_worker_dead(self, worker_id):
        with self._workers_lock:
            proc = self.workers.get(worker_id, {}).get("process")
            if proc and proc.is_alive():
                proc.terminate()
                proc.join(timeout=5)
                if proc.is_alive():
                    proc.kill()

    def _start_worker(self, step, attempt_id):
        worker_id = step["step_id"]

        # 串行执行场景，清理旧消息
        while True:
            try:
                self.result_q.get_nowait()
            except queue.Empty:
                break

        with self._workers_lock:
            self.registry.unregister(worker_id)

            proc = WorkerProcess(
                worker_id,
                attempt_id,
                step,
                self.config,
                self.heartbeat_q,
                self.result_q,
            )
            proc.start()

            timeout = self.config.timeout_for(
                step.get("model_type", "A")
            ) + self.config.get("heartbeat_grace", 10)

            self.registry.register(worker_id, attempt_id, timeout)

            self.workers[worker_id] = {
                "process": proc,
                "step": step,
                "attempt_id": attempt_id,
                "started_at": time.time(),
            }

    def _drain_heartbeats(self):
        while True:
            try:
                msg = self.heartbeat_q.get_nowait()
            except queue.Empty:
                break

            if msg[0] == "beat":
                _, worker_id, attempt_id, _ts = msg
                self.registry.update(worker_id, attempt_id)

    def _wait_worker(self, worker_id, attempt_id):
        step = self.workers[worker_id]["step"]
        timeout = (
            self.config.timeout_for(step.get("model_type", "A"))
            + self.config.get("heartbeat_grace", 10)
            + 15
        )
        deadline = time.time() + timeout

        while time.time() < deadline:
            self.main_hb.beat()
            self._drain_heartbeats()

            try:
                msg = self.result_q.get(timeout=0.5)
            except queue.Empty:
                pass
            else:
                if (
                    msg[0] in ("done", "error")
                    and msg[1] == worker_id
                    and msg[2] == attempt_id
                ):
                    if msg[0] == "done":
                        return {"status": "done", "data": msg[3]}
                    return {"status": "error", "message": msg[3]}

            with self._workers_lock:
                proc = self.workers.get(worker_id, {}).get("process")
                if proc and not proc.is_alive():
                    return {"status": "error", "message": "worker exited"}

        with self._workers_lock:
            proc = self.workers.get(worker_id, {}).get("process")
            if proc and proc.is_alive():
                proc.terminate()
                proc.join(timeout=5)
                if proc.is_alive():
                    proc.kill()

        return {"status": "error", "message": "worker wait timeout"}

    # ---------- 状态机执行 ----------

    def run(self, task):
        self.state = self._load_or_init(task)

        while self.state.phase != "DONE":
            self.main_hb.beat()
            phase = self.state.phase

            if phase == "INIT":
                self._prepare(task)
                self.state.phase = "PREPARE"
                self.state.checkpoint["prepared"] = True
                self._save()

            elif phase == "PREPARE":
                if not self.state.checkpoint.get("prepared"):
                    self._prepare(task)
                    self.state.checkpoint["prepared"] = True
                self.state.phase = "EXECUTE"
                self._save()

            elif phase == "EXECUTE":
                self._execute_plan(task)
                self.state.phase = "VALIDATE"
                self._save()

            elif phase == "VALIDATE":
                self._validate_global()
                self.state.phase = "FINALIZE"
                self._save()

            elif phase == "FINALIZE":
                output = self._finalize()
                self.state.checkpoint["output"] = output
                self.state.phase = "DONE"
                self._save()

            else:
                raise RuntimeError(f"unknown phase: {phase}")

        return self.state.checkpoint["output"]

    def _prepare(self, task):
        # 幂等准备
        self.state.checkpoint["plan_signature"] = self._plan_signature(task)
        self.state.checkpoint["task_meta"] = {
            "run_id": task["run_id"],
            "steps": task.get("steps", []),
        }

    def _plan_signature(self, task):
        return json.dumps(
            task.get("steps", []),
            sort_keys=True,
            ensure_ascii=False
        )

    def _plan(self, task):
        return task.get("steps", [])

    def _execute_plan(self, task):
        max_retries = self.config.get("max_worker_retries", 3)

        for step in self._plan(task):
            step_id = step["step_id"]

            if step_id in self.state.completed_steps:
                continue

            retries = self.state.retries.get(step_id, 0)

            while retries <= max_retries:
                self.main_hb.beat()

                self._start_worker(step, retries)
                result = self._wait_worker(step_id, retries)

                if result["status"] == "done":
                    # 独立质量规则，B_turbo 跳过 reasoning_ratio
                    try:
                        QualityGate(self.config).validate(result["data"], step)
                    except QualityError as e:
                        retries += 1
                        self.state.retries[step_id] = retries
                        self._save()
                        self._backoff(retries)
                        continue

                    self.state.checkpoint.setdefault("results", {})[step_id] = result["data"]
                    self.state.completed_steps.add(step_id)
                    self._save()
                    break

                # worker 崩溃/超时/error
                retries += 1
                self.state.retries[step_id] = retries
                self._save()
                self._backoff(retries)

            else:
                raise RuntimeError(
                    f"step {step_id} failed after {max_retries} retries"
                )

    def _validate_global(self):
        # 全局校验；如果失败可回退到 EXECUTE，重跑指定 step
        return True

    def _finalize(self):
        results = self.state.checkpoint.get("results", {})
        # 生产环境建议大结果写入 result store，这里只做演示
        return {
            "run_id": self.state.run_id,
            "results": results,
        }

    def _backoff(self, retries):
        deadline = time.time() + min(2 ** retries, 30)
        while time.time() < deadline:
            self.main_hb.beat()
            time.sleep(1)
```


### 场景 3：Engine 主进程被 kill -9

```text

state 文件保留最后一条安全状态
下次运行 python main.py
Engine 发现相同 run_id
自动跳过 completed_steps
从断点续跑
```

## 5. 双轨自衡设计

执行轨和校验轨不是互相消灭，而是通过状态机握手：

- 执行轨：负责生成结果，产生 `completed_steps`。
- 校验轨：负责质量门禁，只对未完成/未通过的 step 触发重试。
- B_turbo 的高 reasoning_ratio 是正常特性，由 B 轨独立规则承接，不进入废稿重试循环。
- 已完成步骤不会回滚，只有未完成/失败步骤会重试，系统状态单调前滚，避免“功能熵”无限累积。

这套机制不需要外部守护进程，崩溃恢复能力全部内建在 Engine 自身。
