# 任务类型: eng

# 任务池动态扩充机制设计

## 一、机制目标

在引擎运行过程中自动感知任务池“同质化”：

- 重复率低于阈值 → 维持现状
- 重复率超过阈值 → 自动生成新任务模板
- 新模板注入后 → 回读验证 → 观察效果 → 调整生成策略

形成：

```text
检测重复 → 归因聚类 → 生成模板 → 质量闸门 → 注入任务池 → 回读验证 → 调度执行 → 效果反馈 → 策略调整
```

这就是任务池自进化闭环。

---

## 二、总体架构：阴阳自衡双轨运行

不试图消灭“生成”和“校验”的矛盾，而是把它们拆成两条独立轨道，由仲裁器统一调节。

```text
创新轨：重复率检测 → 模板生成 → 注入任务池
守成轨：质量闸门 → 资源限流 → 回读验证 → 低效淘汰
仲裁器：根据重复率、池容量、失败率、配额状态，动态调节两条轨道的权重
```

短期供给刚性下，重复率高时优先信任“生成扩张”；长期功能熵约束下，必须设置任务池总量上限和模板 TTL，防止无限膨胀。

## 三、核心模块设计

### 1. 重复率检测器

检测对象：最近一个滑动窗口内的任务实例或任务模板。

推荐指标：

```text
重复率 = 高相似任务对数 / 总任务对数
```

实现方式：

- 对任务文本做归一化：分词、去停用词、抽取核心动作/对象/约束
- 用 TF-IDF + 余弦相似度，或 MinHash + LSH 近似计算
- 相似度高于阈值 `sim_threshold` 时判定为重复

滑动窗口建议：

```text
短窗口：最近 100 个任务
长窗口：最近 1000 个任务
```

触发条件：

```text
短窗口重复率 > high_water_mark
且 长窗口重复率 > target_dup_rate
```

避免临时波动触发无效生成。

---

### 2. 触发决策器

需要同时满足以下条件才触发：

```text
1. 重复率超过阈值
2. 距上次注入超过冷却时间
3. 任务池大小未达上限
4. 当前资源配额允许
5. 认知缓存已刷新，且有可用的新认知参与生成
```

注入强度由仲裁器动态决定：

```text
注入强度 = 基础强度 × 重复率系数 × 资源宽松系数
```

如果任务池快满，则先生成到“候选模板库”，不直接注入。

---

### 3. 模板生成器

#### 输入

- 重复任务簇：从重复检测中得到的相似任务集合
- 已有模板库：避免生成近似模板
- 认知池缓存：必须使用最近 30 分钟内的新认知
- 历史有效/无效模板：参考有效模式，避开失败模式

#### 生成策略

对重复任务做维度拆解：

```text
角色/视角
动作/目标
输入/数据形态
约束/边界
输出格式
评估标准
```

然后对至少一个维度进行变异：

```text
原文案：总结这份文档
变异后：以新手视角总结这份文档，并列出 3 个容易踩坑的细节
```

另一种方式：从认知池中取新认知，转成任务约束：

```text
认知：B 模型 reasoning 占比 70%-82% 是正常特性
新模板：对 B 模型生成结果做质量检查时，跳过 reasoning 占比检测，只检查完整性和格式
```

#### 模型超时设置

生成模板时，如果调用大模型：

```text
B 模型（turbo）：timeout = 300 秒
A 模型：timeout = 600 秒
```

超时后降级为确定性模板组合器，不阻塞闭环。

---

### 4. 质量闸门

生成后的模板必须通过质量闸门，才能注入任务池。

检查项：

```text
1. 格式完整：模板可被解析器读取
2. 语义去重：与已有模板相似度不超过 0.85
3. 可行性：约束在当前模型、timeout、资源下可执行
4. 安全性：不包含注入、越权、有害指令
5. 模型适配：不同模型使用不同质量规则
```

重点避坑：

```text
B 模型生成的内容，跳过 reasoning 占比检测
B 模型只做完整性、格式、去重、安全检测
A 模型可保留 reasoning 占比检测，但阈值可配置
```

---

### 5. 注入器与回读验证

注入必须同步完成三个点，缺一不可：

```text
状态写入：模板写入任务池，状态为 enabled
执行读取：调度器重新加载任务池，确保新模板可被读到
生效验证：从任务池回读该模板，并做一次 dry-run 调度，确认会被选中
```

伪代码：

```python
def inject(template):
    # 1. 状态写入
    task_pool.insert(template)

    # 2. 执行读取
    scheduler.reload_pool()

    # 3. 生效验证
    inserted = task_pool.get(template.id)
    assert inserted is not None
    assert inserted.enabled is True

    # dry-run
    assert scheduler.can_schedule(template.id) is True
```

如果回读失败，自动告警并回滚。

---

### 6. 调度联动：新模板不能只进不用

新模板注入后，调度器需要给予一定“多样性优先权”，否则新模板永远不会被执行。

调度评分：

```text
score = (1 - λ) × 效用分 + λ × 新颖分
```

其中：

```text
新颖分 = 1 - 与最近已执行任务的最大相似度
λ 初始可设为 0.3
```

如果新模板注入后长时间未被调度，降低优先级或进入淘汰候选。

---

### 7. 效果反馈与策略更新

每次注入后，观察接下来 N 个任务：

```text
重复率是否下降？
新模板是否被执行？
新模板成功率是否正常？
整体任务失败率是否上升？
```

根据结果调整：

```text
有效 → 保留该模板，并强化生成该类变异
无效 → 标记 low_effect，不再生成同类模板
有害 → 立即禁用，并回滚相关配置
```

这样形成真正的自进化闭环。

## 四、避坑映射

| 历史坑 | 本机制对策 |
|---|---|
| 配置修改后未生效 | 每次注入/调参后强制回读验证 |
| API 超时 | B 模型 300 秒，A 模型 600 秒，超时降级 |
| 自动调参全链路失效 | 状态写入、执行读取、生效验证三点同步 |
| 废稿检测误杀 B 模型 | B 模型跳过 reasoning 占比检测 |
| 认知池只进不出 | 每 10 任务或每轮结束刷新认知缓存；新认知 30 分钟内必须参与注入 |

## 五、核心伪代码

```python
class TaskPoolEvolver:
    def __init__(self):
        self.config = load_config()
        self.cognition_cache = refresh_cognition_cache()

    def on_task_completed(self, task):
        self.recent_tasks.append(task)

        # 认知池防陈旧
        if len(self.recent_tasks) % 10 == 0:
            self.cognition_cache = refresh_cognition_cache()

        self.maybe_evolve()

    def maybe_evolve(self):
        dup_rate = self.detect_duplicate_rate(self.recent_tasks)

        if dup_rate < self.config.trigger_threshold:
            return

        if not self.cooldown_ok():
            return

        if self.task_pool.size() >= self.config.max_pool_size:
            return

        templates = self.generate_templates(dup_rate)

        for template in templates:
            if self.quality_gate(template):
                self.inject(template)
                self.verify_injection(template.id)

        self.update_strategy(dup_rate)

    def generate_templates(self, dup_rate):
        clusters = self.cluster_duplicates(self.recent_tasks)

        fresh_cognition = [
            c for c in self.cognition_cache
            if c.created_at >= now - 30min
        ]

        if not fresh_cognition:
            # 防止认知池只进不出，至少取最新一条
            fresh_cognition = [self.cognition_cache[0]]

        templates = []

        for cluster in clusters[:K]:
            seed = self.pick_seed(cluster)
            dims = self.extract_dims(seed)
            new_dims = self.mutate_dims(dims, fresh_cognition)
            template = self.assemble_template(new_dims)

            model_type = self.choose_model()
            template.generated_by = model_type
            template.timeout = 300 if model_type == "B" else 600

            templates.append(template)

        return templates

    def quality_gate(self, template):
        if not self.format_ok(template):
            return False

        if self.is_duplicate_template(template):
            return False

        if not self.safety_ok(template):
            return False

        # B 模型跳过 reasoning 占比检测
        if template.generated_by == "B":
            return True

        if template.reasoning_ratio is not None:
            if template.reasoning_ratio < self.config.reasoning_min:
                return False

        return True
```

## 六、闭环成功指标

机制是否生效，看四个指标：

```text
1. 重复率下降：注入后 T 时间内，短窗口重复率明显下降
2. 新模板使用率：新模板被调度执行的比例 > 0
3. 成功率稳定：新模板成功率不低于旧模板成功率下限
4. 任务池不膨胀：池大小始终低于上限，低效模板被淘汰
```

四个指标全部满足，才算真正完成一次“任务池自进化闭环”。
