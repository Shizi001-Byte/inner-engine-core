## 一、底层逻辑依据（基于已有认知锚定，无重复论证）
### 1. 问题本质映射
当前L4成品转化模块仅支持SOP的**强固化单类型结构**属于「有（低熵单一有序）」，随着业务需求扩展（多类型输出），原有结构的适配性失效，是「有→无（高熵无序、能力缺失）」的自发熵增过程，完全符合「反者道之动」的自否定演化规律，并非意外故障。
### 2. 修复原则锚定
- **反者道之动维度**：主动引入多类型扩展的高熵可能性，通过编码实现（负熵输入）转化为新的多类型有序结构；同时适配AI系统的熵增退化必然性，预留三层退化兜底（配置层/接口层/质量层）。
- **弱者道之用维度**：采用弱约束柔性架构替代硬编码强固化逻辑，确保系统可持续接收负熵（新增类型），避免强固化结构加速熵增崩溃。
---
## 二、问题根因明确
当前L4成品转化链路存在两个核心缺失：
1. **扩展能力缺失**：采用硬编码判断仅支持SOP类型，无多类型抽象层（强固化结构，符合「弱者道之用」的反例特征）。
2. **全链路未落地**：Code/Checklist两类的配置项、生成逻辑、格式化校验、超时配置均未实现。
> 风险等级判定为low：改动为增量扩展，无侵入式修改原有SOP逻辑，有配置化回滚+降级兜底能力，影响范围仅局限于L4转化模块。
---
## 三、修复方案整体设计
采用**「弱约束策略架构+配置化驱动+三层退化兜底」**方案：
- 横向：新增Code/Checklist两类转化能力，满足当前需求。
- 纵向：通过抽象策略层实现弱约束扩展，后续新增类型仅需加配置+策略类，无需修改核心流程，避免强固化熵增。
- 兜底：对应AI系统三层熵增退化（配置层/接口层/质量层）设置分级降级机制。

```python
# config/l4_config.py
import yaml
from pydantic import BaseModel, ValidationError

class L4TypeConfig(BaseModel):
    model: str
    timeout: int
    prompt_template: str
    output_schema: str

class L4Config(BaseModel):
    supported_types: list[str]
    sop: L4TypeConfig
    code: L4TypeConfig
    checklist: L4TypeConfig

    @classmethod
    def load(cls) -> "L4Config":
        with open("config/l4_config.yaml") as f:
            data = yaml.safe_load(f)["l4_convert"]
        # 启动时校验配置完整性，缺失直接报错（避坑：配置不生效）
        try:
            return cls(**data)
        except ValidationError as e:
            raise RuntimeError(f"L4配置校验失败: {e}") from e

    def get_type_config(self, target_type: str) -> L4TypeConfig:
        # 统一读取入口，避免配置散落在代码中
        return getattr(self, target_type, self.sop)
```

#### 3. 策略实现层新增（3个策略类）
> 对应「反者道之动」：负熵输入，将多类型可能性转化为实际有序能力
- 原有SOP逻辑迁移为`strategies/sop_convert_strategy.py`（无逻辑修改，仅适配抽象接口，确保兼容）
- 新增`strategies/code_convert_strategy.py`：
```python
from .base_convert_strategy import BaseConvertStrategy
from ai_client import AIClient
import re

class CodeConvertStrategy(BaseConvertStrategy):
    def generate(self, input_prompt: str) -> str:
        client = AIClient(model=self.model)
        # 明确传入配置的超时时间（避坑：API调用超时）
        return client.generate(
            prompt=self.prompt_template.render(input_prompt=input_prompt),
            timeout=self.timeout
        )

    def format(self, raw_content: str) -> Dict:
        # 代码结构化：提取代码块、识别语言、补全元数据
        code_blocks = re.findall(r"```(\w+)\n(.*?)```", raw_content, re.DOTALL)
        return {
            "type": "code",
            "language": code_blocks[0][0] if code_blocks else "unknown",
            "content": code_blocks[0][1] if code_blocks else raw_content.strip(),
            "metadata": {"model": self.model, "raw_length": len(raw_content)}
        }
```
- 新增`strategies/checklist_convert_strategy.py`：
  逻辑与Code策略对齐，`format`方法实现检查清单结构化（提取条目、权重、检查标准等字段）。

#### 4. 策略工厂层新增（文件：`strategies/convert_strategy_factory.py`）
> 对应「弱者道之用」：弱约束路由，避免硬编码分支，新增类型无需修改工厂核心逻辑
```python
from typing import Type
from config.l4_config import L4Config
from .base_convert_strategy import BaseConvertStrategy
from .sop_convert_strategy import SopConvertStrategy
from .code_convert_strategy import CodeConvertStrategy
from .checklist_convert_strategy import ChecklistConvertStrategy

class ConvertStrategyFactory:
    # 策略映射表，新增类型仅需在此注册+加配置，无需改核心流程
    _strategy_map: dict[str, Type[BaseConvertStrategy]] = {
        "sop": SopConvertStrategy,
        "code": CodeConvertStrategy,
        "checklist": ChecklistConvertStrategy
    }

    @classmethod
    def get_strategy(cls, target_type: str, config: L4Config) -> BaseConvertStrategy:
        # 一层退化兜底（配置层熵增）：未知类型降级为SOP
        if target_type not in cls._strategy_map or target_type not in config.supported_types:
            target_type = "sop"
        type_config = config.get_type_config(target_type)
        return cls._strategy_map[target_type](type_config)
```

#### 5. 主流程修改（文件：`l4_converter.py`）
> 替换原有硬编码判断，接入策略工厂+三层退化兜底
```python
from config.l4_config import L4Config
from strategies.convert_strategy_factory import ConvertStrategyFactory

class L4Converter:
    def __init__(self):
        self.config = L4Config.load() # 启动时加载+校验配置（避坑：配置不生效）

    def convert(self, input_data: dict) -> dict:
        input_prompt = input_data["prompt"]
        origin_type = input_data.get("target_type", "sop")
        strategy = ConvertStrategyFactory.get_strategy(origin_type, self.config)

        # 二层退化兜底（接口层熵增）：超时/调用失败重试
        max_retry = 2
        for i in range(max_retry):
            try:
                raw_content = strategy.generate(input_prompt)
                formatted = strategy.format(raw_content)
                # 三层退化兜底（质量层熵增）：格式校验失败重生成
                if strategy.validate(formatted):
                    return {
                        "type": origin_type if strategy.config == self.config.get_type_config(origin_type) else "sop",
                        "content": formatted,
                        "version": "v2.0",
                        "degrade_flag": strategy.config != self.config.get_type_config(origin_type)
                    }
            except TimeoutError:
                if i == max_retry - 1:
                    break
                continue
        
        # 最终兜底：降级为SOP生成
        sop_strategy = ConvertStrategyFactory.get_strategy("sop", self.config)
        raw_content = sop_strategy.generate(input_prompt)
        formatted = sop_strategy.format(raw_content)
        return {
            "type": "sop",
            "content": formatted,
            "version": "v2.0",
            "degrade_flag": True
        }
```
