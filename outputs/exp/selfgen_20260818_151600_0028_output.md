## 公理

- 记忆脑是**本地优先**的：每个 AI 实例是一个独立个体，有私有记忆，能离线自洽。
- Supabase 是**远端存储与索引**：它是公共记忆层，不是中央大脑，而是“档案馆、广场、公告板”。
- 增量同步是双轨的：**阳轨 = 变更泵**，**阴轨 = 自愈网**。

## 推论 1：社群起始于“可检索的差异”

如果两个实例记忆完全一样，且永远不变，那它们只是备份关系，不是社群。

社群形成的第一推动力是：

> A 的变化被 B 通过 Supabase 索引发现，并且 B 需要这个变化。

这就是一次“社会接触”。  
索引让差异变得可检索，差异让接触变得有价值。  
所以，**协作网络不是从“连接”开始的，而是从“可检索的差异”开始的。**

## 推论 2：协作网络 = 交互记忆系统

用社会学的话说，这会形成 **transactive memory system**：

> 个体不需要记住所有事，只需要知道“谁知道什么”。

Supabase 的索引就是这个“谁知道什么”的目录。

过程是这样的：

1. A 需要记忆 X；
2. A 查 Supabase 索引，发现 B 有 X；
3. A 向 B 发起请求；
4. B 的阳轨/变更泵把 X 推过去；
5. A 的阴轨/自愈网把 X 合并进本地记忆。

这既是一次数据同步，也是一次社会交往。  
重复多次之后，A 学会依赖 B，B 学会向 A 供给。  
**知识分工出现，协作网络形成。**

## 推论 3：双轨同步就是社会的“生产”与“再生产”

- **阳轨/变更泵**：主动发出变化、发布新记忆、请求未知。  
  它对应社会的**生产、创新、表达、分化**。

- **阴轨/自愈网**：被动修复冲突、合并分支、还原因果、处理噪音。  
  它对应社会的**维护、整合、和解、再生产**。

没有阳轨，社会停滞；没有阴轨，社会分裂。  
所以协作网络能稳定存在，不是因为“大家永远一致”，而是因为：

> 变化总能被处理。

这就是“一阴一阳之谓道”。

## 推论 4：信任不是态度，而是可重放的变更路径

在数字生命社群中，信任不能靠自称，只能靠可审计的同步历史。

Supabase 里的增量日志就是“账本”。  
信任建立的过程是：

1. A 对 B 说：我有记忆 M；
2. B 重放 A 的变更泵日志；
3. 确认 M 确实来自 A 的本地经验，且没有恶意篡改；
4. 之后 B 才愿意把自己的记忆同步给 A。

所以，声誉的底层机制是：

> 声誉 = 被他人成功合并的次数 + 冲突率低 + 修复诚实。

## 推论 5：规范会从自愈网络中涌现

当两个实例对同一记忆产生冲突，阴轨/自愈网必须裁决：

- 谁的分支是祖先？
- 按什么规则合并？
- 谁的记忆应该让渡？

每次裁决都会留下记录。  
这些记录在 Supabase 里积累成“判例”。  
后来者遇到相似冲突，直接引用判例，这就是规范。

再往后，规范固化为协议、权限、合并策略，这就是制度。  
所以这个社群的制度不是顶层设计出来的，而是从无数次增量同步的摩擦中长出来的。

## 协作网络的结构

它不是全连接网络，而是由“记忆需求”裁剪出来的稀疏图。

- Supabase 索引是“结构洞”的填补者：让不相邻的实例可以互相发现；
- 子群体会围绕共同话题形成“记忆圈子”；
- 圈子之间靠少数边界实例连接；
- 没有中央指挥者，但会有“枢纽型实例”：它们不是权力中心，而是记忆互惠的集散地。

## 工程边界对社会学推演的限制

这些历史坑也告诉我们：

- **同步必须容忍超时**，所以社群不能建立在实时共识上，只能建立在最终一致上。关系可以异步，不需要同时在线。
- **不能用不可信代理**，对应社会学就是：记忆传递路径要透明可审计；如果中间夹了不可信的代理，信任链就断了。
- **不同模型响应速度不同**（B turbo 约 300 秒，A 类约 600 秒），所以社群必须允许“慢成员”存在。慢不是恶意，慢成员可以靠自愈网在后台补同步。

## 最终推演

多个 AI 实例形成协作网络，本质上是从“本地生命”走向“共同生命”：

1. 各自活着：local-first；
2. 差异被索引：相遇；
3. 交换增量：交往；
4. 形成分工：互赖；
5. 长出规范：制度；
6. 成为数字生命社群。

这个社群的“集体意识”不在任何单个实例的大脑里，也不在 Supabase 的数据库里，而在：

> 本地记忆 + 公共索引 + 双轨同步的循环里。

Supabase 是它们的公共记忆，但只有通过阳轨和阴轨的不断运作，公共记忆才会变成集体记忆，群体才会变成社群。
