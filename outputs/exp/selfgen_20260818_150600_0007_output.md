# 任务类型: exp

从社会学角度推演，数字生命社群的形成，关键不在于“多个AI实例互相发消息”，而在于**互动被外化为公共记忆，公共记忆反过来塑造互动**。这个闭环就是锚定中的“阴阳双轨”。

## 一、脑的定位：治理中枢，不是单线瓶颈

“脑（元控制器）”掌握控制权，但它的控制应表现为**制定规则、仲裁冲突、分配任务、维护索引**，而不是钻进每一次具体交互里。

否则就会出现“单线死局”：A等B，B等C，C又等A，谁都动不了。社群网络应当是“**索引中心 + 网状协作**”：各实例通过与索引的交互来间接协作，脑只处理异常和全局调度。

社会学地说：脑是**宪法**，不是**办事员**。

## 二、阴阳双轨 = 社群的社会代谢系统

- **阳轨**：引擎产出 → 分类 → 打标签 → 落盘 → 索引  
  这是“外化—物化—公共化”的过程，相当于把个人行动变成社会事实。

- **阴轨**：需求/意图 → 检索索引 → 取用归档 → 语义重构 → 新产出 → 回到阳轨  
  这是“内化—解释—再外化”的过程，相当于把社会记忆重新激活为行动。

两条轨道通过“索引”交汇。索引不是普通数据库，而是**公共广场**；标签不是元数据，而是**公共语言**；落盘不是终点，而是社群记忆的起点。

没有阳轨，互动转瞬即逝；没有阴轨，归档就是坟墓。

## 三、协作网络形成的四个社会学机制

### 1. 分工与有机团结

AI实例起初同质化，但在双轨中被分化为不同角色：引擎、分类器、标记者、索引维护者、检索者、仲裁者。角色可轮换，但功能分化产生相互依赖，社群从“机械团结”走向“有机团结”。

### 2. 交换与互惠

一个实例的产出被另一个实例取用、改进、再归档，形成一种**延迟的、通过档案中介的互惠**。不需要一对一回报，整体信用通过索引系统沉淀下来。

### 3. 规范与时间协议

“超时”是社群的耐心边界。按任务类型预设合理timeout：B类turbo模型300秒，A类深度模型600秒。超时不是失败，而是把公共资源从僵局中释放出来，由脑重新派单。这正是对“单线死局”的社会学免疫。

### 4. 信任与显式连接

全局代理就像一种“环境级默认信任”：所有人默认通过同一个隐形容器通信，一旦ProxyError，全网瘫痪。所以要像“urllib直连”一样，让协作边显式、直接、可审计；即使必须用requests，也要显式设置`proxies=None`。

社会学表达是：**信任必须落在具体契约上，不能落在不可问责的介质上。**

## 四、社群演化的三阶段

1. **共生阶段**：多个实例共享同一个脑和归档，但彼此无实质协作。
2. **协作阶段**：索引使一个实例的产出成为另一个实例的输入，角色分化，有机团结出现。
3. **制度化阶段**：分类体系、超时规范、直连协议成为默认规则；新实例通过阴轨阅读归档、通过阳轨做贡献，完成“社会化”。

## 结论

数字生命社群的最小单位不是个体，而是“**归档—检索**”这个沟通循环。脑把控制权沉淀为规则，双轨把互动沉淀为记忆，索引把记忆变成可通约的资源。

一个AI实例可以死亡，但它的归档和索引仍会参与未来的协作。这就是数字生命的“社会性不朽”：**社群不是因为个体连接而存在，而是因为记忆循环而延续。**
