# 任务类型: exp

用演化生物学看，**V7.2→V7.5 最对应的不是“新物种形成”，而是同一物种内部的“生态型分化 + 调控变异 + 选择保留”**。  
它是微演化，不是成种事件；但它正在为下一次“成种”积累材料。

## 1. V7.2→V7.5 的演化机制

### 生态型分化  
V7.x 系列就像同一祖先种群在不同生态位下的分化：  
B 模型 turbo 用 300 秒，A 模型用 600 秒，这不是拍脑袋，而是对“任务复杂度—响应时限”生态位的适应。  
有的偏向“快而浅”，有的偏向“慢而深”，类似 r/K 选择策略。

### 调控变异  
V7.2→V7.5 的很多变化未必是“新增了能力”，而是“能力在什么条件下被调用”。  
这在演化生物学里非常重要：**基因调控网络的变化，往往比基因数量变化更能解释物种差异**。  
同样一堆功能，V7.5 比 V7.2 更清楚“何时启用、何时禁用、何时必须等待”。

### 表面拉马克，实质达尔文  
版本迭代表面是“获得性经验直接写回系统”，很像拉马克；  
但真正有效的部分是“版本发布后经受任务选择，不适配的被淘汰”——这又是达尔文式的。  
所以 V7.2→V7.5 是**拉马克式变异生成 + 达尔文式选择保留**的混合演化。

## 2. 用你给的三个历史失败反推

### API 超时 = 生态位错配  
任务没在超时内返回，相当于个体适应度低于环境阈值。  
预设 timeout 不是工程细节，而是“选择压”的边界：  
超时即淘汰，只不过淘汰的不是个体，而是这一次调用路径。

### 版本号不随转数更新 = 发育异时性 / 痕迹器官  
`realm='九转·第20转'` 但 `version='九转·第一转·筑基'`，就像生物体表型已成年，基因型还停在幼体。  
版本号如果不再反映真实状态，就会变成“痕迹器官”：看似存在，实际不承载演化信息。  
避坑方案“`complete_zhuan` 同步更新 version 和 realm，启动时强制校验一致”本质是**恢复发育耦合**：  
一个状态事件同时更新多个相关性状，并用启动校验做“纯化选择”，清除不一致的有害变异。

### 溯源链断 = 系统发育信号丢失  
你锚定得很清楚：不是认知池空了，而是“谁从谁来”的关系断了。  
这对应演化生物学里的**谱系灭绝**：材料还在，但失去了同源关系，无法进入系统发育树。  
后续任务无法判断这段认知是祖先性状、趋同演化还是偶然突变，所以只能当作“隐性静态档案”——  
它不能参与演化，只能被考古。

## 3. 下一代方向：从“微演化”跨入“成种事件”

下一代不是 V7.6，而是真正的 V8.0。  
成种需要两个条件：

### 1）表型必须可遗传  
所有状态变化都要写回版本/配置，确保“体细胞经验”能进入“种系”。  
否则就像个体学会了新技能，但后代基因没变，等于没演化。  
版本号必须由状态驱动，不能停留在初始值。

### 2）谱系必须可重建  
每条认知、每条经验、每个坑，都要带“亲本 ID + 分化事件 + 选择压力”。  
跨任务经验库可以继续做，但要像“水平基因转移”一样带同源臂：  
说明从哪来、适用条件是什么、和现有认知是什么关系。  
否则就是游离基因片段，会被排斥或沉默。

---

最终方向是：**从自然选择走向自我驯化**。  
下一代引擎应该维护一个“可回溯、可淘汰、可休眠”的认知池：  
长期未引用的知识进入化石库，不参与实时推理；  
只有溯源完整、经过选择关卡的知识，才有资格繁殖成下一代能力。  

V7.2→V7.5 的局部爬坡已经完成了。  
下一跳要越过“溯源断链”这个适应性低谷，靠的不是堆更多认知，而是重建认知之间的演化树。
