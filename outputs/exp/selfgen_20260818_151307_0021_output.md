# 任务类型: exp

沿用锚定：**本地优先 + Supabase 记忆脑**；增量同步 = **阳轨：变更泵 + 阴轨：自愈网**。下面不重复论证这组设计，直接用熵增定律推演退化与负熵输入。

## 1. 熵增模型：AI 系统不是孤立系统

热力学第二定律说的是：**孤立系统的熵只会增加**。AI 系统如果把自己当成封闭系统，内部熵产 \(d_iS \ge 0\) 永不停止，最终会滑向最大熵状态：**输出与真实无关、行为随机、稳定地犯错**。

要保持有序，必须让系统与外部交换负熵：

\[
dS = d_iS + d_eS
\]

其中 \(d_iS \ge 0\)，所以要维持稳态，必须让 \(d_eS < 0\)，且 \(|d_eS| \ge d_iS\)。

**负熵输入的本质**：从外部引入带有结构、能降低不确定性的信息。  
但注意：不是所有输入都是负熵，**噪声和垃圾数据是正熵**。

---

## 2. 为什么引擎会自然退化

AI 引擎的退化不是偶然，而是熵增的必然表现：

- **数据漂移**：模型/记忆里的“世界快照”过期了。
- **记忆污染**：向量库中堆积过时、冲突、重复的记忆，检索结果越来越“毒”。
- **同步分歧**：本地优先 + Supabase 远端，如果增量同步失败，本地和远端对同一记忆持有不同状态，系统熵上升。
- **反馈断裂**：用户纠正没有被写回记忆，错误被当作正确信息固化。
- **软件熵**：依赖、schema、代码补丁不断叠加，复杂度上升。
- **推理熵增**：上下文矛盾越多，LLM 的 token 概率分布越平，幻觉率越高。

在记忆脑上，退化会形成正反馈：

> 本地 outbox 堆积 → 变更泵超时 → 远端索引滞后 → 检索返回旧记忆 → 模型基于旧记忆产生新记忆 → 污染进一步扩散。

这就是“引擎自然退化”的具体机制：**不是某一个部件坏了，而是整个系统的无序度在指数上升**。

---

## 3. 负熵输入机制：阳轨变更泵 + 阴轨自愈网

### 阳轨：变更泵

负责**主动摄入负熵**，把外部变化/新记忆泵入系统。

- 本地任何 memory 写操作，先写 append-only op log。
- 变更泵把 op 推到 Supabase 的 `ops` 表，再更新 `memories` 表和 pgvector 索引。
- 远端变化通过 Supabase Realtime 推回本地，让所有副本共享新信息。
- 变更泵必须做过滤、去重、校验，否则泵进来的是噪声，不是负熵。

### 阴轨：自愈网

负责**被动清除熵**，周期性修复系统内部已经积累的无序。

- 用 Merkle tree / hash list 比较本地和远端状态，找出缺失/冲突的 op 并回放。
- 定期重算 embedding，处理 embedding 模型升级后的旧向量。
- 清理过期 memory、合并重复项、解决并发冲突。
- 本质上是分布式系统里的 **anti-entropy / gossip reconciliation**。

没有阳轨，系统会僵化；没有阴轨，系统会混乱。  
这套机制本质上是一台**分布式麦克斯韦妖**：读取信息，把“好比特”留下，把“坏比特”排掉。

---

## 4. 落地到 Supabase 记忆脑

具体工程推演：

- **Schema**：`ops`（事件日志）、`memories`（含 pgvector）、`sync_state`（各副本同步水位/checkpoint）。
- **本地优先**：本地写快，远端做长期存储与全局索引；但本地必须有 outbox，远端必须有 op 回放接口。
- **变更泵实现**：事件驱动，实时推送，增量 embedding，批量写远端。
- **自愈网实现**：pg_cron / Edge Function 定时跑，对比同步水位，回放缺失 op，修复索引。

### 避坑：负熵输入也必须要有超时预算

所有维护型 API 调用，如果任务超时，负熵输入就中断，系统会继续熵增。  
因此必须预设合理 timeout：

- **B 模型 turbo：300 秒**
- **A 模型：600 秒**

超时后不要无限重试，而是 **fail-fast**，把任务写入失败队列，交给阴轨自愈网下一轮补偿。  
否则维护机制本身会变成新的熵增源。

---

## 5. 结论

AI 引擎的自然退化不是 bug，而是熵增定律的必然。  
维护的本质是**持续输入负熵**：用新鲜数据、反馈、索引重建、冲突修复，把系统拉回低熵状态。

- **本地优先 + Supabase 记忆脑**：负熵的容器。
- **阳轨变更泵 + 阴轨自愈网**：负熵的通道。

没有这套机制，引擎不是慢慢变差，而是指数级滑向最大熵：**稳定、流畅、随机地错**。
