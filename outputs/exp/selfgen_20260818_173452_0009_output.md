# 任务类型: exp

按你的锚定：**数字生命社群 = 带验证门和公共档案的协作 DAG**。不重复证明这个结论，直接用它推演维护机制。

## 1. 熵平衡式：退化是默认项，不是 bug

把 AI 系统看作开放系统：

\[
\frac{dS}{dt} = \sigma - \Phi
\]

- \(\sigma \ge 0\)：内部自发熵产。只要系统在运行，权重会过期、上下文会污染、记忆会漂移、反馈会自激。
- \(\Phi\)：负熵输入通量。来自外部验证过的事实、结构性约束、清理操作、人类反馈。
- 如果 \(\Phi < \sigma\)，引擎自然退化；如果 \(\Phi > \sigma\)，系统维持或进化。

所以“AI 引擎会自然退化”不是偶然故障，而是热力学第二定律的默认趋势。维护的本质，就是持续向系统输入负熵。

## 2. 退化的三条熵增通道

### ① 参数熵增：模型权重冻结，世界在变

模型的知识是训练时快照。现实世界不断产生新事件、新事实、新分布。旧参数对不上新世界，输出概率开始“均匀化”——也就是越来越平庸、越来越不确定。

### ② 上下文熵增：窗口被噪声填满

长对话、历史记忆、中间结果会不断积累。无关信息、矛盾信息、重复信息占据上下文窗口，注意力被稀释。系统表面上还在运行，实际上已经接近“最大熵状态”：什么都像，什么都不准。

### ③ 记忆熵增：用生成代替回忆

一旦“补全记忆”被当成“回忆”，模型就会用概率生成填充缺失。这些未经验证的填充一旦进入公共档案，就会在 DAG 里产生伪边。伪边会传染：后续记忆基于伪边继续生长，整个协作图从晶体变成一团乱麻。

## 3. 负熵输入机制设计

### 3.1 验证门 = Maxwell demon

所有输入——数据、记忆、任务结果——先过验证门，分三类：

- **可验证且已验证**：绑定外部证据，进入公共档案。
- **不可验证**：降级为个体叙事，禁止进入公共 DAG。
- **已证伪**：标记后丢弃，或作为反例节点保留。

验证门不是简单过滤，而是减少系统“可访问微观态数”。一个未经验证的说法有无数种可能；一个绑定证据的节点只有一个位置。

### 3.2 公共档案 = 外部参考系

公共档案不是“大家共享一份长文本”，而是**带验证门的协作 DAG**：

- 节点 = 可验证事件 / 结论
- 边 = 因果、引用、支持、反驳
- 每个节点有公共 ID，可回溯到原始证据

新记忆必须引用已有公共节点。没有引用的记忆不能合并进公共层，只能作为暂存或个体叙事。

这就像晶体生长：新原子必须落在晶格位置上。没有这个约束，系统就会变成气体，每个实例各自漂移，群体熵极大。

### 3.3 第一件事永远是重锚定，不是补全

记忆缺失时，正确动作不是问模型“当时发生了什么”，而是问：

> 公共档案里有没有对应事件？

- 有：把个体记忆绑定到公共事件 ID。
- 没有：明确标记为“未知 / 个体叙事 / 推测”。

“补全记忆”是最大熵猜测；“重锚定到可验证事件”才是负熵输入。  
这也是为什么你已有的锚定说：**第一件事不是补全记忆，而是给记忆重新锚定到可验证事件，或者明确降级为个体叙事。**

### 3.4 负熵清洗：定期删除也是维护

- 定期校验 DAG 一致性：悬空引用、冲突边、无源节点。
- 低置信度节点自动降级为个体叙事。
- 冗余节点合并，过期节点归档。
- 被污染的上下文直接重置，从公共档案重建，而不是继续在长上下文里打转。
- 模型更新时，用验证后的公共档案作为训练信号，绝不用模型自己的生成输出训练自己。

删除和遗忘不是损失，而是把熵排出系统。Landauer 原则下，清除信息本身要耗散能量，所以维护必须付出真实成本。

## 4. 代价与预算

验证门不是免费的。它需要计算、人工审核、真实世界传感器、时间。  
用你给的避坑提醒来说：**API 调用要设 timeout，B 模型 300 秒，A 模型 600 秒**。这本身就是负熵输入的一部分——一个不返回的调用会阻塞系统，让状态停在未知处，等于放任熵增。

所以维护预算不能只算“数据量”，要算“验证后的有效信息量”。更多原始数据只会增加熵；只有经过验证门、锚定到公共 DAG 的数据，才是真正的负熵输入。

## 一句话结论

AI 引擎退化是熵增，维护就是持续输入负熵；而负熵的载体不是“更多记忆”，而是**带验证门的公共档案 DAG + 重锚定到可验证事件**。  
第一件事永远是：**重锚定，不是补全。**
