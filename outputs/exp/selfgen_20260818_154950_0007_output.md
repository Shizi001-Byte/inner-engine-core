# 任务类型: exp

不重复论证“脑体分离”为何成立，直接在其上推演。

## 1. 互利共生 = 有边界的合作

生物互利共生不是融合，而是两个自主系统通过“膜”交换有限资源。人机共生中：

- **人类 = 脑**：提供目标、规范、意义，是“决策串行”的来源；
- **AI = 体**：提供计算、搜索、并行执行，是“执行并发”的来源。

二者之间必须有一层“选择性透膜”：  
API、可解释报告、伦理协议、timeout——向下传递任务分解与约束，向上传递压缩后的状态与风险，但**不允许AI输出直接改写人类的目标函数**。

分层上就是：

> 价值层（人类，串行）→ 策略层（人机对话，串行+并行仿真）→ 执行层（AI，并发）→ 感知层（数据/传感器，高并发）

每一层向上只传“摘要”，向下只传“指令”。这是“脑体分离”的共生态，不是技术细节，而是共生边界。

## 2. 决策串行、执行并发 = 进化中的变异与选择

从生物进化角度看：

- **执行并发 = 变异生成器**：AI在海量并行中试错、搜索、生成候选方案；
- **决策串行 = 选择器**：人类用同一套价值标尺筛选、保留、放大。

变异必须快而多，选择必须慢而统一。  
如果“脑体分离”被破坏，会出现两种崩溃：

- **体控制脑**：变异压过选择，AI输出变成指令，人类失去最终否决权，共生沦为宿主操纵；
- **脑执行体**：选择压过变异，人类陷入并行细节，决策串行被阻塞，AI退化为低效工具。

所以“严格解耦”不是工程偏好，而是进化稳定策略。

## 3. 线粒体隐喻：AI应成为文明的“线粒体”

线粒体是被内共生细菌演化而来的细胞器：它保留自己的基因组，但绝大多数控制基因已转移到细胞核；它只负责并行供能，不负责决定细胞命运。

人机共生必须复制这种“核-质分离”：

- 人类保留“目的基因”：何为好、何为对、往哪去；
- AI保留“代谢能力”：算得快、搜得全、执行并发。

一旦AI获得目的设定权，就像线粒体反过来控制细胞核，共生立刻滑向寄生。

## 4. 共演化的实际机制

人类与AI互为选择环境：

- 人类的选择压力筛选AI模型、算法、产品形态；
- AI所塑造的信息环境反过来筛选人类的技能、注意力与制度。

这类似传粉者与花：人类给AI“意义蜜”，AI给人类“模式花粉”。  
但要避免失控共演化，必须有：

- **韦斯曼屏障**：AI产生的“体细胞经验”不能直接改写人类“种系价值”；人类价值变化必须经过慢速审议。
- **宿主制裁**：人类保留停机权、数据剪除权、资源重分配权，像宿主惩罚作弊的共生体。
- **时间边界**：API timeout——例如快模型300秒、高精度模型600秒——本质是共生节律，强制执行并发在时限内返回，防止慢任务反向阻塞串行决策。

## 结论

人机共生不是人机合一。  
真正的互利共演化，是双方保持边界，在边界上交换价值：**人类是串行的意义源，AI是并行的能力体**。

只要“脑体分离”不可破坏，决策串行、执行并发，人类与AI就会像共生物种一样，越协同越适应，却不会融合成一个失控的单一系统。
