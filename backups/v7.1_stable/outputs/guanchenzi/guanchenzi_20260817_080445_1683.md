# API 接口设计文档

## 概述
引擎对外提供RESTful API，支持任务提交、状态查询、结果获取。

## 接口列表

### 1. 提交任务
```
POST /api/v1/tasks
Content-Type: application/json

Request:
{
  "task_type": "cognition_single",
  "priority": "B",
  "payload": {
    "file_path": "/path/to/file.md",
    "qc_level": "standard"
  },
  "max_tokens": 50000,
  "max_seconds": 300
}

Response 201:
{
  "task_id": "task_20260817_001",
  "status": "pending",
  "priority": "B",
  "created_at": "2026-08-17T14:30:00+08:00"
}
```

### 2. 查询任务状态
```
GET /api/v1/tasks/{task_id}

Response 200:
{
  "task_id": "task_20260817_001",
  "status": "completed",
  "progress": 100,
  "tokens_used": 12500,
  "started_at": "2026-08-17T14:30:05+08:00",
  "completed_at": "2026-08-17T14:31:42+08:00",
  "result_url": "/api/v1/tasks/task_20260817_001/result"
}
```

### 3. 获取任务结果
```
GET /api/v1/tasks/{task_id}/result

Response 200:
{
  "task_id": "task_20260817_001",
  "qc_score": 82.5,
  "evidence_chain": {...},
  "issues": [...],
  "recommendations": [...]
}
```

### 4. 引擎状态
```
GET /api/v1/status

Response 200:
{
  "version": "7.1.0",
  "uptime_seconds": 86400,
  "queue_stats": {"pending": 5, "running": 2, "completed": 156},
  "token_usage_today": 1250000,
  "token_limit": 2000000,
  "health_score": 88
}
```

### 5. 取消任务
```
DELETE /api/v1/tasks/{task_id}
Response 204: 无内容
```

## 错误码
| 码 | 含义 |
|----|------|
| 400 | 请求参数错误 |
| 404 | 任务不存在 |
| 409 | 任务已在执行，无法取消 |
| 429 | 请求过于频繁 |
| 500 | 引擎内部错误 |

## 限流策略
- 单IP: 100请求/分钟
- 单任务提交: 10次/分钟
- 超出返回429 + Retry-After头
