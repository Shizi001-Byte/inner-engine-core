# 数据处理脚本设计

## 需求
批量处理认知质检报告，提取关键指标并生成汇总。

## 处理流程
1. 扫描 data/qc_reports/ 目录下所有JSON
2. 提取每个报告的 evidence_score, duplication_rate, gene_alignment
3. 按日期分组统计均值、中位数、P90
4. 生成 markdown 汇总报告
5. 异常报告（score<60）单独标记

## 核心代码
```python
import json, glob, statistics
from pathlib import Path
from datetime import datetime

def process_qc_reports(report_dir: str) -> dict:
    reports = []
    for f in glob.glob(f"{report_dir}/*.json"):
        with open(f) as fp:
            reports.append(json.load(fp))
    
    scores = [r['evidence_score'] for r in reports]
    return {
        'total': len(reports),
        'avg_score': statistics.mean(scores),
        'median_score': statistics.median(scores),
        'p90_score': sorted(scores)[int(len(scores)*0.9)],
        'anomaly_count': sum(1 for s in scores if s < 60),
        'anomaly_rate': sum(1 for s in scores if s < 60) / len(scores) * 100,
    }
```
