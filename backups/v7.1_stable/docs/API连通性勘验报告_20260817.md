## 六、风险与建议

1. **响应耗时偏长**：GLM-5.2 15秒、Seed 26秒，均因开启了深度推理（reasoning_tokens占比92%+）。轻量任务建议关闭或限制推理深度。
2. **Token消耗放大**：reasoning模式下completion_tokens是实际输出的10-20倍，400万额度需精打细算。
3. **加密字段**：Seed引擎返回encrypted_content，需确认是否需要解密处理。
4. **建议**：在7.1引擎中实现"轻量任务直接调用、不触发reasoning"的分流机制。
