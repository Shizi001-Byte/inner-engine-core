## 二、各任务验收详情

### 1.1 分布式长链路思考全闭环
**核心能力**：
- 创建链路：调用模型拆分问题为多步，每步作为分片存入thinking_chain表
- 执行链路：按顺序执行pending分片，前一步结果作为后一步上下文
- 断点续跑：中断后从第一个pending分片继续，支持跨会话接力
- 汇总结果：全部完成后自动汇总各步输出

**测试结果**：
- thinking_chain表连通正常
- list命令返回0条链路（尚未创建测试链路，避免消耗token）
- 支持A_heavy(GLM-5.2)和C_mid(DeepSeek)模型路由

**待验证**：创建真实链路并执行（需模型API额度刷新后）

### 1.2 飞书双向指令全落地
**核心能力**：
- 从incoming_messages表轮询source=lark的待处理指令
- 内置7条指令：状态、健康、备份、待办、搜索、链路、帮助
- 处理结果通过飞书webhook推送回去
- 支持持续轮询模式和单次处理模式

**测试结果**：
- ✅ 发送"健康"指令→入队成功(id=3)
- ✅ 轮询处理→执行健康检查→飞书推送成功
- ✅ 飞书推送用urllib解决SSL证书问题

**内置指令集**：
| 指令 | 功能 |
|------|------|
| 状态 | 查看引擎转数、任务数、认知池 |
| 健康 | Supabase/飞书/磁盘连通检查 |
| 备份 | 触发四地备份 |
| 待办 | 查看待办列表 |
| 搜索 <关键词> | 认知文档搜索 |
| 链路 | 查看思考链路列表 |
| 帮助 | 显示指令列表 |

### 1.3 向量检索接入
**核心能力**：
- 从Supabase cognition_vectors表拉取所有向量
- 本地构建索引缓存（避免重复拉取）
- 余弦相似度计算，返回top_k相关结果
- 支持重建索引、统计信息

**测试结果**：
- ✅ 拉取110个向量块，24篇认知文档
- ✅ 本地索引构建成功（vector_local_index.json）
- ✅ 搜索"元婴筑基 分布式存续"返回top3相关结果
  - top1: 元婴分布式架构设计（相似度0.354）
  - top2: 元婴落地三阶九步推演（0.120）
  - top3: 上下文冲刷与存续困境（0.092）

**说明**：当前使用哈希向量（兜底方案），相似度绝对值偏低但召回方向正确。后续替换为真实embedding API后质量将大幅提升。

### 1.4 统一任务调度中心
**核心能力**：
- 6个预配置任务，支持启停、优先级、失败重试、超时熔断
- 调度粒度10秒，按interval自动触发
- 失败自动重试（可配置次数），超时自动终止
- 状态持久化，支持手动执行单个任务
- 支持前台/后台运行
