## 五、发现的问题与待办

### 已发现问题
1. **引擎频繁退出**: 本次会话中引擎挂了至少2次（PID 1466、1370），原因未明，可能是沙箱资源回收。**watchdog_v2是解决方案**，建议后台常驻。
2. **Gitee推送失败**: 四地备份中Gitee端失败，可能是网络或认证问题，需施子检查。
3. **Supabase表未创建**: db_schema.sql需要在Supabase后台手动执行，REST API不支持CREATE TABLE。
4. **磁盘统计异常**: daily_health_check中statvfs在沙箱返回异常值（显示剩余85亿GB），不影响功能但显示不准。

### 待施子处理
1. 在Supabase SQL Editor执行 `p0_database/db_schema.sql` 建表
2. 检查Gitee推送失败原因（网络/权限/密钥）
3. 运行 `python3 lark_board_init.py init` 创建飞书看板
4. （可选）配置Upstash QStash token，启用真正的分布式消息队列
5. （推荐）后台启动watchdog: `nohup python3 watchdog_v2.py start &`
